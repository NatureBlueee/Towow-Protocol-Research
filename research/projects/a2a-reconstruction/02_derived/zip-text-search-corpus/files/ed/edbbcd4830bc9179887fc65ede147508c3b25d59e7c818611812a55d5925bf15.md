# 从 PRSE-OS v0.1 迁移到 v0.2

v0.1 主要回答“怎样生产高质量规格”。  
v0.2 新增“怎样让未知消费方稳定读取和执行规格”。

## 保留

- 方法宪法；
- CapabilityProfile；
- Context Pack；
- Skill 卡；
- 质量门；
- MethodEvent；
- 语言编译；
- 人类升级。

## 新增

- AI 原生 SpecNode；
- ConsumerSession；
- Runtime-neutral Adapter Contract；
- Conformance Profile；
- 盲消费者测试；
- 质量目标与 Agent 数量解耦；
- 召集台 reference project。

## 迁移动作

1. 不再把长篇 Word 当唯一真相源。
2. 把稳定结论拆成 SpecNode。
3. 给旧结论标记 superseded/deprecated。
4. 为每个 View 建来源映射。
5. 将本地 Harness 通过 adapter 映射进来。
6. 先跑 smoke tests，再跑召集台 conformance cases。
