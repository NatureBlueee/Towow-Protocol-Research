# Run analysis

## What changed the research judgment

The strongest result is negative: direct A2A did not create an accepted
capability unavailable to simpler arrangements. A single static builder found
the composite-identity defect and most visible lifecycle seams. Fixed central
queries exposed the same A/B compatibility conflict. Direct interaction made
that conflict more precise and added recovery-governance conditions, but did
not converge or produce an adoptable patch within the call budget.

Executable counterfactual tests show why non-convergence was rational. The
hidden branch and A2A candidate implement mutually exclusive source-less
semantics. Each passes its own acceptance family and fails the other. The
remaining gap is an authorized value choice backed by corpus evidence, not more
message exchange.

## Classification

- Repository-specific defect: locator-only reference identity and a worktree
  hook false alarm.
- Transferable design principle: identity changes must be propagated through
  producer, ordered fold, projection, auxiliary events, gates, and migration
  evidence; consumer-only edits create false closure.
- Mechanism evidence: private vetoes can expose a real value conflict and form
  recovery clauses, but interaction does not imply acceptance or net value.
- Core theory change: none justified by this single local task.

## Defeaters and limits

- Synthetic private contexts were authored from one repository and mediated by
  a trusted root.
- The same model family served all Claude roles.
- No real organization had non-collapsible authority; least-privilege central
  could safely collect the relevant answers.
- The hidden branch pre-existed, so rediscovering composite identity is
  discovery, not first creation.
- The experiment did not measure the real legacy corpus.
- A central builder transport failure required a separately preregistered
  replication; run-001 itself remains failed.

## Decision

Requalify, do not promote, the generative A2A claim. For collapsible local
engineering tasks, start with static/full-context engineering plus
least-privilege owner queries. Escalate to sovereign A2A only when authority,
liability, acceptance, or privacy cannot safely be collapsed and when the
interaction-formed condition can be executed and accepted.
