# Harness Adapter 指南

本地 Harness 不需要改造成 PRSE 的样子。只需把自己的实体映射到通用语义，并实现七个逻辑钩子。

## 通用对象映射

| PRSE | 本地可能叫法 |
|---|---|
| CapabilityProvider | agent / worker / role / node |
| Skill | recipe / program / subflow |
| ContextPack | knowledge pack / memory bundle |
| WorkItem | task / job / issue |
| Artifact | result / file / object |
| Validator | judge / eval / checker |
| MethodEvent | trace / event / log |
| EscalationCase | human interrupt / approval |

## 七个必须语义

- read_package
- resolve_context
- route_capability
- execute_method
- validate_artifact
- emit_method_event
- escalate

函数名和技术形式不重要；语义缺失会造成规范不可执行。

## 接入步骤

1. 复制包到 `.spec/prse-os/`；
2. 填写本地映射；
3. 实现或适配七个钩子；
4. 导出 MethodEvent；
5. 运行 smoke tests；
6. 加载召集台 reference pack；
7. 跑一次盲消费者与变更传播测试。

## 边界

Harness 是 Consumer / Runtime，不是规范本身。Harness 的默认 Prompt、缓存和编排不得静默改变规范节点。
