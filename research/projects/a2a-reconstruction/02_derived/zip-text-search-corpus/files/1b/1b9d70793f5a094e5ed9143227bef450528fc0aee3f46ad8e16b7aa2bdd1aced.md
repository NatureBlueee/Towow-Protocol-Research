- [ ] 能区分 accepted / draft / superseded
- [ ] 能保留 evidence 和 provenance
- [ ] 能生成 Artifact 到独立目录
- [ ] Validator 不能与 Producer 完全同上下文自证
- [ ] MUST 失败会中断发布
- [ ] 可产生 EscalationCase
- [ ] 可导出 MethodEvent
- [ ] 可执行盲消费者测试
- [ ] 不会将旧原型自动当成当前规范
