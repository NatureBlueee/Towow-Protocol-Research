# 公开访谈语料的作用与边界

本轮确认了 Zenodo 上公开的 ML System Development Processes Expert Interview Transcripts：8 份翻译后的访谈 PDF 和一个汇总表；关联论文报告了 9 名来自德国和瑞士公司的受访者、30–60 分钟半结构访谈，并明确指出专家常常并不知道自己行动的意义，研究者需要从陈述中重建知识。

这类材料适合补充：

- 主体内部真正使用的流程词汇；
- POC、feasibility、business value、productization、deployment、monitoring 的实际决策点；
- 分工团队之间的 handoff 与上下文损失；
- 什么内容只有访谈能恢复，什么内容应由目标系统 witness。

它不适合直接充当：

- 完整时间事件链；
- 法律或组织 Authority 证明；
- Commitment / Effect / Acceptance 记录；
- Agent 介入的因果实验。
