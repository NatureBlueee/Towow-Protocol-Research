# PRSE-OS v0.1 总纲

## 一句话
把“做产品的方法”从隐性经验，变成可由多 Agent 与人类共同运行、可检查、可升级的规格生产系统。

## 不是
- 不是一个万能 Prompt；
- 不是一份大而全的 PRD 模板；
- 不是专家角色扮演；
- 不是固定瀑布流程；
- 不是某个 Agent 框架的绑定方案。

## 是
- 规范内核；
- 能力与知识的路由协议；
- 标准产物系统；
- 质量门与升级机制；
- 方法可观测系统；
- 内外语言的语义编译器。

## 最重要的设计

### 1. 能力替代身份
专家由知识、技能、工具、范围、权限和表现定义。人类与智能体使用同一抽象。

### 2. 产物替代对话
长期真相不住在聊天里，而住在 Concept、Decision、Object、Loop、View、Claim 等版本化产物中。

### 3. 质量门替代“感觉不错”
每个阶段都有可以失败的明确准入。失败必须可见，并触发修复、重路由或人类升级。

### 4. 最小上下文替代上下文堆积
按 concern 选择知识包，记录版本、来源、有效期和使用限制。

### 5. 语义编译替代复制粘贴
规范、团队、界面、市场和公共语言是不同投影。对外层不能偷偷创造新的能力。

### 6. 遥测替代黑盒
记录路由、上下文、技能、产物、验证、冲突、升级和人类覆盖，形成方法健康面板。

## 方法运行闭环
问题 → 证据 → 主张 → 决策 → 本体 → 闭环 → 视图 → 保证 → 表达 → 验证 → 发布 → 观测 → 修订

## 最终验收
另一个不了解历史的智能体，只拿到方法包与项目包，也能：
- 选择正确流程；
- 路由正确能力；
- 生成标准产物；
- 发现不足而不是胡补；
- 在需要时准确升级给人类；
- 输出与产品规范一致的界面和对外表达。
