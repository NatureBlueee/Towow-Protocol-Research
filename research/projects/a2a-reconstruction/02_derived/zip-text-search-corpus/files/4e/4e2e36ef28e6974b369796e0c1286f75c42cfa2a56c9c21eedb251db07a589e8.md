# 宪法：与运行主体无关的规格制度

## 1. 核心目标

本系统的目标不是规定“谁来做”，而是规定“什么结果才算成立”。

同一条要求可以由：

- 一个人；
- 一个 Agent；
- 多 Agent；
- 一个自动化程序；
- 人机混合组织；

以不同方式达成。只要它们满足相同的证据、产物、质量和责任要求，就被视为合格实现。

## 2. 规范与实现分离

规范层 MUST 定义：

- 语义；
- 事实与依据；
- 对象和关系；
- 闭环与后果；
- 产物契约；
- 质量门；
- 升级条件；
- 对外表达边界。

实现层 MAY 决定：

- Agent 数量；
- 模型；
- 并发方式；
- 编排拓扑；
- Prompt；
- 工具；
- 存储；
- 自动化程度。

## 3. 对“100 个 Agent”的纠正

规范 SHOULD 描述质量需求，而不是随意锁定执行数量。

错误：

```text
必须有 100 个 Agent 审查。
```

更好的规范：

```text
MUST 覆盖 12 个 concern；
MUST 至少有 4 个互相独立的审查上下文；
MUST 包含正向、反向和对抗性审查；
MUST 达到 95% 边界状态覆盖率；
在连续两轮没有新的 Critical finding 后 MAY 停止。
```

只有当样本量、博弈结构、并行探索空间或法定程序确实要求数量时，才 SHOULD 写死实例数；同时必须规定独立性和多样性，否则 100 个高度相关的副本仍然只是一个偏见的回声室。

## 4. 文档面向 AI 的根本变化

AI 不缺一般常识，但缺：

- 当前项目的有效事实；
- 词语的精确定义；
- 信息来源和可信度；
- 哪些决定已定、哪些已废弃；
- 哪些内容适用于当前任务；
- 权限和可使用范围；
- 冲突时的优先级；
- 产物必须满足的结构。

因此 AI 原生规格 MUST 优先建设信息渠道，而不是堆叙事。

## 5. 规格不是答案，而是方向场

对于尚未研究完成的部分，规范 MUST 能表达：

- 已知什么；
- 不知道什么；
- 当前鼓励的方向；
- 明确禁止的误读；
- 下一步需要什么证据；
- 什么条件下可以改判。

这比假装给出永久定论更专业。

## 6. 人类与 Agent

人类和 Agent 都是 Capability Provider。二者使用同一产物契约和验证规则。

但责任不可虚构：

- Agent MAY 产生建议、分析、草案和可验证执行；
- 只有有权主体可以承担正式批准、签字、法律与组织责任；
- 何时必须升级给人类，由 concern 和后果决定，而不是由“AI 是否聪明”决定。
