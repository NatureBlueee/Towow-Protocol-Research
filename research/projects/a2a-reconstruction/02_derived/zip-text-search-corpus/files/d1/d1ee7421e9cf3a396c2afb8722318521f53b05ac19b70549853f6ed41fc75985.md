# Independent review — effect reality matrix

## Reviewer and independence

Reviewer: context-separated `effect_matrix` subagent, completed before the
primary repair. The reviewer inspected Harness source/tests and returned an
independent scenario judgment without editing project code.

Independence is limited: the reviewer used the same model family and repository
snapshot as the primary researcher. This is a separate-context review, not an
independent organization or model replication.

## Review judgment

1. The four semantic stages are useful. Timeout, partial output, durable park,
   stale index, and raw event bytes must not be treated as equivalent to accepted
   outcomes.
2. Existing Harness evidence can represent the decisive facts in the reviewed
   cases. Real prevention comes from authoritative readback and acceptance
   gates, not automatically from four new durable top-level objects.
3. A naive exit/text/last-event baseline loses important provenance and can
   select the wrong retry or closure action.
4. The background poller was a high-value transfer case: it wrote raw bytes
   whose producer-shaped record could not be consumed by the standard
   `EventLog` reader.
5. `EscalationAnswerApplied(resumed=True)` requires care. A durable carrier for
   future redispatch is not identical to verified consumption by a session.

## Baseline recommendation

- `B0_terminal`: keep only as a cheap observation, never as closure authority.
- `B1_harness`: use existing events/files plus fresh authoritative readback;
  missing readback must remain pending.
- `T1_explicit_aeva`: retain as a normalization and decision layer over the same
  evidence.

Promote a new authoritative object only if a held-out case demonstrates an
error that `B1_harness` cannot represent or prevent with the same evidence.

## Primary-research response

The primary run accepted the review's core conclusion, added a fresh-reader
regression, captured the predicted red baseline, and changed the poller to the
canonical EventLog writer. It also retained the escalation event-semantics
counterexample rather than declaring the existing representation perfect.
