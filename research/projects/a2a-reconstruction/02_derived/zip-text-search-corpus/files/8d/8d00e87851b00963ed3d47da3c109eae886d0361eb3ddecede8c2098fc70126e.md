# 当前研究状态 v0.6

## 已完成

- 继承 v0.5 的三案公开过程重编码与文档消融；
- 新增 Sidewalk Toronto、UK Open Banking、Crossrail、SGMA 四案；
- 七案共 58 个 typed events；
- 建立 institutional frame / relation-specific version 双分辨率；
- 操作化 standing、declared/enacted schema、五维 stability、制度化 compile 和六类 reopen；
- 建立来源剖面、缓存、校验和、claim-source compatibility；
- 形成可重跑 analyzer 和 v0.6 event schema。

## 已提高的主张

- 现实制度中确实存在当前 Relation Schema 试图描述的 material 变化；
- institutional-frame sufficiency 比任务复杂度更适合作为 CollapseSafe 边界；
- standing 可以 material 而不等于 signature authority；
- declared schema 与 enacted schema 需要分开；
- 技术 Adoption 与治理/合法性稳定正交；
- coordination mechanism 随权威拓扑、自治和 outcome 变化。

## 未提高的主张

- live Agent delegation 与 explain-back；
- Towow 形成的新路径因果新颖性；
- 相对强人类经纪/中心 Agent 的净价值；
- 最小披露的真实隐私—形成质量权衡；
- 长期 Acceptance、操纵、权力与第三方效果。

## 证据等级

`single-coder archival mechanism evidence — theory-calibrating, not treatment evidence`。
