# R5.4 负对照摘要

## 任务

真实 Harness 源码中的 reference identity 兼容与来源隔离冲突。

## 比较

- 静态单 Agent；
- 固定最小权限中心查询；
- 六轮直接 A2A；
- 现有 Harness + 人工／隐藏实现。

## 结果

- 静态 Agent 已发现主要复合 identity 缺陷；
- 中心查询已暴露 A 的全局兼容要求与 B 的来源隔离要求；
- A2A 生成 null-source、severability、disclosure、entitlement floor 和 dispute 等更丰富候选条款；
- 没有双方最终认领、目标域采纳或被接受补丁；
- 核心 Unknown 依赖真实历史 corpus 与有权 Owner 的价值选择；
- A2A 成本高于静态路径，但该局部成本不代表通爻一般经济价值。

## 研究定位

这项实验现在是：

- 协商与规范候选生成的机制证据；
- 可折叠工程任务中 A2A 不必默认启动的架构负对照；
- `COUNTER / UNKNOWN / REFUSE` 有效性的证据；
- 生成性互动旗舰任务选择的反例。

它不是：

- PFE 能力形成证据；
- 主权 A2A 结构必要性证据；
- A2A 商业价值的普遍否定；
- 多轮交流不能创造能力的证据。
