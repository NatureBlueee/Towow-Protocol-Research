# 方法可观测模型

观测对象不是“Agent 想了什么”，而是可以公开检查的运行事实：

- 读取了哪些规范节点；
- 装载了哪些知识；
- 为什么路由某种能力；
- 生成了什么中间产物；
- 哪个质量门失败；
- 决策如何改变；
- 人类为何介入；
- 哪个外部 View 从哪些内部节点编译而来。

这避免依赖不可审计的内部推理，同时仍能判断机制是否健康。

## 三种失败定位

1. **渠道失败**：缺包、旧包、权限不足、上下文冲突。
2. **能力失败**：Skill 或 Provider 不适合任务。
3. **规范失败**：要求本身冲突、不可验证或定义不完整。

不要把三者都归结成“模型不够聪明”。
