# 公开证据研究程序 v0.5

## 目的

把公开材料拆成可复现、可限定的观测窗口，持续寻找会改变理论、规范、Fieldkit 或未来真人实验设计的证据。公开资料不是 E7 真实 Principal 证据，也不是总体抽样。

## 材料谱系

### A. 正式过程与效力记录

SEC proxy/8-K、监管决定、GAO bid protest、法院/行政公开记录。主要观察 Authority Locus、RelationVersion、Commitment、Effect、challenge、reopen 和 scoped Settlement。

### B. 控制型人类谈判语料

CaSiNo、DealOrNoDeal、CraigslistBargain 等。主要观察隐藏偏好、理由披露、策略、agreement readback 和 NoDeal。它们通常预设角色、动作与奖励，因此是“丰富互动不等于 Schema 形成”的负控制。

### C. 开放专家访谈和逐字材料

用于恢复主体内部角色、上下文、流程变体、非正式否决和未对象化知识。访谈是来源化陈述，不自动等于 Commitment、Effect 或客观全史。

### D. 压缩公共叙事

新闻稿、企业介绍、最终公告。用于文档充分性消融与输入边界测试，不能被当作完整主体世界。

## 当前已完成的研究流

### P1. 事件级历史过程追踪

- 冻结公开可见的时间点、行为者、Authority Locus 与 RelationVersion；
- 区分 Assertion、Stance、Commitment、Operation、Effect、Adoption、Acceptance；
- 每个 materiality 判断指出改变的可达轨迹或权威/证据/数据/结果语义；
- 不用最终结果倒推不可观察的私有状态。

### P2. 文档充分性消融

比较压缩公告流与正式过程记录，计算事件、material event、critical turn 与 Authority recall，并记录错误合并。

### P3. 最大差异反例搜索

主动选择交易完成、被禁止、被重构、已发生 Effect 后被重开、能力证据失效、身份/签署权不明等案例。每例必须声明其反驳或修订的命题，不做支持性堆例。

### P4. Shadow Towow reconstruction

把公开历史事后编码为 Fieldkit RelationVersion、typed event、materiality 和 compile readiness，检验内核表达力。不得从表达成功推出机制优越或历史因果。

## 下一批研究

1. 将最大差异语料扩展到 30–50 例，覆盖法院 specific performance、联盟/许可、监管沙盒、标准组织与采购重评；
2. 对至少 5 例做独立第二编码；
3. 开发 archive-to-Fieldkit importer 与差异比较器；
4. 对固定语法谈判语料做 hidden preference / reason / NoDeal 校准；
5. 对开放访谈做 authority/process vocabulary 与不可观察项校准；
6. 建立静态平台、优秀人类中介、同权限中心 Agent、主权 Entity 四类反事实基线。

## Gate

- 单编码者 pilot 不声称编码一致性；
- 有意选择档案不推断总体频率；
- 没有 prospective Agent intervention 不升级为 Agent 因果效果；
- 没有目标世界 witness 不升级为 Effect；
- 正式批准不升级为 explain-back 或自由认领；
- 来源没有观察到的内容保持 `UNKNOWN`，不得写成不存在；
- 当连续十个新增案例不再产生理论或 Fieldkit Design Delta 时，停止扩大同类档案。
