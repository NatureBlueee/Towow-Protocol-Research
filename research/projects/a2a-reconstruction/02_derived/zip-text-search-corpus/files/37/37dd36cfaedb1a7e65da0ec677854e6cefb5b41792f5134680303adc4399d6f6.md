# 动态研究地图：从技术域闭环转向真实主体闭环

## 当前元问题

两个无法安全共享完整世界的人或组织，能否通过各自 Agent 发现并形成一条此前不存在的联合行动路径；这条路径能否被双方分别理解、认领、执行和接受，并产生高于协调成本的真实价值？

## A. 已进入实现与自动回归

### 现实语义和证据闭合

- LogicalActionKey / AttemptID
- ActionAttempt / Effect / Verification / Acceptance
- canonical commit / readback
- Claim-specific Witness
- journal-before-ack
- stable revision identity
- Evidence portability
- negative state / revocation / dispute

研究方法：代码审计、属性测试、故障注入、形式验证、自动回归。

不再占据主研究轮次，除非直接制造假闭环或暴露核心机制。

## B. 已获得 scoped mechanism evidence

### 跨技术域采纳

Allbuddy—Agent World 已证明：来源域可以在不暴露正文的条件下，交付自己有权声明的粗状态；目标域可以正式物化、撤销、离线降级和重启复建。

未知：真实组织、不同技术栈、版本迁移和商业使用。

### 形成后确定性运行

证据支持：冻结边界后 least-privilege coordinator 足以机械执行。

未知：matched central formation 是否同样高效；开放任务是否能稳定冻结。

## C. 当前最高优先级：真实 Principal 形成与 Recognition

竞争解释：

1. Agent 能发现双方没有意识到的互补性；
2. Agent 只是在揭示原本隐含的偏好和能力；
3. Agent 根据常见模式投射了双方并不真正认可的方案；
4. 人工经纪人或最小权限中心同样可以完成；
5. 双方最终仍只需要一个人作价值取舍。

需要的新增证据不是更多技术测试，而是：

- 两个真实人的独立材料和权威；
- 互动前没有被双方接受的路径；
- Agent 形成现实条件，而不仅是文本；
- 两人分别认领或拒绝精确方案；
- 去掉关键互动或条件后路径消失；
- 原始价值没有被降低；
- 实际行动和接受发生；
- 人类高认知时间和机会价值可观测。

## D. 能力形成和迁移

问题：本次技术 bridge 是一次性集成，还是一种可复用能力？

已知：同一协议和环境内有一个负状态 holdout。

未知：跨版本、跨环境、跨主体和不同任务。

下一判别条件：能力 Claim 必须在执行前冻结，并对未知任务作预测；干预后的成功不能回填为原预测命中。

## E. 偏好发现、偏好形成与模型投射

当前技术域实验无法回答。软件策略的自动 adopted 不是人的 Recognition。

这是下一研究对象必须转向真实人的根本原因。

## F. 经济与认知价值

当前状态：UNKNOWN。

需要比较：

- 机会不发生；
- 人工经纪人 / 经理人；
- 人工 + AI；
- full central；
- least-privilege central；
- sovereign A2A。

关键量：高认知人类时间、阅读与切换、等待、披露、风险、返工、新机会价值、最终接受。

## G. 长期网络与权力问题

暂缓主线：战略隐瞒、串谋、边界重建、声誉操纵、协调器权力和规模效应。

它们重要，但当前不会决定最小真实主体闭环怎样设计。

## 研究调度原则

下一项工作只有在满足下列条件时才进入主线：

- 会改变核心对象、运行方法或产品适用域；
- 现有理论和工程知识无法直接决定；
- 现实反馈能区分至少两种实质不同解释；
- 结果能够新增解决能力，而不仅是增加测试；
- 失败仍能产生可执行替代结构。

## 当前方向判断

优先级已经从“跨域技术 bridge 的更多完善”转为“现实主体确认”。技术 bridge 继续作为实验基础设施，不再作为 Principal 的替代品。
