# 上下文渠道模型

AI 的关键治理对象不是“懂不懂常识”，而是：它从哪里、在什么权限、什么版本、什么 Scope 下获得事实。

## 八类包

1. Core Method Pack
2. Project Core Pack
3. Current State Pack
4. Concern Pack
5. Evidence Pack
6. Task Pack
7. Language Pack
8. Negative Pack

每个 Context Pack 必须有 provenance、freshness、trust_level、allowed_concerns、forbidden_uses 和 conflicts_with。

## 最小充分原则

上下文越多不一定越好。过量上下文会引入锚定、冲突掩盖和注意力稀释。

## 缺口行为

缺少 Required Pack 时必须产生 ContextGap。除非 Requirement 明确允许推断，否则不得用一般知识静默补齐。
