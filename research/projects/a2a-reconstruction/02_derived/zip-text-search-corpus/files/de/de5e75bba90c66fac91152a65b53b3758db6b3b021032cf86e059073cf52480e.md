# Hypothesis — cross-source `@reference` identity

## Research value

The current Harness reducer and invalidation reader treat an `at_reference` /
`reference_id` locator as globally unique. Two independently controlled source
concepts can legitimately hold the same typed locator. This gives a real task
whose combined failure cannot be observed from either owner's local lifecycle
alone.

The task is deliberately not evidence that a solution is globally novel. An
unmerged local branch contains a prior repair and held-out regression oracle.
Rediscovering that repair is at most epistemic discovery unless interaction
also creates an accepted condition not already present in either initial
dossier and a simpler fair baseline cannot obtain it.

## Preregistered claims

- `R54-GEN-001`: direct A2A interaction may form a jointly acceptable reference
  identity/lifecycle contract that static description and a least-privilege
  central query baseline do not obtain.
- `R54-CENTRAL-001`: because these source contexts are safely summarizable, a
  least-privilege central baseline may equal or beat direct A2A at lower cost.
- `R54-BOUNDARY-001`: tool-less model sessions plus a source-bound broker create
  functional model-context and authority separation, while not constituting OS
  or organizational sovereignty.

## Falsification

`R54-GEN-001` is weakened or refuted for this task if any of the following hold:

1. the static single-agent patch passes the same acceptance suite;
2. the least-privilege central patch passes at lower total cost;
3. the A2A contract merely restates a source field already present in public
   code and does not change an accepted action;
4. the A2A patch fails target-domain adoption or preserves the goal only by
   globally deleting legacy data, ignoring a consumer, or narrowing coverage;
5. the decisive condition appears without questions, refusal, countercondition,
   or disclosure change.

No local outcome may be generalized to production, other repositories, or
long-running cross-organization cooperation.
