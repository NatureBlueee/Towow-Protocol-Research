## Operational domain and preconditions

The claim applies only to a single-host, synthetic local Allbuddy consumer
source and an independent local Agent World process. The source must expose the
frozen claim/readback/ack interface, a pre-established 24-hour consumer session,
monotonic revision lineage, and a coarse six-field readback. World must retain
its own journal directory and use the correct World claim capability.

## Prospective guarantee

For a previously unseen operation within that domain:

1. producer `completed` without consumer adoption/cancellation creates no World
   EventRecord or projection;
2. an authorized `not_adopted@rev1` source report is journaled before ack,
   becomes one commandless source-authoritative C2 EventRecord and one stable
   C4 claim projection whose state is exactly `not_adopted`;
3. a fresh World process reconstructs byte-equivalent R5C C2/C4 state from the
   journal after the source delivery has been acked;
4. Artifact content, query text, consumer session, read capability, lease token
   and World bearer do not enter the durable World journal;
5. a wrong World bearer creates no source enumeration and no projection.

## Known defeaters and nonclaims

- malformed, divergent, wrong-issuer, wrong-policy, wrong-reference or
  non-contiguous evidence is rejected rather than repaired;
- source loss before any accepted report creates no projection; source loss
  after a report retains the last value only as offline/unknown;
- no claim of human preference, customer adoption, Artifact correctness,
  business value, production IAM/HA, multi-host durability, power-loss
  durability, or the persistence of Agent World's unrelated command pipeline;
- success on the holdout supports this narrow adapter capability, not a general
  A2A Capability Claim.

## Falsifier

The claim fails if the holdout is projected as adopted/completed, if no
projection appears despite an authorized canonical not-adopted report, if a
fresh restart changes identity/current state, or if any private payload or
credential appears in World durable bytes.
