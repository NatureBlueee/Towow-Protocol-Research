# 固定语法谈判语料的作用与边界

## CaSiNo

包含 1,030 条人类营地物资谈判，对 Food/Water/Firewood 的偏好理由、说服、rapport 和结果有丰富记录。但偏好顺序由实验分配，作者明确称其为 tractable closed-domain abstraction。

## Deal or No Deal

包含 5,808 条人类对话；双方拥有不同私有价值函数，10 轮后可 NoDeal，双方还要独立提交自己理解的最终分配，若不一致则双方得零。它非常适合检验 `language agreement ≠ shared state readback`。

## CraigslistBargain

用真实 Craigslist listing 和 6,682 条人类谈判，引入配送、附加物品、同情诉求等 side offers。它比纯物品分配更开放，但 buyer/seller、商品、价格和核心 offer/accept/quit 动作仍是平台预定的。

## 研究结论

这些数据可以测试：

- 隐藏偏好是否被正确提取；
- 理由披露与信息成本；
- NoDeal 与错误 agreement；
- side offer 是否只扩展实例，还是改变动作/义务类型；
- typed shared object 是否减少双方对结果的分歧。

它们不能证明：

- Agent 拥有真实授权；
- 关系语法由现实主体共同形成；
- 结果进入现实组织；
- 参与者长期接受或承担责任。
