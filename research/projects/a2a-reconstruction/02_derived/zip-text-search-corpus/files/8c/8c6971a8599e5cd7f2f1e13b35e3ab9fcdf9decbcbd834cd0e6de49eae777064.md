# R5C-RETURN-001 Portable Packet

This directory is the complete portable return packet for the bounded
constructive flagship episode `R5C-EP-001`.

## Start here

1. Read [`RETURN_SUMMARY.md`](RETURN_SUMMARY.md).
2. Inspect the claim-by-claim ledger in
   [`CLAIM_EVIDENCE_UPDATE.csv`](CLAIM_EVIDENCE_UPDATE.csv).
3. Reconstruct the episode from
   [`FORMATION_EPISODES/README.md`](FORMATION_EPISODES/README.md).
4. Review rejected evidence and unresolved limits in
   [`RAW_EVIDENCE/PROVENANCE_LIMITATIONS.md`](RAW_EVIDENCE/PROVENANCE_LIMITATIONS.md).
5. Run:

   ```sh
   python3 verify_return_packet.py
   ```

## Contents

- the eight return views required by `09_RETURN_PACKET_TEMPLATE.md`;
- one complete Formation Episode with pre-state, interaction, actions,
  Defeaters, target state, Acceptance, ablations, holdout and final review;
- discovery, environment, state and decision records;
- the governing v1.5 task inputs and supplied JSON Schemas;
- the complete claim/evidence ledger;
- reconstructable source patches pinned to baseline and final commits;
- schema/dependency and model/agent provenance;
- checksums and a verifier that checks file closure, local links, claim
  evidence references and manifest coverage.

## Interpretation boundary

“Complete” means that the packet contains every preserved artifact needed to
audit this scoped result, and explicitly names evidence that was never
captured. It does not mean the fifth-stage research program is globally
complete. It also does not convert a checksum, test pass or local synthetic
Acceptance into production, human or commercial Acceptance.
