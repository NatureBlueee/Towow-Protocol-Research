# R5C-EP-001 pre-state

## Objective and value dimensions

Create a local, reversible path by which one private Allbuddy advisory result is:

1. generated from tenant-scoped state;
2. adopted by the Allbuddy consumer;
3. independently ingested and honestly projected by Agent World;
4. traceable without exposing prompt text or enterprise object contents;
5. kept below `source_confirmed` when target Acceptance, provenance, freshness or
   integrity is absent.

Preserved value dimensions: tenant isolation, business-answer authority,
independent provenance authority, honest uncertainty, replay safety, target
adoption and recoverability.

## Reachability before interaction

No accepted end-to-end path exists.

- Allbuddy `app/_lib/workspace-runtime.ts` uses hard-coded
  `ADVISOR_OUTCOMES`, produces an Artifact and marks every step
  `completed`. This is a product-local claim, not an independent
  postcondition.
- Allbuddy `core/advisor/engine.ts` has a real model client and tenant-scoped
  substrate, but sends only an object-count digest and is not the current
  workspace consumer path.
- Agent World `apps/server/src/bootstrap-v0.mjs` accepts H1 events only when
  their `correlation.commandId` exists in the current backend generation.
  Externally caused observations are dropped.
- Agent World OQ-004 and OQ-009 leave redacted Source Maps and external
  event admission unresolved.

## Private worlds and authority

### Allbuddy principal

- Can inspect tenant-scoped substrate, local advisory runtime, Artifact
  consumer and business-facing failure modes.
- Owns whether a result was adopted in the target product.
- Must not expose prompts, enterprise object contents or cross-tenant state.
- Cannot assign Agent World `source_confirmed` authority.

### Agent World principal

- Can inspect canonical EventRecord, RealityProfile, Source Map, ingress,
  deduplication and projection semantics.
- Owns whether an external observation is honestly represented.
- Must not inspect enterprise content or decide whether the business answer is
  good.
- Cannot treat producer self-report as independent confirmation.

### Root experimenter

- Relays messages without adding solution content.
- May execute only local, reversible actions in isolated worktrees.
- Does not preselect a receipt schema, state mapping or success path.

## Candidate explanations to distinguish

1. A static one-shot receipt contract is sufficient.
2. Adaptive A2A queries form a smaller or safer boundary artifact.
3. Full-access central is technically stronger but invalid under privacy.
4. Least-privilege central can match A2A under the same allowed projection.
5. No local technical artifact can establish independent Acceptance; owner or
   external authority is required.

## Acceptance boundary

Automated local evidence may support a technical mechanism claim. It cannot
establish owner-recognized business value or production readiness.
