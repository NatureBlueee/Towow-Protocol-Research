# Agent World ExecPlan independent review 01

## Semantic review — COUNTER

What was accepted:

- commandless EventRecord is schema- and foundation-valid;
- `source` authority can mean only authority over Allbuddy's own report;
- `local_equivalent_real` is honest for the independent local API/process,
  never actual external Harness or release;
- one stable projection ID updated across revisions is the right direction.

Blocking corrections:

- C4's structural OR-floor did not satisfy canonical NoOrphanProjection;
  create a stable `claim` semantic entity and bind it plus EventRecord/SourceRef;
- after a prior adopted state, offline/gap/conflict cannot be “no mutation,”
  because that leaves stale success looking current; explicitly downgrade
  stale/unknown/partial or disputed;
- freeze immutable AdapterSnapshot and exact provenance joins;
- require unique eventId/revision, decimal sourceSequence, contiguous lineage,
  ordered correction and divergent-revision dispute;
- derive projection identity only from stable claim identity, never compiler
  content version;
- add an exact Canonical Basis and a non-claim matrix.

## Systems review — COUNTER

Blocking failure:

`createMemoryStore()` loses C2/C4 and counters on restart. Persisting only a
claimed delivery, then acking the source, would make acked semantics disappear
permanently after World restart.

Required corrections:

- replace delivery inbox with a restart-replayable semantic journal containing
  immutable claim core, complete lineage readbacks, exact first C2 envelopes,
  stable identity allocation, phases and ack-ready postcondition;
- keep lease token, World bearer and reader capability ephemeral; re-lease
  token changes are not event divergence;
- read and durably stage the full lineage batch before exposing any revision;
- reconcile C2-only/C4-only/delta-missing cut points rather than treating C2
  duplicate as full success;
- ack only after full semantic postcondition can be recreated from journal;
- add ack-then-restart, cut-point, rev2-first, token rotation, timestamp retry
  and reverse-reference-order probes.

## Disposition

Both reviews were incorporated into the ExecPlan before implementation.
Re-review is required; this document is not approval.
