# Coordination baseline comparison

This is an evidence-bounded comparison over the local research task. It is not a
causal experiment and does not claim production or cross-organization
generality.

| Strategy | Executed here | Observed value | Observed or expected cost | Current judgment |
|---|---:|---|---|---|
| Full-access central | No | No incremental value demonstrated over scoped access | Broader disclosure and larger accidental-effect radius; unnecessary for the selected local tasks | Not justified |
| Least-privilege central | Yes | Found a real unreadable-event defect, repaired it, preserved provenance, and ran ordinary holdouts | One central context, explicit environment setup, about 66.5 captured command seconds across Runs 001–002, plus review/packaging attention | Best-supported execution baseline |
| Sovereign coordination | No true sovereign execution | No measured incremental error prevention in this run | Additional handoff, boundary maintenance, duplicated context, latency, and reconciliation; exact cost unmeasured | Superiority not demonstrated |
| Existing Harness plus human owner | Yes, as substrate and scope authority | EventLog, test guards, Git isolation, existing domain events, and owner scope correction prevented false closure or unauthorized expansion | Requires correct authority ordering and human attention for scope; current event names can overstate acceptance | Necessary baseline, not sufficient without fresh readback |

## Why the least-privilege central baseline won locally

The decisive conditions were concrete and local:

- isolated branch/worktree;
- explicit source provenance;
- policy-compatible temporary root;
- canonical `EventLog` writer;
- fresh state readback;
- protected main tree and canonical ledger;
- human clarification that excluded all attack/defense-related work.

No selected task required full repository write authority, production access, a
remote provider, or cross-organization settlement. Adding sovereign protocol
machinery would therefore have increased coordination cost without an observed
decision benefit.

## What remains open

A sovereign approach could still win when independent organizations control
different truth sources, cannot share authority, and must verify portable claims
without a common operator. That condition was not present or executed here.

The next valid comparison should pre-register:

- one task that genuinely spans independent environments;
- the same acceptance oracle for central and sovereign strategies;
- token, latency, human attention, disclosure, handoff failure, recovery, and
  reconciliation costs;
- a stopping rule that retains the simpler winner.
