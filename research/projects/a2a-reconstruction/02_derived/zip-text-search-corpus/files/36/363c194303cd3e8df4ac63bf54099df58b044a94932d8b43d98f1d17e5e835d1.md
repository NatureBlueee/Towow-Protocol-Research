# 规格与方法治理

## 三种版本

- Method Version：PRSE 方法版本；
- Project Spec Version：具体产品规范版本；
- View Version：UI、文案、运营手册或原型版本。

三种版本不得共用一个版本号假装同步。

## 禁止追加式更新

重要改变必须：

1. 修改规范节点；
2. 标记旧节点 superseded；
3. 执行影响扫描；
4. 更新受影响的 Loop、View、Metric 和 External Claim；
5. 运行回归测试；
6. 生成 Migration Note。

## 方法变更准入

一条方法规则升级为默认前，应至少完成：历史回放、当前项目试运行、跨领域迁移验证三项中的两项，并证明没有关键退化。
