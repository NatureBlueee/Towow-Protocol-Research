# Independent review boundaries

The blind reviewer saw preregistration, public/static/central/A2A traces and
could refuse or return Unknown. It did not see private dossiers, evaluators,
hidden implementations, other worktrees, or Git refs.

The oracle-aware reviewer saw frozen outputs and the hidden branch only after
the model outputs were frozen. It was told that the oracle was not necessarily
correct and identified both static semantic faults and oracle test gaps.

Neither reviewer modified the repository. The root independently executed the
paired pytest counterfactuals after their analyses.
