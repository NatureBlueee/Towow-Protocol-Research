# 通爻 A2A 当前整体判断 v0.5

本文件保留版本化入口。完整、经过两项公开证据研究与三项 Shadow reconstruction 整合后的当前判断见：

[`00_EXECUTIVE_SYNTHESIS.md`](00_EXECUTIVE_SYNTHESIS.md)

最核心的 v0.5 修订是：通爻的研究对象从“怎样形成一条新路径”收敛为“怎样构成并持续修订合格联合行动空间”。严格形成可以是 Expansion、Transformation 或 Protective contraction；Epistemic clarification 单列。Settlement 必须带 RelationVersion、jurisdiction、standing、challenge horizon 与 evidence state。

公开档案已经足以校准现实 Authority、RelationVersion、Effect、challenge、reopen、evidence gate 和 scoped Settlement，也已改变 Fieldkit；但它没有观察 Agent 因果贡献、真实范围化认领或相对优秀人类中介的净协调剩余，因此 C18、C19、C20 仍保持 `UNKNOWN`。
