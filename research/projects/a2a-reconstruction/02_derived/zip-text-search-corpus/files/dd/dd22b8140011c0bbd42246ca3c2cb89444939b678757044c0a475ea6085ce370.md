# 包结构地图

| 目录 | 作用 |
|---|---|
| `01_METHOD_CORE` | 当前统一的方法宪法、架构、语义与治理 |
| `02_DESIGN_PROCESS` | 从召集台问题到 PRSE-OS 的完整演进与关键修正 |
| `03_HARNESS_ADAPTER` | 与任意本地 Harness 对接的运行契约 |
| `04_SKILLS` | 可路由的方法程序与 Skill 契约 |
| `05_CONTEXT_PACKS` | 知识包类型、Schema、路由和冲突规则 |
| `06_VALIDATORS` | 校验器、独立性政策与结果格式 |
| `07_ARTIFACTS` | 方法运行产生的标准对象与模板 |
| `08_QUALITY_GATES` | 质量门、成熟度、停止条件和发布准入 |
| `09_OBSERVABILITY` | 方法事件、指标、面板和故障定位 |
| `10_TESTS` | 一致性、盲交、变更传播和语言漂移测试 |
| `11_SUMMON_REFERENCE` | 召集台第一份参考实现和原始研究材料 |
| `12_ROADMAP` | 方法研究、工程实现与采用路线 |
| `13_ARCHIVE` | v0.1/v0.2 原始版本及发布包 |
| `14_PROJECT_TEMPLATE` | 新产品接入 PRSE 的空白工程模板 |
| `15_TOOLING` | 离线校验、清单生成和项目初始化工具 |
