# Release Notes v0.7

## 研究焦点

- 将应用目标聚焦到超级个体与 OPC，同时保持理论对更大组织和多主体系统的可扩展性；
- 将研究对象从狭义 A2A 提升为“当 Agent 成为世界行动主体时的主权代理操作系统”；
- Agent Entity 被定义为外部连续、可认证、可追责，内部允许多人、多角色、多模型、多工具和多个局部权威的操作边界；
- 每轮唯一主论文成为理论、证据、系统与反驳条件的累积载体。

## 理论与系统

- 提出从身份/权威根、Mandate、本地世界编译、机会发现、机制选择、关系形成、能力组装、承诺、Operation/Effect、Adoption/Acceptance、学习到 Reopen 的十二阶段全流程；
- 形成八类协调机制组合器：自执行、确定性服务、平台市场、中心优化器、人类经纪、双边形成、临时联盟和人工裁决；
- Router 输出机制序列或机制图，不输出“去中心化程度”；
- 保持六类 canonical roots，不因 OPC 或 QDR 结果继续增加协议本体；
- 把“做不了”转化为可执行的构成过程：诊断缺失条件、提出最小反条件、补工具/伙伴/训练/授权/任务重构、运行可逆 probe、形成新版本、局部编译或重开。

## 新证据与实验

- QDR：52 份访谈、3 份工作簿；自动筛查与单分析者审计仅用于结构校准，不作为 OPC 频率或因果证据；
- QDR 工作簿：18 个流域出现 15 种配置，顾虑最近邻仅 1/18 复现同配置；
- 11 个盲化历史截点：authority-aware 诊断实现高召回，但无精确维度集合命中，因此只能用于 probe 排序；
- 七案三机制 Replay：版本化权威图保留全部编码信息；该结果来自表示同构，不证明决策优越或净价值；
- 24 个构造 OPC fixtures：五轮失败推动 Router 增加资源预留、争议冻结、版本保存、Effect/Acceptance 分离、pre-effect validation 与多地权威 Gate；最终 24/24 只代表构造一致性；
- 90 项双人盲化编码器材已生成，但尚无独立 kappa。

## Fieldkit v0.7

- 新增 OPC Operating Envelope、Coordination Context、八机制 Router、五维 Stability Vector、Enactment Assurance、frame inheritance、Mandate 撤销、精确版本 Stance、证据哈希与 scoped reopen；
- 31 项单元测试通过；
- 仍不是生产安全系统，缺少正式身份、加密资产托管、法律签署和完整连接器。

## 数据发布纪律

QDR 下载数据及逐字段/逐字派生材料不进入可分享研究包。包内保留代码、汇总结果、方法和生成器；合法取得 QDR 数据的研究者可以本地重建受限材料。

## 尚未完成

- 双人独立编码尚未执行；
- 没有真实 OPC 对 Agent Mandate、explain-back 和 Acceptance 的前瞻性证据；
- 没有相对优秀人类经纪与强中心 Agent 的因果净价值比较；
- 24 个 OPC fixtures 为理论构造样本，不是现实分布；
- Fieldkit 尚未完成 v0.8 的 probe ranking、资源预留执行、A2A/MCP/OAuth 连接器与真实 Effect connector。
