# Formation and causality

## Before interaction

Composite source/locator identity was already reachable: the static builder
found it, and a hidden branch pre-existed. Owner B's fixed central report already
contained the null-source/no-wildcard rule. Owner A's fixed report already
contained the incompatible global-compatibility rule.

Therefore the core engineering fix and core value conflict were present before
direct interaction. They cannot be credited as uniquely created by A2A.

## What interaction changed

Direct interaction changed the explicit contract trajectory:

1. B's veto caused A to replace global fallback with a null-source class.
2. B's remedy objection caused A to add an infeasibility trigger and
   severability.
3. A's mutual lapse caused B to articulate an entitlement floor, disclosure,
   contestability, and reopening.

These are real normative condition changes, not synonyms. They remained
unaccepted and unimplemented.

## Ablation and alternatives

- Static/no interaction: found the main code defect and most visible surfaces;
  did not resolve the owner value conflict.
- Fixed central queries: exposed both conflicting policies without adaptive
  messaging.
- Direct A2A: refined the conflict and recovery regime, but did not converge.
- Hidden implementation: operationally complete for wildcard compatibility,
  but does not adjudicate null-source safety.
- Executable counterfactual: proves the A2A clause changes real behavior and
  breaks existing acceptance.

Two independent reviewers rejected a strong formation-success conclusion. See
[blind review](independent_reviews/blind_mechanism_review.md) and
[oracle-aware review](independent_reviews/oracle_aware_engineering_review.md).

## Alternative explanations

Retained:

- discovery of a pre-existing composite key;
- specification elaboration;
- conflict revelation from pre-authored private requirements;
- central sufficiency with a runtime failure;
- target-value tradeoff rather than technical infeasibility.

Rejected:

- pure language restatement: the null-source and lapse clauses change executable
  behavior and rights;
- completed formation: no signatures or adoption;
- goal-preserving success: A's compatibility value was narrowed and B had not
  accepted the final mechanism.

## Evidence grade

E3 local mechanism-related evidence:

- real model calls and refusals/counters;
- functional context separation;
- frozen paired baselines;
- executable bidirectional counterfactuals;
- independent blind and oracle-aware review.

The ceiling remains below E4 because the model family, trusted root, repository,
and synthetic authority were shared; there was no cross-environment or
independent target owner adoption.

## Next discriminator

First determine the actual mixed legacy state and an authorized acceptance
predicate. Then compare a short/streaming central synthesis with an A2A contract
on the same measured corpus. To test structural necessity rather than
specification quality, select a task whose authority or liability cannot be
safely delegated to one root.
