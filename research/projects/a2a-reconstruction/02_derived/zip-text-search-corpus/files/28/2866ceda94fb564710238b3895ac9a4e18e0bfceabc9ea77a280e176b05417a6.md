# v0.4 Release Notes

## 研究变化

- 将研究对象收敛为“不可折叠权威条件下的共同可行动关系形成”；
- 将“关系语法”操作化为 `Relation Schema Γ=<R,V,T,A,E,D,O>`；
- 明确参数变化、非实质模式变化和实质模式变化；
- 定义局部稳定、最小权限编译和依赖闭包 reopen；
- 将 Agent Entity、Principal、Authority Locus、Mandate 和 Execution 分离；
- 将系统目标从成交率改为稳定处置真实性；
- 定义 strict formation 与 CollapseSafe 的可反驳条件。

## 本体变化

默认长期 aggregate root 收敛为：

```text
Entity
Mandate
RelationVersion
Assertion
Commitment
Operation
```

`UsageGrant`、`DataUseEvent`、`DerivationRecord`、`JointArtifactRights` 和 `LearningUpdate` 的语义被保留，但依据独立权威、生命周期和外部引用条件决定是否物化。

## 证据变化

- 用统一标准重审早期协议、第二轮、R5、R5.2、R5.4 与 R5C；
- 重新运行可得的历史 verifier；
- 用户口述八组合成实验因缺少当前可重跑原始实现而降级为 reported evidence；
- v0.3 的 180,000/210 万级实验因当前工作树只含报告而降级；
- 新增本体收敛和 Relation Schema materiality 两项可复现实验；
- 明确所有合成实验只承担机制压力测试，不能替代真实 Principal。

## 工程变化

- 新增 Towow Fieldkit；
- 新增哈希链事件、私有前态、Mandate、RelationVersion、schema change、compile readiness、裁决、指标和 redacted export；
- 新增 11 个单元测试；
- 新增一个虚构企业 AI 只读试点样例：2 个关系版本、21 个事件、4 个权威域；
- 新增 R7 真实主体实验协议、Owner 手册、招募脚本和七份表单。

## 尚未完成

- 没有执行真实 Principal 实验；
- Fieldkit 没有加密、正式身份、法律签署或生产权限控制；
- Relation Schema 的现实编码一致性尚未测试；
- Mandate 撤销、依赖闭包 reopen、附件证据和盲化工具仍待补；
- 现实净价值、长期接受、权力不对称和第三方外部性仍为开放问题。
