# Towow SJAC / Boundary-Oracle Coordination Reference Engine

This research implementation accompanies the second-round Towow A2A papers.
It demonstrates three core ideas:

1. A joint-action candidate is coordinated through sovereign local boundary
   oracles rather than by centralizing full private contexts.
2. Hidden local contribution modes can be discovered through a
   column-generation-inspired protocol instead of static profile search.
3. A candidate arrangement cannot create an external obligation until a
   separate delegation and trust-adapter path compiles it into a commitment.

The package is deliberately small. It is not a production protocol, legal
contract engine, privacy system, or secure distributed implementation.

Run tests:

```bash
cd code
pytest -q
```

Run experiments from the repository root:

```bash
python experiments/run_all.py
```
