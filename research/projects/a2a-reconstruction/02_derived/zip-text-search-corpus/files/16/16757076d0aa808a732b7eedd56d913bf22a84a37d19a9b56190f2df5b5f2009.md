# Open re-review 05 — local source freeze

## Verdict

`PASS` for the explicitly bounded local synthetic source interface.
`COUNTER` for production extrapolation.

The reviewer independently exercised localhost HTTP from a separate process:

- a lost `/run` response recovered the prepared operation through the
  pre-existing session and operation ID;
- expired claim leases redelivered the same event identity with a new token;
- public readback contained only coarse source-owned state;
- cancellation after ack appended `revoked@revision 2` with complete lineage;
- service restart preserved canonical state and pending correction.

The reviewer also ran 14 focused probes. The decision is based on the HTTP and
restart evidence, not the green count.

## Frozen boundary

- ProductShell's policy is synthetic automatic adoption: submitting a task
  pre-authorizes automatic review/adopt on recovery. This is not a human
  preference or Agent World adoption.
- Recovery authority lasts only as long as the 24-hour HttpOnly consumer
  session. A lost/expired cookie does not provide long-lived recovery.
- The authority is single-host files plus a shared local World bearer.
- The HTTP source is ready for an independent Agent World consumer to
  implement; this review does not prove that World has adopted it.
- Process restart and fsync+rename paths were checked; SIGKILL at individual
  syscalls and actual power loss were not.

No production, real-tenant, key-rotation, cross-host, human-acceptance or
business-value claim is permitted.
