# 公开现实证据路线：执行结论 v0.5

**状态：已完成事件级过程深描、最大差异档案校准、文档消融与三项 Fieldkit Shadow reconstruction；不是 live Agent experiment。**

## 研究为什么可以继续，而不必被动等真人资源

公开资料不能替代真实 Principal，但能先解决大量更基础的问题：我们的 Schema 是否装得下现实过程；哪些变化真正改变权威、权利、证据和结果路径；什么情况下 Effect 之后仍会 reopen；哪些输入只是压缩叙事；哪些理论在监管、交易和采购争议中会立即遭遇反例。

本轮因此把公开材料从“相关工作”提升为正式的**档案校准层**，并要求每个材料只承担与其可观察结构相称的主张。

## 两项互补研究

### R7P-1：过程深描与文档消融

- 3 个案例：LinkedIn–Microsoft、Amazon–iRobot、NASA HLS；
- 33 个来源可定位事件；
- 33/33 可映射到 `Γ=<R,V,T,A,E,D,O>`；
- 28/33 达到当前操作完整标准；
- 压缩公告流严格事件召回 18.2%，部分计权后 25.8%；
- 关键转折加权召回 25.0%。

它证明的不是七维完备，而是当前没有出现必须增生第八维的结构残差。NASA HLS 作为负控制说明：影响巨大或结果意外不等于 material schema change；若制度已预留 contingency，变化可能仍在既有模式内。

### PEA-10：最大差异、反例与硬性未发现

- 10 个案例：4 个 SEC、3 个 CMA、3 个 GAO；
- 主要修订类型：1 Expansion、3 Transformation、5 Protective contraction、1 Clarification；
- 外部 Authority 改变路径：7/10；
- tentative state 后 challenge/reopen：6/10；
- 证据门失败：3/10。

这些计数只描述有意选择语料，不是总体频率。

硬性未发现：Agent 因果贡献、条款级主观 explain-back、与优秀中介可比的净协调剩余，直接观察均为 0。因此 C18、C19、C20 继续为 `UNKNOWN`。

两项研究合计覆盖 12 个不重复现实事项。LinkedIn–Microsoft 同时出现在两种设计中，用于跨设计对照。

## 三项 Shadow reconstruction

Microsoft–Activision、Meta–Giphy、Deloitte 被事后重构为 Fieldkit 案例：

- 7 个 RelationVersion；
- 4 次版本转换，全部判为 material；
- 17 个哈希链事件；
- 3 个案例结构验证全部通过；
- readiness 序列分别为 `NOT_READY→READY`、`NOT_READY→NOT_READY→READY`、`READY→NOT_READY`。

这证明的是当前 Fieldkit 能表达公开历史中的外部 jurisdiction、权利重构、Effect 后 reopen、能力依赖失效和 scoped Settlement；不是“如果用了 Towow 就会更好”的反事实。

## 对理论的直接改变

1. 形成从“路径扩张”修订为“合格联合行动空间的 Expansion、Transformation 或 Protective contraction”；Clarification 单列。
2. Settlement 改为带 RelationVersion、jurisdiction、standing、challenge horizon 与 evidence state 的派生视图。
3. Authority topology 从主体计数改为功能图；同一信任根内 proposal、approval、execution、witness、acceptance 仍可分离。
4. evidence admissibility / version incorporation 被加入证据语义：知道某信息不等于它已被当前 RelationVersion 正式采用。
5. Source provenance 进入 Assertion assurance，但不新增 SourceRecord aggregate root。

## 对 Fieldkit 的直接改变

- `standing_rules`、`jurisdiction_rules`、`challenge_rules`、`settlement_rules` 成为 materiality 组件；
- compile readiness 检查 required/covered jurisdictions、external standing、open challenges 与 challenge horizon；
- 新增 `READY_WITH_CONTINGENCY`；
- 编译器不得凭空创造 jurisdictional clearance 或 Settlement；
- v0.5 共 15 项单元测试。

## 公开证据可替代和不可替代的部分

它可以替代 R7-0 历史校准的一大部分：真实 Schema 变化、Authority、Effect、负结果、challenge、reopen、证据门与事件类型缺口都能先做。

它不能替代 R7-A 的核心变量：live Mandate、真实 explain-back、偏好发现/形成/投射、认知与隐私负担、Agent 因果贡献、与优秀经纪人的净价值，以及长期 Acceptance。
