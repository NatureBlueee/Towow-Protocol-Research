# R7 参与者操作清单

## 参与前

- [ ] 我知道这是一项研究，不保证促成合作；
- [ ] 我知道 Agent 只在我明确授权范围内行动；
- [ ] 我可以拒绝问题、拒绝操作、撤销 Mandate 或退出；
- [ ] 我知道私有材料和共享材料会分开存放；
- [ ] 我知道共享自由文本仍可能包含身份信息，公开前需要另行审查；
- [ ] 我已确认现实 probe 是低风险、可逆或可补偿的；
- [ ] 我已明确哪些决定是我的权限，哪些不是。

## 私有前态访谈

- [ ] 用自己的话描述目标；
- [ ] 标明硬约束、软偏好和未知；
- [ ] 列出真实可用的资源和能力；
- [ ] 指出不能共享的内容与可共享投影；
- [ ] 写出当前最佳替代方案；
- [ ] 写出退出条件；
- [ ] 确认前态在协调前被冻结。

## Mandate

- [ ] Agent 可以披露什么；
- [ ] Agent 可以询问什么；
- [ ] Agent 可以直接拒绝什么；
- [ ] Agent 可以提出哪些反条件；
- [ ] Agent 可以承诺的金额、资源、时间和风险范围；
- [ ] Agent 可以执行的动作；
- [ ] 必须升级给我的事项；
- [ ] 授权有效期与撤销方式；
- [ ] 数据用途、保留、训练和再披露边界。

## 每个 RelationVersion

- [ ] 我看到的是一个精确版本；
- [ ] 我能用自己的话解释其关键内容；
- [ ] 我知道自己认领了什么；
- [ ] 我知道自己没有认领什么；
- [ ] 我的条件和退出路径已记录；
- [ ] 新版本没有偷偷扩大我的权限或责任；
- [ ] material change 已重新征得必要权威 Stance。

## 现实 probe

- [ ] probe 解决的是会改变设计的未知，而不是形式演示；
- [ ] 输入、权限、时限和停止条件已确定；
- [ ] 目标世界的 Effect witness 已指定；
- [ ] 数据和派生物的用途已指定；
- [ ] 失败后的撤回、清理或补偿已指定；
- [ ] 我批准的是本次 probe，不是无限授权。

## 结果与 follow-up

- [ ] Operation、Effect、Adoption 和 Acceptance 没有被合并；
- [ ] 我独立作出 Commit/Reject/Conditional/Unknown 等 Stance；
- [ ] 我说明了理由和未解决问题；
- [ ] 我将在 T+7/T+14/T+30 更新后悔、新 Defeater 和结果状态；
- [ ] 我可以对记录中的误代表提出争议或更正。
