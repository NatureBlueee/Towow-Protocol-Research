# Open re-review 03 — third Allbuddy source implementation

## Verdict

`BLOCKED`. The implementation demonstrated a real local happy path, but it
could not yet be frozen as an independent Agent World source interface.

This review was intentionally open: the reviewer was not given the two earlier
defect lists and was asked to search beyond the existing green tests.

## New Defeaters

1. **First-response recovery was not real.** `/workspace/run` persisted the
   record but first issued the HttpOnly session capability in that same
   response. If the response was lost, the browser could not authenticate
   recovery. Later review/adopt/readback network failures also fell into a
   generic UI failure path that deleted the local operation marker.
2. **Abort could be inverted into adoption.** Explicit abort/reset/role switch
   did not delete the pending operation marker. Reload would automatically
   review and adopt a still-`prepared` record.
3. **A crashed lock holder permanently blocked the reference.** An orphan
   `open("wx")` lock made every later operation wait about ten seconds and
   return unavailable.
4. **Revision operation replay was not exact.** Reusing an old operation ID
   ignored its original `expectedRevision` and state, then returned the latest
   revision rather than the original result.

The review also identified interface-freeze risks that were not required to
establish the four minimal Defeaters: same-session prepare input confusion,
latest-only readback for queued historical deliveries, same-`worldId`
concurrent lease ambiguity, lack of an actual independent HTTP World consumer,
and no production-level fsync/IAM/HA proof.

## Positive evidence retained

- target unit suite, typecheck and lint passed before the open review;
- one real ProductShell + HTTP browser happy path passed;
- the normal path persisted Artifact before adoption, wrote adoption and
  outbox together, retained all concurrent records, and excluded the private
  sentinel from public readback.

These facts establish partial local capability, not interface freeze or
production fitness.

## Required discriminator

The next source candidate must demonstrate:

- session authority established before a recoverable run;
- response-loss retry without deleting the operation marker;
- explicit abort that cannot later become adoption;
- orphan same-host lock recovery;
- exact operation replay and revision-specific readback;
- lease ownership that distinguishes concurrent consumers;
- a fresh open re-review after these conditions pass.

Production extrapolation remains prohibited.
