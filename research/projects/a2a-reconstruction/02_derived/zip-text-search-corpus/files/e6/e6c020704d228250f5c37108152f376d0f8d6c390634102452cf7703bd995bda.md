# 返回包证据审计说明

- 原 tar 包包含 macOS AppleDouble `._*` 元数据文件。
- 原 verifier 会把 `SOURCE_PATCHES/._*.patch` 误判为源码补丁，因此在 Linux 环境直接失败。
- `MANIFEST.sha256` 和 `RETURN_MANIFEST.json` 不包含这些 AppleDouble 文件。
- 删除纯元数据 `._*` 后，原始 verifier 通过：

```text
R5C-RETURN-001: OK (files=90, claims=19, local_links=36)
```

- `sha256sum -c MANIFEST.sha256` 全部通过。

判断：这是仓库打包／跨平台可搬迁缺陷，不影响受清单保护的研究内容完整性，也不应升级为通爻核心理论结果。后续打包流程应在生成 Manifest 前清除 AppleDouble 元数据或让 verifier 明确忽略它们。
