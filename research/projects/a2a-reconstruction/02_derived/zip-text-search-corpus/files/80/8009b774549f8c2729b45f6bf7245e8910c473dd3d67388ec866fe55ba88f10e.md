# IF-3 · 算子契约规格 v1.0（已冻结）

**层级：** 接口冻结层三件套之三。交叉检查已通过，本文为v1.0冻结版。
**设计意图陈述：** 协议管边界不管路径（D4）：本契约约束的是"什么样的比较可以在网络中流动并被中继安全转发"，绝不约束端侧如何思考。工程师遇到未覆盖情形按此意图外推：**凡影响中继决策的运算必须带可验上界与有界成本；凡只在端侧执行的运算给予完全自由。**

## 1. 评分语义（全网统一基准）

**坐标语义**：facet坐标分量为内容对锚点的余弦相似度，逐分量∈[-1,1]，**不做向量级归一化**（前缀截断保语义的前提，见IF-2§3修订）。

**基准评分（k级）**：对查询面q与目标面b（语法角色互向：SEEK对OFFER），
```
score_k(q, b) = (1/k) · Σ_{i<k} q_i · b_i ，k = min(prefix_len_q, prefix_len_b)
```
性质：对b线性；值域[-1,1]；跨k近似可比；阈值表按k分级声明（锚点集版本发布物携带）。

**W核评分**：`score_k(q,b;W) = (1/k) · (W_kᵀ q_k) · b_k`，其中W_k为W的k×k前主子块。
- **查询侧折叠**：q′=W_kᵀq_k每查询每级仅算一次；在线比较仍为单次内积成本。
- **谱范数约束**：‖W‖₂ ≤ 声明上界（W版本发布物携带），保证评分值域受控；Guard机械校验。
- **嵌套感知要求（对M5的强制）**：W的训练目标必须使各前主子块独立可用（度规继承嵌套纪律），否则粗筛级使用W即未定义行为。
- **中继度规不可知不变量（I-O1）**：W仅折叠于查询侧；包络与一切中继状态约束原始b，**W版本更新不得要求任何中继状态变更**。剪枝健全性与W无关；W进化只影响聚类效率（R6侧），不影响漏检（R7侧）。

## 2. 算子两级分类（契约的核心切分）

**可路由算子（routable）**：参与传播过滤、其判别值可被中继转发的算子。准入四性质：
- P1 **成本上界**：单次评估O(k)且常数声明；超时即违约。
- P2 **盒可界性**：算子必须随附健全上界函数`UB(query_state, Box)`，满足 ∀b∈Box: score(q,b) ≤ UB；无UB者不得路由。基准评分与W核评分的UB见§3。
- P3 **披露单调性**：对同一对象，等级n+1信息下的判别力不劣于等级n（认证电池验证，见§4）。
- P4 **纯函数性**：同输入同输出，无副作用、无外部调用。

**端侧算子（endpoint-only）**：在包络路由送达后、于端侧自由执行的任意运算——含LLM判断、合取谓词、多面组合、私有模型。**零契约约束**（A1/D4），唯一要求：其结论若回流网络（如反对、拒绝、接受），以IF-1的类型化事件表达。
合取语义的标准落法：合取拆多探针OR路由保召回（每个析取支一支探针），AND收敛在端侧算子与quest完成（C8/R2结案口径：任意表达性由动词编排满足，不由信号对象单独满足）。

## 3. 包络代数（中继的全部数学）

**盒**：`Box_k := { lo[0..k), hi[0..k) }`，逐锚点维的min/max，覆盖子树内全部在册面坐标。
**上界函数（基准/W核通用，q′为折叠后查询）**：
```
UB_k(q′, Box) = (1/k) · Σ_{i<k} ( q′_i ≥ 0 ? q′_i·hi_i : q′_i·lo_i )
```
健全性：线性泛函在盒上的最大值逐维可分；盒⊇成员集 ⇒ UB ≥ 成员真最大。**剪枝规则**：UB_k < 阈值_k ⇒ 整支剪除，零漏检。
**合并代数（聚合封闭，R10）**：`merge(Box_a, Box_b) = { min(lo_a,lo_b), max(hi_a,hi_b) }`——交换、结合、幂等：(Box, merge)为并半格，多跳合并次序无关；UB随merge单调不减 ⇒ 任意层级剪枝健全。
**I-O2 单调加宽铁律（健全性的时间维）**：成员坐标更新生效前，其到根路径上所有盒必须**先完成加宽**并确认；收窄仅允许后台惰性执行。违反此序的实现，零漏检保证作废。盒携带`widen_seq`确认号，审计可重放校验。
**I-O3 盒的W无关性**：盒约束原始b空间；任何把W折入盒侧的实现违约（破坏I-O1）。
**剪枝效率仪表**：`剪除率@零漏检`为overlay语义聚类度的标准度量，供M5拓扑学习作目标函数（效率问题，永不与健全性交易）。

## 4. 注册、认证与吊销

**注册件**：`{ operator_id, class: routable|endpoint, facet_pair, k_levels, score_fn_ref, UB_fn_ref(routable必), cost_decl, version, signer }`。
**认证电池（Guard执行，机械化）**：
- 成本：基准硬件上抽样计时≤声明值。
- 盒可界：随机盒×随机成员抽样，UB违例零容忍（一例即拒）。
- 披露单调：标注对上各等级ROC，等级序必须支配（允许统计噪声带，阈值由版本发布物定）。
- 纯函数：重放一致性抽查。
**吊销**：违约证据（UB违例/超时/副作用）触发版本吊销事件；在途match_context按其打开时的算子版本钉死（版本钉扎），新context不再可用。
**W版本治理引用**：W按J1（匹配几何宪法，呈批中）与锚点同流程版本化；本契约只消费其发布物（W_ref、谱范数、嵌套认证、k级阈值表）。

## 6. 形式化附录（健全性证明梗概）

UB健全性：score_k(q′,b)=(1/k)Σq′_i b_i，对每i独立有 q′_i b_i ≤ max(q′_i lo_i, q′_i hi_i)（b_i∈[lo_i,hi_i]，线性函数端点取极值）；逐维求和除k即得UB≥score对盒内任意b成立；盒⊇成员集由I-O2维护 ⇒ 对任意在册成员成立。∎
合并健全性：lo逐维取min、hi逐维取max ⇒ merge后盒⊇两子盒并集⊇全部成员；半格性质由min/max的交换结合幂等直接继承。∎
