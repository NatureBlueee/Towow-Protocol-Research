# Live Cross-Repository Formation Episode

## Scope

- date: `2026-07-25`
- source process: Allbuddy Next.js on `127.0.0.1:3127`
- source store: isolated temporary single-host store
- consumer: ProductShell synthetic automatic-adoption policy under a
  pre-established HttpOnly consumer session
- target process: separate Agent World Node 24 driver
- target store: fresh in-memory semantic store reconstructed from an isolated
  durable World journal on every invocation
- production effects: none

Only opaque references, coarse readbacks and World semantic identifiers are
recorded here. The Artifact body, cookie, bearer, lease token and reader
capability are excluded.

## Initial unreachable state

Before the model-principal episode, Allbuddy producer `completed` was not a
canonical consumer fact, ProductShell Artifact adoption lived in React memory,
and Agent World had no accepted external-source path. Giving World the private
Artifact would violate disclosure; letting Allbuddy self-author a World
projection would collapse independent authority.

## Formed arrangement

The two model principals converged only after repeated local Defeaters on:

- file-ledger concurrency;
- response-carried authority;
- response-loss recovery;
- browser impersonation of World;
- orphan process locks;
- revision replay;
- adoption-response/abort races;
- World restart and semantic cut points.

The final arrangement separated producer completion, consumer authority and
World presentation. It used:

- pre-established consumer session;
- review and canonical read-after-write;
- monotonic `adopted/not_adopted/revoked` revision lineage;
- durable source claim/readback/ack;
- six-field coarse readback;
- World journal-before-ack;
- commandless source-authoritative C2 EventRecords;
- one stable claim entity and one stable C4 projection;
- explicit offline/unknown and disputed states.

## Counterfactual removals actually run

### Producer-only

A distinct `drawing-retrieval` run returned producer `completed` and an
adoption offer, but no consumer decision was made. A fresh World journal and
authorized driver produced:

```text
processed=0
adapterSnapshots=0
eventRecords=0
entities=0
worldProjections=0
sceneDeltas=0
```

### Wrong World authority

The same source was queried with an incorrect World claim bearer. The
non-enumerating interface returned no deliveries and a fresh World journal
remained 0/0/0/0/0.

### Source unavailable

Stopping the actual source process first exposed a missing TCP-error handler.
That Defeater was fixed. The repeated real process test then produced an
offline/unknown update without advancing source state or source revision.

### Private payload

Searches over both live and holdout World journals found none of the Artifact
title/query/customer text, Artifact/task ID, consumer session, World bearer,
lease token or reader capability. A separate test injects a private sentinel
as an extra readback field: the field is rejected, not journaled, and an
existing projection is downgraded to stale/unknown.

## Open re-review Defeaters and repairs

The first post-implementation World-principal review returned `COUNTER` despite
50 passing tests. It independently reproduced:

1. missing SceneDelta still returning `ackReady`;
2. HTTP 200 with `acknowledged:false` being marked confirmed;
3. `ack_confirmed` regressing to `ack_pending` on replay;
4. malformed/private readback leaving old adopted as current;
5. authorized source Viewer projecting into an unrelated target Viewer.

The implementation now repairs a delta-missing cut point before ack, requires
an explicit positive ack body, preserves ack confirmation, persists
stale/unknown or disputed observations without private bytes, binds the source
viewer to the one R5C target viewer before any replay, and freezes
`(reference, revision)` to one canonical event/readback identity across all
journals. Fresh reconcile preflights the same identity invariant before any
store mutation. Focused plus package tests rose to 58/58.

## Acceptance and nonclaims

Acceptance achieved:

- the Allbuddy synthetic consumer source canonically adopted/revoked/re-adopted;
- the independent World target ingested and projected the coarse source report;
- the World target survived fresh-process replay;
- key condition removals eliminated or downgraded the outcome.

Acceptance not achieved and not claimed:

- real human/customer preference;
- Artifact correctness or business value;
- production identity, IAM, HA or multi-host durability;
- full Agent World pipeline persistence;
- a general A2A capability.

## Design Delta

The formed capability is not “send a receipt”. Authority delivery is part of
the source capability: session establishment, recovery, canonical readback,
monotonic cancellation, lineage, claim/persist/ack and epistemic downgrade must
be designed as one cross-principal operation. World must verify the complete
semantic postcondition before acknowledging transport.
