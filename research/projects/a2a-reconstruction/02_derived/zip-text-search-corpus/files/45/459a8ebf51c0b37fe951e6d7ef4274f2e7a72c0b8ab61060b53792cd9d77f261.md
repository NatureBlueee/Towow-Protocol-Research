# 资料覆盖范围与已知缺口

## 1. 覆盖声明

本交接包汇集的是**当前运行环境中可取得的全部通爻/A2A/Harness/PRSE 相关研究资产**。它包含原始上传归档、解压材料、同行研究、多个本地现实返回包、旗舰实验首席吸收、现有统一论文及其证据账本。

它不是完整聊天记录导出，也不能保证包含历史会话中所有曾经生成、但未保存到当前文件系统的中间文件。

## 2. 已包含的主要资产

### 2.1 原始设计与方法基础

- 通爻协议设计语料库 v1.5 终包；
- Flowness Harness Cognitive Engineering v0.1；
- PRSE-OS v0.3-dev；
- 相关召集台资料和方法档案（随 PRSE 包）。

### 2.2 同行与第二轮研究

- 同行第二轮完整研究包；
- 两篇同行论文、合订本、图、实验结果和参考引擎。

### 2.3 本地现实实验与返回包

- R5.2 Harness Reality Transfer 返回；
- R5.4 真实模型协商返回；
- R5C 旗舰建设性跨技术域返回；

### 2.4 当前统一成果

## 3. 没有独立保留、但已被后续材料继承的内容

当前文件系统中没有以独立原始归档形式保留某些中间阶段的全部 standalone 论文和代码包，例如部分第三、第四阶段原始交付目录。它们的主要结论、对象和实验通过以下材料被继承：

- 当前统一论文；
- Claim–Evidence Register；
- Concept Decision Ledger；
- R5.2 / R5.4 / R5C 返回包；
- 旗舰实验首席吸收；
- 后续任务包中的 Current System 和 Research Map。

新研究员应当将这些继承材料视为**二次表示**，而非等价于原始全文。如果用户或其他存储位置仍保有 R3/R4 原始包，建议补入 `supplemental_sources/`，再重新校验主张谱系。

## 4. 未包含的聊天内容

本包不包含完整对话逐字稿。已通过交接文档保留的内容包括：

- 研究元问题；
- 关键概念演化；
- 主要理论修正；
- 现实实验的首席解释；
- 用户对最终统一论文的要求；
- 最新三维统一模型假说。

但原始语气、未成文的细节和部分探索过程可能未完全保留。若新研究员需要验证某一概念为何出现，应优先查找对应阶段原始文件，而不是仅依赖本交接摘要。

## 5. 文件重复与清理原则

全量包同时保留：

- 原始 ZIP/TAR.GZ；
- 便于检索的解压资料。

这会产生一定重复，但具有以下价值：

- 原始归档可验证来源和完整性；
- 解压资料便于全文搜索、阅读和代码审计。

在解压副本中已排除 macOS `._*` 和 `__MACOSX` 元数据；原始归档未被改写。

## 6. QA 文件

现有统一论文目录中的大批页面渲染 PNG 和联系表不进入核心研究资料，仅保留最终 PDF/DOCX 和必要源稿。原因是：

- QA 渲染用于视觉检查；
- 不包含额外理论证据；
- 会显著增加包体积。

如需重新排版，可从 DOCX/PDF 源重新渲染。

## 7. 安全与隐私

当前归档主要是研究材料、代码、实验日志和任务包。新研究员仍应检查：

- 是否包含真实密钥、Token、客户数据或个人信息；
- return packet 中的工作区路径是否需要脱敏；
- 代码补丁是否包含不应公开的仓库细节；
- 对外发布前是否需要生成单独的 public release。

本交接包是研究内部交接制品，不自动等于公开发布包。
