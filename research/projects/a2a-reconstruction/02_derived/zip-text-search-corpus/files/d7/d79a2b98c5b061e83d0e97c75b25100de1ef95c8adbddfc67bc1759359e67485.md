# 通爻 A2A：当前整体研究判断 v0.5

## 一句话定义

通爻研究的是：

> 当多个不可互相代行的实体拥有私有、变化且不能被一个中心无损复制的世界，并分别控制事实、资源、工具、权威、责任与接受权时，怎样构成并持续修订一个**合格的联合行动空间**，使一项关系能够被发现、解释、拒绝、重构、认领、承诺、执行、见证、采用、接受、挑战和局部重开。

这里的 Agent-to-Agent 不等于两个模型互发消息。Agent Entity 是一个对外可认证、可归因、具有连续性和治理入口的实体包络；内部可以是人、组织、模型、工作流、工具、预算、委员会和无法完全数字化的现实判断。A2A 是否必要，取决于权威、责任、信息边界、退出权和接受权能否被一个中心无损代行，而不是部署拓扑是否分布式。

## 1. 本轮为什么不是“找论文补引用”

外部参与者暂时难以获得，不意味着只能继续做合成实验。公开世界已经留下大量不完整但正式的现实观测：证券披露中的交易形成过程、监管机构的第三方证据与裁决、政府采购争议、控制型人类谈判语料和开放专家访谈。

本轮没有把这些材料当成真人实验替代物，而是把它们按可观察结构拆开：

- 正式档案观察真实 Authority、RelationVersion、Effect、challenge 和外部处置；
- 谈判数据观察隐藏偏好、理由披露、NoDeal 和 readback，但其关系规则通常预先固定；
- 访谈观察内部流程与未对象化知识，但不能自动证明现实 Effect；
- 新闻稿/企业介绍作为压缩投影，用于测试信息遗漏。

因此，公开证据承担的是**现实结构校准**，不是 Agent 因果效果证明。

## 2. 两项互补的公开研究

### 2.1 R7P-1：三案、33 事件的过程深描

LinkedIn–Microsoft、Amazon–iRobot、NASA HLS 被编码为 33 个来源可定位事件。每个事件记录 actor、Authority Locus、RelationVersion、event type、`R/V/T/A/E/D/O`、materiality、Stance、Effect、unknown 与来源。

结果是：

- 33/33 事件均可映射到既有七维；
- 28/33 在当前编码协议下达到操作完整标准；
- 压缩公告流严格恢复的事件只有 18.2%，部分计权后为 25.8%；
- 对关键转折的加权召回为 25.0%；
- NASA HLS 构成关键负控制：影响巨大、结果意外，不等于 Schema 发生变化；若 contingency 已在制度模式中被保留，它可能只是环境或实例具体化。

这项研究的主要 Design Delta 是：materiality checker 必须识别 reserved contingency；证据必须区分“主体知道”与“已被当前版本正式纳入/可采用”；企业介绍和新闻稿不能被当作主体世界。

### 2.2 PEA-10：十案最大差异与反例搜索

十个公开制度案例覆盖 4 个 SEC 交易过程、3 个 CMA 监管过程、3 个 GAO 采购争议。选择目的不是估计现实频率，而是最大化理论差异与失败门。

首轮主要修订类型为：

```text
Expansion               1
Transformation          3
Protective contraction  5
Epistemic clarification 1
```

在这组有意选择语料中：7/10 出现外部 Authority 改变路径，6/10 在 tentative state 后出现 challenge/reopen，3/10 出现证据门失败。更重要的硬性未发现是：Agent 因果贡献、条款级主观 explain-back、与优秀人类中介可比的净协调剩余，直接观察均为 0。

这些“0”只描述当前材料的可观察性，不能推断现实总体不存在；它们的作用是阻止研究用正式档案冒充 C18–C20 的证据。

## 3. 最重要的理论修订：形成是合格空间修订

定义时点 `t` 的合格联合行动空间：

```text
Q_t = {a |
  Executable(a)
  ∧ ValidlyAuthorized(a)
  ∧ EvidenceQualified(a)
  ∧ RightsCompatible(a)
  ∧ JurisdictionallyAdmissible(a)
  ∧ RequiredStandingAddressed(a)
  ∧ ¬EffectivelyProhibited(a)
}
```

严格形成不再只指“新增一条路径”。它包括：

- **Expansion**：新路径经工具、授权、伙伴、任务重构、现实 probe 或新证据进入 `Q_t`；
- **Transformation**：旧路径退出，新的角色、权利、授权、证据、数据或 Effect path 进入；
- **Protective contraction**：未授权、证据不足、身份不明、依赖失效、向第三方转嫁风险或被有效禁止的路径退出；
- **Epistemic clarification**：认识更清楚，但尚未证明 `Q_t` 改变。

这使“真实优先于成交率”获得可操作含义。NoDeal、Reject、Conditional、Unknown、Disputed 和 Reopen 都可能是正确结果；但保护性收缩仍需比较避免损失、错失机会与治理成本，不能把监管禁止自动写成净福利证明。

## 4. Settlement 必须带范围

当前定义：

```text
Settled(
  RelationVersion,
  JurisdictionSet,
  StandingSet,
  ChallengeHorizon,
  EvidenceState
)
```

Meta–Giphy 一类过程说明，双边所有权 Effect 已发生，仍可能被外部 jurisdiction 重开并要求剥离；Microsoft–Activision 说明，原交易被禁止后，只有改变权利对象、角色与监管条件的新交易路径才可能进入现实；Deloitte 采购争议说明，团队成员移除后，原能力证据不能静默继承。

因此：

```text
Attempt ≠ Effect
Effect ≠ Adoption
Adoption ≠ Acceptance
Bilateral completion ≠ global Settlement
```

standing、jurisdiction、challenge 和 Settlement scope 被加入 Relation Schema/Fieldkit 的规则与状态，但没有被提升为新的 aggregate root。

## 5. Authority topology：一个主体内部也不能被压成一个开关

公开案例持续出现以下不同功能：

```text
proposal
negotiation
recommendation
ratification
execution
Effect witness
adoption
acceptance
external jurisdiction / standing
```

这些功能可能落在同一组织、同一信任根或同一个 Agent Entity 内，但不能互相代行。系统需要记录“谁对哪个版本、在什么范围、凭什么让哪一步作数”，而不是简单地给组织或 Agent 一个全能认证标记。

## 6. 公开材料促成的本体收敛

本轮没有因为发现更多现实变量而继续增加顶层对象。长期 canonical aggregate root 仍为：

```text
Entity
Mandate
RelationVersion
Assertion
Commitment
Operation
```

- SourceRecord 默认进入 Assertion provenance；
- standing/jurisdiction/challenge 进入 RelationVersion 的 `R/A/T/O` 规则；
- Settlement 是带 scope 的派生视图；
- UsageGrant、DataUseEvent、DerivationRecord、JointArtifactRights、LearningUpdate 仍按风险映射为 Mandate 范围、typed Event、provenance edge、Commitment 或 Effect；只有出现独立权威、生命周期、撤销、争议或跨关系引用时才提升。

这回答了“现实意义是否等于顶层对象”的问题：不等于。

## 7. Shadow reconstruction：规范能否装下现实历史

本轮把 Microsoft–Activision、Meta–Giphy、Deloitte 三案事后装入 Fieldkit：

| 案例 | RelationVersion | 版本转换 | compile-readiness 序列 |
|---|---:|---|---|
| Microsoft–Activision | 2 | 1 个 material | NOT_READY → READY |
| Meta–Giphy | 3 | 2 个 material | NOT_READY → NOT_READY → READY |
| Deloitte | 2 | 1 个 material | READY → NOT_READY |

三案结构与哈希链验证全部通过。这个结果支持 Fieldkit 能表达外部 jurisdiction、Effect 后 reopen、权利持有人变化、能力依赖失效和 scoped Settlement；它不证明原历史过程使用 Towow 会更快、更便宜或更好。

## 8. 当前证据状态

### 已经相对稳定

- 静态投影不能定义开放未来任务的完整行动空间；
- identity、capability、authority、objective ownership 彼此正交；
- Operation、Effect、Adoption、Acceptance 必须分离；
- Relation Schema materiality 是任务相关语义差异，而不是文档 diff；
- 稳定局部应编译成最小权限确定性运行，Defeater 只重开受影响依赖闭包；
- 可折叠任务应使用更简单的中心机制。

### 获得现实结构校准但仍有范围

- 形成包含 Expansion、Transformation 和 Protective contraction；
- 外部 standing/jurisdiction 可以改变或重开双边关系；
- 正确 NoDeal 是合法且可能有价值的制度处置；
- 数据使用可产生新的战略派生信息；
- 同一权威根内存在不同的 authority functions。

### 仍然未知

- **C18：** Agent/Towow 是否因果地形成真实新行动；
- **C19：** 相比优秀经纪人、项目经理或同权限中心 Agent 是否有正净协调剩余；
- **C20：** 真实 Principal 能否理解、自由并范围化地认领精确版本。

公开证据没有、也不应被允许“间接证明”这三项。

## 9. 现在可以继续推进什么

真人资源不再是当前研究的阻塞门。接下来的高信息增量工作是：

1. 将 10 案扩展为 30–50 个最大差异案例，直到连续新增案例不再产生理论或 Fieldkit Design Delta；
2. 对至少 5 案做独立第二编码，并把分歧拆成定义、来源缺失、规范判断和事实读取四类；
3. 完成 archive-to-Fieldkit importer、SourceRecord、Mandate 撤销、精确 Stance 引用与 dependency-closure reopen；
4. 对固定语法谈判语料和开放访谈做相反方向校准，补私有前态、理由和内部流程；
5. 构造静态平台、优秀人类中介、同权限中心 Agent 与主权 Entity 的强反事实基线。

一旦真实机会自然出现，R7-A 只需要针对公开资料无法回答的窄问题：live Mandate、explain-back、主观负担、操纵风险、Agent 因果贡献和净协调剩余。
