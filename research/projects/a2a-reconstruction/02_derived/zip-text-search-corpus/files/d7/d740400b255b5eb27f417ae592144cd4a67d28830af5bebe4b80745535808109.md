## Original value preserved

- Static: aimed at both isolation and compatibility, but canonical shape errors
  made the patch ineffective.
- Central: preserved both owner statements but produced no synthesis.
- A2A: protected B's isolation and remedy, but A's historical-global value was
  narrowed without corpus evidence.
- Hidden implementation: preserved global compatibility but permits a
  source-less event to affect later sourced owners.

No architecture achieved accepted original value.

## Non-model costs

- Disclosure: A2A exchanged two synthetic source identities, the shared locator,
  and owner veto/acceptance conditions. No credentials or raw peer dossiers were
  disclosed.
- Verification: four paired pytest executions, exact/recount patch checks, and
  two independent reviews.
- Rework: static path normalization; root-built counterfactual implementation;
  separate central replication.
- Recovery: Python timezone compatibility, schema compatibility, network
  approval, and two five-minute central failures.
- Human attention: experiment design, interpretation, counterfactual coding,
  and acceptance classification remained centralized in the root researcher.

## Fairness and scope

All main conditions used the same Claude alias and public source. Central saw
only fixed owner reports; direct owners saw only their own dossier plus prior
messages. The central output surface was unusually long and failed twice, so
its synthesis capability is Unknown. It would be unfair to count transport
failure as A2A superiority.

The private contexts and authorities were synthetic and safely collapsible.
This task therefore favors simpler centralized engineering and cannot establish
sovereign A2A's structural necessity.

## Net value judgment

Direct A2A produced useful specification and recovery insights, but those did
not become an accepted action and cost about 2.49 times the static builder
before verification overhead. For this task:

`AcceptedOriginalValue = 0` for every experimental architecture.

With no accepted outcome, A2A's additional model, latency, disclosure, and
verification costs make its observed net value lower than the simpler static
plus owner-query workflow. This judgment is local, not a universal ranking.
