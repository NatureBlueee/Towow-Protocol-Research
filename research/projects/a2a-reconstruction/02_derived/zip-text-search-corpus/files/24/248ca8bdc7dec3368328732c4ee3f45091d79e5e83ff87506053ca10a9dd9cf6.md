# Towow Archival Coder v0.6

这是对公开现实案例进行结构化重编码的最小研究仪器。它不是自动真相提取器，也不决定法律/组织 materiality。

## 输入

每个 `archival_cases/<case_id>/case.json` 包含：

- 来源与证据覆盖；
- institutional/relation frame；
- Authority Locus；
- 时间线事件；
- `R/V/T/A/E/D/O` 变化；
- Formation operator 研究标签；
- Operation/Effect/Adoption/Acceptance；
- 支持、不支持、竞争解释和 Design Delta。

## 运行

```bash
python instrument/archival_coder/validate_cases.py
python instrument/archival_coder/summarize_cases.py
```

## 解释纪律

- 所有案例当前为 `single_coder_provisional`；
- 计数只描述编码，不估计现实频率；
- Formation operator 是研究代码，不是协议对象；
- 只有 source pointer，没有长篇复制受版权保护的材料；
- 未获得原始 transcript 时不得声称完成 transcript-level 研究；
- 任何 treatment-effect 结论都应失败验证，因为这不是干预实验。

## 升级为双人编码

复制 case 文件为 `coder_a.json`、`coder_b.json`，独立完成 timeline 与 authority topology，再生成：

```text
agreement/materiality
agreement/schema_components
agreement/authority_loci
agreement/outcome_chain
adjudication_log
```

不要让第二编码者先读 v0.6 的 Design Delta，以减少确认偏差。
