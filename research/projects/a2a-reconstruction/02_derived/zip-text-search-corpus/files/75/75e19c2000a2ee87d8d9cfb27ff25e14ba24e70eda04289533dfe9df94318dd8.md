# 与本轮方法相关的外部研究线索

这些文献不是通爻的答案，只用于提醒本地研究者现有方法空间，避免重新发明已知机制或把单一方法误当作唯一道路。

- Coactive Learning：系统从用户对候选结果的改进中学习，而不是假设偏好一开始已完整表达。
- Cocoa / interactive plans：复杂任务中共同计划和共同执行可以比纯聊天提供更好的可操控性。
- Mixed-Initiative collaboration：双方都能主动提议、接受和拒绝，并根据能力与可用性动态重新分工。
- Dec-POMDP / partial information sharing：不同信息结构决定中心化表示是否存在及其代价。
- Active-Acquisition POMDP：系统可主动购买或请求信息，并平衡信息成本与决策价值。
- On-demand communication：通信应依据异步状态和边际价值触发，而不是固定持续广播。
- Social influence / counterfactual influence：互动价值可通过“移除一个动作后，对他方行为或最终结果的变化”衡量。
- Preference learning：人类偏好可能不完备、不传递或只能通过具体方案逐步显现。

研究者可以扩展这些方向，但不得因为某篇论文存在，就把其形式直接固化成通爻协议对象。
