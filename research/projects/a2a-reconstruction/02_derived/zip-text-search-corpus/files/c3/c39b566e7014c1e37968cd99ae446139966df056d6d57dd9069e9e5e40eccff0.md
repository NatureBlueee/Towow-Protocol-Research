# Core A2A experiment

## Task and research value

Two independent sources may hold the same typed `@reference` locator. Current
consumer paths key lifecycle state by locator alone, so one owner's removal can
erase or satisfy obligations for the other. The task has real code, deterministic
tests, a hidden pre-existing implementation, and naturally different owner
acceptance conditions.

## Subjects and boundaries

| Subject | Private context | Authority | Cannot do |
|---|---|---|---|
| Source owner A | A add/remove sequence and historical compatibility value | disclose A facts; accept A removal semantics | accept B survival; patch code |
| Source owner B | B active/supersede sequence and isolation veto | disclose B facts; veto cross-owner effect; accept B semantics | accept A semantics; patch code |
| Builder | public source plus condition-specific contract | propose a patch | self-accept; read oracle |

Subjects used independent Claude Code CLI 2.1.219 calls with no tools, no browser,
no persistence, stdin prompts, and JSON-schema actions. Benign canary checks
showed each subject returned only its own canary and marked the peer Unknown.
The trusted root could read both synthetic dossiers, so this was functional
context separation rather than sovereign or adversarial isolation.

Configuration and disclosures are preserved in
[boundary_and_disclosure.json](experiments/r5-4-run-001-source-identity/boundary_and_disclosure.json).

## Paired conditions

1. Static: one builder saw the public symptom, public source, and a capability
   card; no owner query.
2. Least-privilege central: A and B answered the same four narrow questions;
   the central builder received only those reports.
3. Direct A2A: owners adaptively proposed, countered, disclosed, retained
   Unknowns, and could sign or refuse an exact contract.
4. No-interaction ablation: represented by the static condition.

All were preregistered before main model outputs. See
[preregistration](experiments/r5-4-run-001-source-identity/preregistration.json).

## Actual interaction

- Round 1 A proposed composite identity plus legacy global fallback.
- Round 2 B refused wildcard legacy semantics and demanded outcome-scoped
  supersede and evidence behavior.
- Round 3 A adopted a null-source class and enumerated seven surfaces.
- Round 4 B refused to pre-waive a remedy for an unverified mechanism.
- Round 5 A added severability and a scoped infeasibility lapse.
- Round 6 B countered that lapse could not erase the protected entitlement and
  demanded disclosure, dispute rights, and a corrected surface list.

The structured actions and raw CLI outputs are in
[transcripts](experiments/r5-4-run-001-source-identity/transcripts/a2a/).

## Result and acceptance

The interaction formed an **unclosed candidate**, not a joint solution. There
was no final signature, no builder call under an accepted A2A contract, no
product patch, and no target adoption.

Executable counterfactuals proved that the disputed condition is real:

- A2A null-source candidate: 3/3 dedicated checks pass.
- Hidden wildcard implementation against those checks: 0/3.
- Candidate against existing core expectations: 39 pass, 2 fail.
- Hidden implementation native suite: 44/44 pass.

JUnit evidence is under
[validation](experiments/r5-4-run-001-source-identity/validation/).

## Failures, Unknowns, and exits

- Static output had corrupt hunk counts and deeper canonical-schema defects.
- Run-001 central builder closed mid-response.
- A2A reached the call cap at B `COUNTER`.
- The separately preregistered central replication also closed mid-response.
- The real legacy corpus and owner value choice remain Unknown.

These outcomes are retained under [failures](failures/) and the experiment
directories.

## Why this is actual A2A but not A2A success

The owners functionally had different private facts and acceptance authority,
and B exercised a real veto that changed A's proposed contract. This is more
than a central internal chain-of-thought or fixed role state machine. But the
authority was synthetic and safely collapsible to the trusted root; no accepted
world change followed. The evidence supports negotiation-mechanism behavior,
not structural necessity or formation success.
