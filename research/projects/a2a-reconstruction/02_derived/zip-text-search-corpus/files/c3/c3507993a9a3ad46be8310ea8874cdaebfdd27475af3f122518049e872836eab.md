# Schema and Dependency Record

## Boundary schema

The frozen public readback is an exact six-key allowlist:

```text
issuer
observedAt
policy
reference
revision
state
```

The World adapter accepts only:

- issuer `allbuddy:consumer-adoption`;
- policy `local-recoverable-outbox-v3`;
- state in `adopted`, `not_adopted`, `revoked`;
- a positive integer revision;
- an opaque validated reference;
- an ISO-parseable observation timestamp.

Extra/private fields fail closed. Source revisions must be contiguous, and the
same `(reference, revision)` cannot map to divergent event/readback identities.
The actual validators, journal schema and tests are contained in the Agent
World source patch.

## Dependency changes

- Allbuddy added no package or lockfile dependency.
- Agent World added one existing workspace export and one script entry; it
  added no third-party dependency.
- Reproduction still requires the original repositories at their pinned
  baselines and their existing Node/pnpm workspace dependencies.
- Local service ports, stores and capabilities are runtime fixtures and are not
  embedded in the packet.

## Durable evidence exclusion

Artifact bodies, query/customer text, tenant identity, cookies, bearer tokens,
lease tokens, session capabilities and reader handles are intentionally absent.
The redacted state outputs in the Formation Episode document what was retained.
