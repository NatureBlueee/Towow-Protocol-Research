# 从公开证据到真实实验的桥接程序 v0.6

- 五个最大差异案例；
- 统一 Relation Schema/Authority/Effect 编码；
- 公开来源索引与竞争解释；
- 单编码者横向综合；
- 对 v0.4 的理论和 Fieldkit Design Delta。

P0 的结论等级：`archival mechanism evidence — provisional`。

## 阶段 P1：双人编码与原始访谈校准

### P1.1 双人独立编码

选择 Sidewalk、Crossrail、Microsoft–LinkedIn 三案，分别代表：

- institutional frame 变化；
- declared/enacted schema 断裂；
- mature frame / CollapseSafe。

第二编码者只读 source bundle 与 coding manual，不读本轮结论。目标不是追求高一致性，而是暴露：

- Relation Schema 仍然过宽或含混的位置；
- materiality 依赖价值判断的位置；
- Authority Locus 与 standing 的边界；
- outcome chain 的证据不足。

### P1.2 SGMA transcript-level 研究

取得 QDR DOI `10.5064/F6QHVGUI` 的 52 份去标识访谈后：

1. 按研究问题抽取与机制选择、自治、数据共享、拒绝、权威和代表性相关的回答；
2. 不用“清晰度/惊奇度”作为质量代理；优先看与关键研究问题的直接相关性；
3. 比较正式协议/论文编码与访谈中的非正式规则；
4. 搜索至少三类反例：形式相同但机制原因不同、自治不是首要关切、协作没有带来预期 outcome；
5. 输出 Fieldkit 的 interview-to-Assertion 转换规则，但不把访谈推断自动升级为 Principal Stance。

## 阶段 P2：公开材料上的前态保持测试

为每案定义时间截点，只向编码者提供截点之前的文件。要求其输出：

- 未闭合 Γ 维度；
- 是否可编译；
- 最小下一 probe/authority query；
- central/human/Towow 路由；
- 可能的 Defeater。

随后与真实下一事件比较。它检验的是诊断和研究仪器，不是预测市场结果。

## 阶段 P3：公开案例重放器

将时间线转成可重放 event stream：

```text
source event
→ proposed typed Assertion/Stance/Commitment/Operation
→ materiality decision
→ affected dependency closure
→ compile/reopen state
```

对三种系统做离线对照：

1. 仅文档摘要；
2. 单一中心 Agent；
3. 多 Authority Locus + RelationVersion + scoped reopen。

主要终点：遗漏的 material issue、错误权威归属、Effect/Acceptance 混淆、无谓重开、无法追溯的推断。由于没有真实参与者，不能把它写成“用户价值”实验。

## 阶段 R7-A：仍然保留

公开证据完成后，最小 live experiment 会更小、更明确：

- 不需要先证明所有理论；
- 只选择 institutional frame 不足但可通过 1–3 个形成操作解决的事项；
- 公开案例已经校准 standing、assurance、governance 和 CollapseSafe 排除规则；
- live experiment 只集中检验 Agent 干预的因果增量、Mandate 可用性、披露成本和真实 Acceptance。
