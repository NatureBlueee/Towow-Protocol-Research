## 2. 跨案例最稳定的发现

### 2.1 关系模式的核心不是“字段多”，而是效力生成规则

五个案例都能映射到 `R/V/T/A/E/D/O`，但真正解释转折的通常不是新增字段，而是：谁拥有决定权、什么证据能让结果作数、谁具有 standing、怎样退出或重新打开，以及局部输出怎样成为端到端 Effect。

这支持 Relation Schema 作为有限操作框架；同时反驳把它做成一个穷尽所有业务语义的万能 ontology。

### 2.2 institutional frame 与 relation-specific version 必须同时存在

Microsoft–LinkedIn 表明：具体条款可以大幅变化，但成熟的 M&A institutional frame 已经提供董事会权威、竞价、受托责任、监管、退出和 closing witness。这里不需要从零形成“什么是交易”。

Sidewalk、Open Banking 和 SGMA 则显示：institutional frame 本身可能仍在形成或重新分配。Crossrail进一步表明，纸面 frame 存在也不代表 enacted frame 有效。

因此，CollapseSafe 不是“只有参数变化”，而是：

> 当一个被参与者和外部制度认可的 frame 已经充分给出角色、权威、证据、争议、退出与结果语义，当前关系变化能够在其内部被合法处理时，可以安全折叠到中心、人类经纪或确定性工作流。

### 2.3 形成、编译和运行不是时间上的一次性三段

Open Banking 在技术运行后因治理失败重新打开；Crossrail 在大量包件运行后因集成与 assurance 失败重开；Sidewalk 在 threshold resolution 后仍因关键细节未闭合保持条件态。现实结构更接近：

```text
局部形成 → 局部制度化/技术编译 → 局部运行
     ↑                         ↓
     └──── governance / evidence / authority / stakeholder Defeater ────┘
```

### 2.4 技术成功、制度合法性、Principal Acceptance 与社会接受正交

- Open Banking：技术采用高，但治理仍失败并重构；
- Crossrail：包件进度高，不等于铁路可运营；
- Microsoft–LinkedIn：法律 Effect 明确，不等于所有员工/用户接受或长期战略成功；
- Sidewalk：双边条件改善，不等于公众/政府最终接受。

这要求系统保留不同来源的 Effect、Adoption、Acceptance 与 standing，而不是用一个 `success=true` 收束。

### 2.5 不可折叠权威不自动推出 P2P 或统一“主权机制”

SGMA 的结果尤其重要：相同的协调命令下，自治关切会影响机构选择，协作配置也随 outcome 类型变化。中心平台、JPA、MOU、标准、共享服务、本地 Oracle 与人工中介不是从低到高的成熟度，而是根据权威拓扑和风险选择的机制族。

## 3. 对 v0.4 的修正

1. `standing` 必须进入 R/A 的检查：谁有权签字，与谁有合法资格提出受影响主张，不是同一件事。
2. `stability` 明确为向量，至少覆盖技术/运行、权威/治理、证据/assurance、规范/合法性、经济/资源；不新增根对象。
3. `compile` 扩展为制度化：合同、标准、API、审批、监督、争议与退出都可以是编译目标。
4. `reopen` 触发器扩展为治理失败、assurance 失败、authority drift、affected-party claim 和 objective/end-state drift。
5. `declared schema` 与 `enacted schema` 分离：有规则文档不等于规则可执行或被信任。
6. `CollapseSafe` 由 institutional sufficiency 决定，不由任务表面复杂度决定。
7. 快速“成交/不成交”的真实性必须同时满足事实相容、相称权威、合法 standing 和 Effect witness。

## 4. 仍不能从这些案例推出的结论

- Towow 比优秀人类经纪、平台或中心 Agent 更有效；
- Agent 能准确代表人类不可数字化部分；
- 范围化 Mandate 在真实使用中负担可接受；
- 最小披露能够在现实中降低泄露且不损害形成质量；
- Agent 互动因果地形成了冻结前态不存在的新路径；
- 形成机制产生正净协调剩余。

## 5. 当前最好的理论状态

公开证据没有推翻“不可折叠权威下的共同可行动关系”这一核心对象，反而使其更具体。但它把理论从“Agent 之间形成关系”进一步改写为：

> 多个实体在一个或多个既有制度框架下，通过异议、反条件、权威重分配、证据生成和承诺，把关系中特定未闭合部分构成到足以被制度化；随后由确定性机制运行，并在技术、治理、证据、目标或 standing 出现 Defeater 时局部重开。

Agent 的独特作用不是成为新的最终权威，而是提高跨私有世界的发现、翻译、反例生成、条件形成和局部编译能力。
