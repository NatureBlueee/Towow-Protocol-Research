# Open Re-review 02 — Durable Record Is Not a Recoverable Joint Path

第二位复核者从零审查当前 diff，未读取研究日志或第一位复核结论。Verdict：
`BLOCK — do not freeze for Agent World`。

## New blocking evidence

1. adoption commit 后，raw control/read capability 只存在于 HTTP response；磁盘只有 hash。
   response loss、abort、reload、tab close、Web Storage failure 或多 tab 覆盖，都可留下
   server `adopted` 但 ProductShell/World 永久不可发现的 orphan。
2. ProductShell 直接相信 mutation response 的 `adopted`，没有独立 canonical read-after-write。
3. 浏览器 E2E 从 `sessionStorage` 取出 reader secret，再由同一 Playwright context 调 readback；
   没有独立 World 进程、durable handoff、claim/ack 或身份接收。
4. revision/revocation 只存在于 core class tests；runtime/routes/actual consumer 没有该接口。

## Important but production-scoped gaps

- crash 后 stale lock、缺 fsync；
- auto-adopt policy 没有独立业务 acceptance predicate；
- pending/aborted Artifact 私域正文无 GC/retention policy；
- tenant 仍是单一 fixture，Web Storage capability 不分真实用户；
- E2E 依赖显式 experiment env，不是默认生产路径。

## What remains valid

- 64/64 independent prepare；
- one accept capability 在 64 个跨进程竞争中 1 success / 63 denied；
- clean happy path 从持久 store review Artifact；
- 保留 handle 时新实例/独立 Node 进程能回读；
- public World payload 不含正文、raw tenant 或 query；
- 未配置 authority 时诚实不采用。

## Design consequence

source authority 不只需要 durable state，还需要 durable authority delivery：

- mutation 必须幂等可恢复；
- target consumer 必须 read-after-write；
- 跨主体 capability 必须有 durable claim/ack，不能依赖一次 HTTP response 或浏览器内存；
- 若 revision/revocation 属于 contract，就必须进入真实 runtime 接口与独立 reader。
