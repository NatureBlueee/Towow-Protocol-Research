# 通爻 A2A 第二轮研究交付说明

版本：0.2-dev  
日期：2026-07-24

## 研究结论

本轮把元问题重新定义为“主权联合行动构成（Sovereign Joint-Action Constitution, SJAC）”：开放世界里，参与者、角色、变量、候选动作、约束、偏好与证据规则本身都可能尚未被共同定义，且分别埋藏于主体的主权私有世界中。系统的中心任务不是在固定索引里搜索最相似对象，而是逐步构成一个可求解、可认领、可承诺、可执行和可闭合的共同动作。

核心工程结论是“不要把主体压成中心可搜索的完整画像；让主体保留自己的‘体’，按任务方向返回必要的‘边’”。本地节点通过 LLM 与确定性策略共同提供 cut、column、witness、unknown、refuse 等预言机响应；共享协调运行时维护版本化 Coordination IR；大模型生成和修复语法与安排；算法求解；主体认领；权威内核和 TrustAdapter 使结果作数。

## 证据边界

- 数学命题只在论文明确列出的假设下成立。
- 合成实验验证的是机制可行性，不是开放网络生产性能或安全证明。
- 参考实现不是生产协议、法律合约引擎、安全多方计算系统或完成安全审计的分布式实现。
- 本轮尚未完成真实主体、真实商业谈判、真实跨模型本地 LLM Oracle、真实电子签/托管/链上适配器与跨司法域试点。
- “概率可管理”是条件性结论：需要校准、反馈、漂移监控、弃权、完整中介和可追责机制；无限制分布漂移下没有无条件保证。

## 推荐下一轮

1. 单组织、多主体的真实 Dogfood：以 Flowness Harness 本身作为主权节点。
2. 两主体、两信任平台试点：A2A 传输 + 本地 Oracle + 平台/电子签 TrustAdapter。
3. 三主体隐藏贡献模式试验：验证列生成是否发现静态 Profile 无法暴露的组合。
4. 联邦互操作：两个独立实现只交换 Coordination IR、Delegation/VC 和事件语义。
5. 建立 GCBench-R2：包含私有世界、公开投影、局部预言机、安排版本、认领、承诺、执行证据、失败归因和反事实样本。
