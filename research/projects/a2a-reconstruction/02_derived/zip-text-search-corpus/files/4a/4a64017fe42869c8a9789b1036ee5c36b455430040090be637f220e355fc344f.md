# PEA-10：公开制度档案最大差异校准

## 设计

十个有意选择的真实制度案例：4 个 SEC 交易过程、3 个 CMA 监管过程、3 个 GAO 采购争议。它们用于最大化理论反例和结构差异，不用于估计总体频率。编码为单研究者首轮，没有双人一致性主张。

## 结果

- 主要修订类型：{'EXPANSION': 1, 'TRANSFORMATION': 3, 'EPISTEMIC_CLARIFICATION': 1, 'PROTECTIVE_CONTRACTION': 5}；
- 外部 Authority 改变路径：7/10；
- tentative state 后出现 challenge/reopen：6/10；
- 保护性收缩：7/10；
- 关系类别转化：5/10；
- 数据派生问题：3/10；
- 证据门失败：3/10。

以上只描述有意选择语料。不能写成现实中相应机制的比例。

## 硬性未发现

- Agent 因果贡献：0；
- 条款级 explain-back / 主观自由认领：0；
- 与优秀人类中介可比的净协调剩余：0。

因此 C18、C19、C20 保持 UNKNOWN。

## 最重要的理论反例

形成不只可能扩张路径，也可能通过关系转化或保护性收缩提高真实性。Effect 发生后仍可能被有 standing 的外部 Authority 重开；Settlement 必须带 scope。

## Design Delta

1. P4 改为 qualified-space revision；
2. standing/jurisdiction/challenge/Settlement scope 进入 Relation Schema；
3. SourceRecord 进入 Assertion provenance；
4. Fieldkit 加入外部范围 compile gate；
5. 不增加 aggregate root。
