# 当前研究状态与可信边界

## 已经相对稳定的判断

1. 静态 Agent Card、能力标签、Embedding 或知识图谱只能在特定任务中充当发现投影，不能定义主体完整未来行动空间。
2. 模型概率、实体身份、能力、授权、承诺、现实 Effect、目标域 Adoption 和主体 Acceptance 不能互相代答。
3. 能力是任务、环境、工具、权限、资源、恢复和时间条件下的可达性，不是实体的永久标签。
4. 现实效力必须由相称目标世界的权威 readback 或 witness 支持；生产者日志和签名只能证明其各自所证明的内容。
5. 主权 A2A 的必要性来自不可折叠的权威、责任、隐私、战略关系和接受权，而不是部署是否分布式。
6. 关系稳定以后，最小权限确定性运行通常优于持续使用开放式 Agent 协调；反例和变化应触发局部 reopen。
7. NoDeal、Conditional 和 Unknown 是一等研究结果；成交率不是系统总体目标。

## 获得局部机制支持、尚不能普遍化的判断

1. 现实 probe + 权威拒绝 + countercondition reduction 能在跨技术权威域中形成新路径。
2. 动态边界在合成私有约束任务中可以比静态披露用更少信息达到可行解。
3. 版本化共同对象、最小权威门和目标域 readback 能减少自由聊天历史中的状态漂移。
4. 稳定局部关系可以被编译，并在 Defeater 出现时重开。

## 当前未知

1. 真实人和组织是否愿意并能够使用这种结构作出范围化认领。
2. 系统是在发现隐含偏好、帮助形成偏好，还是把模型偏好投射给主体。
3. 相比优秀经纪人、项目经理、人类+AI 和同权限中心 Agent，是否产生正净协调剩余。
4. 长期策略行为、权力不对称、串谋、第三方外部性和监管怎样改变机制。
5. Relation Schema materiality 在真实组织中有多少可以自动判断，多少必须由相称权威裁决。
6. 真实模型升级后，Mandate、目标所有权和长期记忆边界能否持续保持有效。

## 当前证据最高等级

- E1：形式反例与必要条件；
- E2：可复现合成机制实验；
- E3：参考实现、状态机和有界构造；
- E4：真实本地工作区与历史轨迹；
- E5：跨技术权威域 adoption/revocation/recovery 闭环；
- E6：真实模型互动但合成 Principal；
- E7：真实 Principal 认领和现实长期结果——仍然缺失。

## 当前最重要的研究纪律

- 不用文件数、样本数或测试通过数替代证据等级；
- 不把生成器内的零错误外推为现实零风险；
- 不把签名、VC 或身份认证写成内容真实或权威充分；
- 不把技术域 adoption 写成主体接受；
- 不把拒绝自动解释为失败，也不把 Unknown 永久化；
- 不因概念有现实意义就让它成为顶层协议对象；
- 不因一个中心能计算，就假定它可以代行权威；
- 不因两个进程分离，就假定出现了两个真实 Principal。
