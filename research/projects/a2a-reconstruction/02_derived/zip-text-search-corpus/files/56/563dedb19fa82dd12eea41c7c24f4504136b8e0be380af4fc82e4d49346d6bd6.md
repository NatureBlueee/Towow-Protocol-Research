# 公开证据对核心主张的更新 v0.5

## 证据资格

本轮使用十个有意选择的公开制度案例：四个 SEC 交易过程、三个 CMA 监管过程、三个 GAO 采购争议。它们是真实制度 Effect 和权威过程的观察证据，但不是随机样本、真人访谈或 Agent 干预实验。

## 主张更新

| 主张 | v0.4 | v0.5 | 更新原因 | 仍未证明 |
|---|---|---|---|---|
| C13 稳定处置保真优先 | 设计假说 | 范围化制度支持 | 有效 NoDeal、撤销、禁止与转化确实是现实处置 | 福利权重、净价值 |
| C14 materiality | 构造性支持 | 构造 + 现实结构支持 | A/O/R/E/T/D 变化在真实案件中改变路径 | 自动抽取与争议裁决 |
| C16 数据派生 | 概念稳定 | 非 Agent 场景的现实支持 | 聚合使用可产生战略信号 | 普遍频率、最小谱系粒度 |
| C18 Agent 形成真实行动 | UNKNOWN | UNKNOWN | 档案中无 Towow/Agent 因果介入 | 核心未决 |
| C19 正净协调剩余 | UNKNOWN | UNKNOWN | 无匹配基线和完整成本 | 核心产品经济未决 |
| C20 自由、范围化认领 | UNKNOWN | UNKNOWN | 正式批准不等于 explain-back | 可用性、操纵、权力 |
| C21 自动 materiality | OPEN | OPEN | 手工可编码不等于机器可判断 | 真实语义抽取 |
| C23 正确 NoDeal 的价值 | OPEN | 范围化制度支持 | 不成交/撤销可纠正不合格路径 | 经济量化与反事实 |

## 新增主张

- **C26：** 共同可行动性构成包含 Expansion、Transformation 和 Protective contraction；Clarification 单列。
- **C27：** Settlement 只在指定 RelationVersion、jurisdiction、standing、challenge horizon 和 evidence state 下成立。
- **C28：** 有效外部 standing 可以在双边 Effect 后改变或重开合格空间。
- **C29：** 公开档案可以校准结构和现实结果，不能证明 Agent 因果、主观认领或净剩余。
- **C30：** 来源资格是 Assertion assurance 的组成部分。
- **C31：** 同一 Authority Root 内存在不可压平的 authority functions。

## 硬性未发现

本语料中直接观察到的 Agent 因果贡献、条款级 explain-back 和可比净协调剩余均为 0。这个“0”描述的是材料可观察性，不是现实总体不存在。
