## P0：补齐当前公开材料（无需 Owner 外部资源）

1. 下载恢复后全文编码 ML process 访谈；

## P1：双人盲化编码

需要第二位独立编码者，但不要求真实交易参与者。编码者可以是研究助理、法律/商业分析背景人员或另一独立模型+人工裁决。

主要指标：event boundary F1、dimension Jaccard、materiality agreement、Authority Locus agreement。关键转折 agreement 低于 0.70 时，优先修定义而不是训练分类器。

## P2：公开案例 benchmark

形成一个不含受限原文的开放 benchmark：

- source manifest 与定位；
- derived event traces；
- Relation Schema dimensions；
- materiality / reserved contingency；
- Authority Locus；
- Effect / reopen；
- unknown and observability gap；
- compressed-document ablation labels。

## P3：系统实现

- CollapseSafe Router v0.1：加入 fixed schema、reserved contingency、authority centralizability、private-state loss、environment drift；
- Formation Compiler v0.1：将稳定子图编译成审批、OAuth/MCP scope、工作流和 Effect witness；
- Source-aware Fieldkit：禁止把 INFERRED 事件升级为 Principal Stance。

## P4：公开证据能触及的论文

先形成方法/理论论文的可审查稿：

**Constituting Joint Action under Non-Collapsible Authority: A Theory and Public Process-Trace Calibration**

可主张：问题、操作化、本体收敛、历史过程可编码性、固定 schema 负控制、证据拓扑、系统设计。

不可主张：Agent 带来商业净收益、真实用户接受、优于人类经纪。

## P5：真实机会出现时再进入 live

不再为了研究硬找高风险资源。只在自然出现的低风险事项上运行 R7-A；此前的公开证据工作会把 live experiment 压缩成真正不可替代的几个问题：Mandate、explain-back、认领、认知成本、模型投射、真实 Effect 和长期 Acceptance。
