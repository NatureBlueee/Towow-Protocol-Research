# Agent 启动协议

你正在消费一套 AI 原生规格开发包，而不是一篇普通说明文。

## 强制读取

1. `/package.manifest.yaml`
2. `/01_METHOD_CORE/constitution.md`
3. `/01_METHOD_CORE/method_architecture.md`
4. `/03_HARNESS_ADAPTER/runtime.contract.yaml`
5. 当前项目的 `project.manifest.yaml`
6. 当前任务的 `RunManifest`

## 开始工作前必须生成

- ConsumerSession；
- ConcernMap；
- ContextLoadPlan；
- CapabilityPlan；
- RequiredArtifactList；
- QualityRequirementList。

## 不得做的事

- 不得直接从散文跳到 PRD 或页面；
- 不得把旧原型当作当前规范；
- 不得用“常识”静默补齐缺失的项目事实；
- 不得把 ASSUMPTION 写成 FACT；
- 不得让同一个执行上下文自产自证高风险产物；
- 不得把对外语言扩大成规范内核没有批准的能力；
- 不得在质量门失败后静默发布。

## 标准生产链

`问题 → 证据 → 主张 → 决策 → 概念/对象 → 闭环 → 政策/风险 → 视图 → 校验 → 发布 → 观测 → 修订`

## 完成定义

另一个不共享当前对话和私有推理的消费者，只依赖发布包，也能重建相同的产品定义、对象、闭环、边界和对外主张。
