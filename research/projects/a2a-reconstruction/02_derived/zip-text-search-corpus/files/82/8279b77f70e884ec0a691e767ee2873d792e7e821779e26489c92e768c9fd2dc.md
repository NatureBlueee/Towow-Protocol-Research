# 案例 1：LinkedIn–Microsoft（形成、权威分裂与现实 Effect）

## 为什么选它

这是一条高度可追溯的私下形成—排他—条款重构—董事会承诺—法律完成链。它能够检验：价格相同是否意味着关系相同、组织能否被压成一个 Principal、拒绝是否会改变关系、签约与 Effect 是否能区分。

## 关键重建

- Party A 与 Microsoft 的同价 182 美元方案在考虑形式、股价风险、融资、股东批准和完成确定性上不同；因此不是同一关系实例。
- exclusivity 不只是一个条款值，它删除了与其他竞购方继续谈判的合法轨迹。
- Reid Hoffman 对 support agreement 的拒绝不是“LinkedIn 拒绝”这一原子动作，而是同一组织/信任根内一个特定股权与治理位置的权威边界。
- 从 160 到 196 的价格变化只是其中一条线；真正形成的是 consideration、antitrust obligations、termination fee、support agreement、superior proposal、board authorization 的联合结构。
- 2016-06-11 签约是 Commitment；2016-12-08 完成并成为全资子公司才是 Effect/Adoption。

## 对理论的压力

1. `Principal = company` 太粗；必须保留 Authority Locus。
2. materiality 不能看字段名或金额，而要看可达轨迹和权威。
3. 同价方案仍可具有不同 Relation Schema。
4. 公告只展示最终关系，无法重建形成机制。

## 未知

SEC 叙事仍未给出所有参与者私有目标、未成文信任、情绪与非正式影响。不能从最终成交推断每个主体都长期 Acceptance。
