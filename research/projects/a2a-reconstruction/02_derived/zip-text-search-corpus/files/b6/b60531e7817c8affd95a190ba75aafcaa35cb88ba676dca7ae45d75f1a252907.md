# 语言架构

语言分为五层：

- L0 规范语言：对象、状态、规则、证据；
- L1 团队语言：协作和运营；
- L2 界面语言：当下动作与后果；
- L3 市场语言：价值与购买理由；
- L4 公共语言：政策、学术与伙伴讨论。

对外语言不是内部语言删掉术语，而是语义编译：

`Approved Concepts + Decisions + Evidence → ClaimRecord → Audience View → Back Translation → Approval`

任何外部主张必须声明 capability_status、scope、qualifier、evidence 和 forbidden_extensions。
