# 组织协调、边界与生态系统研究的定位 v0.6

## 1. 不把已有理论重新命名为原创

通爻当前的核心问题与至少三条成熟研究传统相交：

- **知识边界**：Carlile 区分 syntactic/semantic/pragmatic boundary，以及 transfer/translation/transformation。它说明跨域创新不是多发消息，而要改变各方知识与利益关系。
- **Trading zone / boundary practices**：Kellogg、Orlikowski 与 Yates 观察到高速度、不确定环境中的可见化、可读化、持续修订与对齐，同时提醒这些机制会压制差异、制造误读和返工。
- **新生生态系统**：Dattée、Alexy 与 Autio研究价值主张无法事前完整知道的技术生态，强调 coupled feedback、动态控制与控制点漂移。

因此，通爻不能把“语义翻译”“动态形成”“边界对象”本身作为原创。

## 2. 当前可能成立的独立贡献

独立贡献候选来自这些传统尚未被共同压进一个可执行 Agent 制度的问题：

1. 对外连续、可认证、但内部不受限定的 Agent Entity；
2. Identity/Capability/Authority/Objective ownership 正交；
3. institutional frame 与 relation-specific version 的可版本化连接；
4. Assertion/Mandate/Commitment/Operation 的最小事实内核；
5. Effect/Adoption/Acceptance 与 standing 的来源分离；
6. 形成操作 → 局部制度化/技术编译 → scoped reopen；
7. CollapseSafe Router 主动把不需要形成机制的任务排除出去。

这些贡献必须通过系统实现和现实证据成立，而不能只靠概念组合。

## 3. 与平台、咨询和人类经纪的关系

优秀咨询顾问、经纪人、董事会程序和监管机构已经执行许多“发现关系、翻译世界、形成条件”的工作。它们不是低级基线，而是最强竞争机制。

通爻需要证明的不是 AI 能复述这些过程，而是：

- 能否在保留本地权威和最小披露时降低跨域发现成本；
- 能否把非正式形成结果编译成可追溯运行机制；
- 能否在变化后只重开受影响局部；
- 能否让优秀中介的结构能力被复用，而不把中介平台化为新的权威中心。

若不能，通爻最多是一套更精细的治理记录系统。
