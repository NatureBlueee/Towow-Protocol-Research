**日期：2026-07-26**

## 这版完成了什么

v0.4 不是在 v0.3 上继续增加对象，而是做了四次收敛。

第一，重新确定研究对象：通爻研究的是**不可折叠权威条件下，共同可行动关系怎样被形成、认领、兑现和重新打开**。Agent-to-Agent 是其中可能出现的运行形态，不是研究对象的全部。

第二，把解释性的“关系语法”收敛为可操作的 **Relation Schema（关系模式）**。它是一份有限、版本化、任务相关的机器对象；只有角色、动作语言、状态转移、权威规则、证据/效力语义、数据规则或接受语义发生任务相关变化时，才算关系模式变化。价格、日期、数量等仍落在既有类型和规则内的变化只是实例参数变化。

第三，建立顶层对象准入测试，并重新安置 `UsageGrant`、`DataUseEvent`、`DerivationRecord`、`JointArtifactRights`、`LearningUpdate` 等候选概念。语义区分被保留，但默认不再各自升级为协议 aggregate root。

第四，用统一证据标准重新评价历史实验；同时新增两项可复现的构造性压力测试和一个可运行的真实主体研究仪器。历史上缺少原始代码或不能在当前工作区复现的数字被明确降级，不再借“大样本”获得不相称的证据强度。

## 当前核心结论

### 1. 核心对象不是消息，而是关系的可行动化

一个跨主体关系只有在以下条件同时得到满足时，才进入“共同可行动”状态：行动语言可解释，必要权威有效，条件与资源足够，能力有相称证据，现实操作与效力见证明确，必要主体能够认领或拒绝，失败和重开机制存在。

### 2. 关系语法不是一个无限包容的漂亮总词

本包将其限制为：

```text
Γ = <R, V, T, A, E, D, O>
```

- `R`：角色与参与拓扑；
- `V`：对象和动作词汇；
- `T`：状态转移、恢复和退出；
- `A`：谁有权提出、认领、承诺、执行、接受；
- `E`：什么证据可证明什么主张或现实效力；
- `D`：披露、用途、派生、保留和再传递规则；
- `O`：什么构成 Commit、Reject、Conditional、Unknown、Adoption、Acceptance 等处置。

`Γ` 之外的价格、数量、时间、供应商名称和具体资源值属于关系实例 `x`。只有当变化改变任务相关的有效行为轨迹或其权威、证据、数据、结果语义时，才是 material schema change。

### 3. Agent 是可归因的实体包络，不是单一模型

Agent Entity 对外提供连续身份、来源、治理接口、授权引用和追责路径；内部可以包含人、模型、子 Agent、工具、程序、委员会和现实资源。模型能力、实体身份、授权范围和目标所有权必须分离。

### 4. 中心化不是敌人

中心服务可以承担索引、路由、候选生成、公共计算、共享对象托管和确定性执行。需要保留的不是网络上的 P2P，而是不可被中心代行的本地权威、拒绝、责任、信息边界、战略位置和最终接受。

### 5. 形成期与运行期采用不同控制制度

关系模式尚未稳定时，需要适应性探问、拒绝、反条件、现实 probe 和授权形成。稳定子图应编译成最小权限、确定性运行；新 Defeater 只重开受影响局部。

### 6. “真实”优先于成交率

合法结果包括 `COMMIT`、`REJECT`、`CONDITIONAL`、`DEFER_UNKNOWN`、`WITHDRAWN`、`DISPUTED` 和 `REOPEN`。系统目标不是促成更多交易，而是以较低成本更快到达与现实相符、可解释且可重开的稳定处置。

## v0.4 新增实验

### 本体收敛构造测试

在 50,000 个生成场景、每场景 5 类查询中，用 `Mandate + typed Event + provenance edge + conditional Commitment` 表示五个候选概念，查询误差为 0；直接压平为当前字段和布尔值的表示出现 48,926 个错误，查询错误率 19.5704%。24.624% 的场景中，联合制品权利因独立认领/修改而需要提升为独立 Commitment。

该结果只证明：在明确生成器和查询集合下，不需要让五个候选概念全部成为顶层对象。它不证明现实法律体系必然接受该映射。

### 关系模式变化分类器

在 30,000 个有界生成变化中，任务相关 typed materiality checker 对预先定义的可达轨迹、权威、见证、接受、数据和角色完整性语义实现 0 决策错误；“任何 schema diff 都重开”错误率 26.76%，永远重开 44.74%，永不重开 55.26%。

这是可执行定义的一致性和负控制测试，不是现实组织能被自动无歧义建模的经验事实。

## 现实证据的边界

当前最强现实证据仍然是：真实本地工作区中的 Effect/Capability/Boundary 异常、R5.2 的现实语义重建、R5.4 的模型协商负结果，以及 R5C 的跨技术权威域能力形成。它们支持工程不变量和局部形成机制，但没有证明真实人或组织会形成此前不存在、自由认领并具有正净值的联合行动。

因此，v0.4 的首个现实研究不是“大规模用户测试”，而是一个低风险、可逆、非标准、能够产生最小现实效力的前瞻性小样本实验。具体资源与操作方式已写入 `real_world_protocol/`。

## 运行最小研究仪器

```bash
cd instrument/towow_fieldkit
PYTHONPATH=. python -m unittest discover -s tests -v
PYTHONPATH=. python -m towow_fieldkit --help
```

它只用于研究记录，不提供加密存储、正式身份认证、法律签署、隐私合规或生产授权控制。真实参与者的数据应放入另行受控的存储中。

## 发布纪律

本包中的结论分为：定义、形式命题、构造性机制证据、真实技术域证据、开放假说和设计选择。它们不能互相替代。任何新的现实主张都必须在 `evidence/` 中登记适用范围、竞争解释、可复现入口和未证明内容。
