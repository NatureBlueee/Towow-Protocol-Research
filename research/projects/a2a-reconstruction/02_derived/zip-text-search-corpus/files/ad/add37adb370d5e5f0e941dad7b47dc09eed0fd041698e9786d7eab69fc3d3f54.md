# Allbuddy Implementation 02 — Durable Consumer Condition

## Design change caused by the Defeater

第一版共享 JSON ledger 被整体替换，不以补几个测试掩盖：

- 每个不可枚举 reference 使用独立 durable record；
- 每个 record 使用跨进程 lock 线性化 review、adoption 与 revision；
- `prepare` 先把完整 Artifact 写入 consumer store；
- ProductShell 必须从该持久 store 读回 Artifact，才获得 one-shot accept capability；
- adoption transaction 同时生成 consumer control capability 与 World-scoped read handle；
- ProductShell 的 capability wallet 只保存 reference/control；刷新后必须经 server canonical store
  恢复 Artifact，而不是从 React 内存或 localStorage 保存正文；
- World readback endpoint 只接受 reference/viewer/read capability，不接受 raw tenant；
- stable store path 与 synthetic tenant principal capability 必须显式配置；不再默认 tmpdir。

## Claim boundary

当前只形成本机、显式 stable path、capability-bound synthetic principals 的 source condition。
没有证明生产登录映射、跨主机数据库事务、灾备、密钥托管、DoS/side-channel 或商业价值。
