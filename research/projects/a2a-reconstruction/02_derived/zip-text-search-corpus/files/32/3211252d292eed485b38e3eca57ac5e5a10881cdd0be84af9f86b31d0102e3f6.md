# Fieldkit JSON 模板

这些模板与 `real_world_protocol/forms/` 的人类可读表单对应，用于把经过参与者确认的内容写入研究案例。

- `case_screen.json`：候选案例筛选；
- `private_intake.json`：协调前冻结的私有前态；
- `mandate.json`：范围化代理授权；
- `relation_version.json`：共享 RelationVersion；
- `event_payload.json`：typed event 通用载荷；
- `followup.json`：T+7/T+14/T+30 结果；
- `adjudication.json`：独立裁决。

模板不是法律文件或完整 JSON Schema。真实实验前应按案例删掉不需要的字段，而不是让参与者为了“填满协议”提供更多信息。
