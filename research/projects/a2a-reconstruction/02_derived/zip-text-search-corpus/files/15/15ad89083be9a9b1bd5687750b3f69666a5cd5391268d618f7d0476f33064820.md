# 本地实验室返回包规范

最终返回包优先呈现“改变了什么”，而不是“做了多少”。

## 1. `RETURN_SUMMARY.md`

- 最出乎预期的发现；
- 最重要的 Design Delta；
- 哪种协调方法在什么条件下工作或失败；
- 哪些现有判断被支持、限定、削弱或推翻；
- 是否形成了真实新能力；
- 中心或人工方案是否更好；
- 下一项最值得研究的未知。

## 2. `CURRENT_SYSTEM_PATCH.md`

只记录现实证据触发的统一体系变化：

- 对象保留、合并、降级或删除；
- 策略和 Provider 的位置；
- 新的不变量；
- 适用域变化；
- 被推翻的说法。

## 3. `DESIGN_METHOD_RESULT.md`

- 研究前无法决定什么；
- 候选协调方法；
- 探索如何改变方法；
- 最终候选循环；
- 关键条件和适用任务结构；
- 被淘汰的方法及原因；
- 可运行参考路径。

## 4. `FORMATION_EPISODES/`

每个承重 episode 保存：

- 预状态；
- 私有边界；
- 模型与工具；
- 互动和动作轨迹；
- 现实状态变化；
- Witness / Defeater；
- 目标域采纳；
- Acceptance；
- 消融；
- 成本；
- Design Delta。

## 5. `BASELINES_AND_ABLATIONS.md`

- 不协调、静态、中心、Harness+human、A2A 中实际运行的基线；
- 公平性和混杂；
- 关键互动/条件移除；
- 强模型、新工具、人工兜底和目标降低的控制。

## 6. `CAPABILITY_HOLDOUT.md`

- 执行前冻结的 Capability Claim；
- holdout 数据；
- 预测、覆盖和失败；
- 形成证据与原预测分离；
- 能力范围如何收缩或扩大。

## 7. `HUMAN_RECOGNITION_AND_VALUE.md`

若涉及真实人：

- 新可能性是否原先未意识到；
- 接受、拒绝和原因；
- 是否改变理解或歪曲偏好；
- 人类高认知时间和决策数量；
- 原始价值保留。

## 8. `ECONOMIC_AND_ATTENTION_ACCOUNTING.md`

- 模型、墙钟、等待、人类时间、披露、验证、返工和恢复；
- 机会未发生基线；
- accepted outcome；
- reusable learning；
- 净价值边界，不用单一 token 数字替代商业判断。

## 9. `CLAIM_EVIDENCE_UPDATE.csv`

每项重大 Claim 包含：

```text
claim_id
claim
status_before
status_after
evidence_refs
counterevidence_refs
evidence_grade
guarantee_boundary
finding_class
design_delta
next_discriminator
```

## 10. 原始证据

- Git baseline/final/diff；
- 环境事实；
- 模型和 Agent 版本；
- Prompt、输入、输出和退出状态；
- 事件、状态读回和消费者回执；
- 失败、拒绝和 Unknown；
- 运行脚本和依赖；
- Manifest、checksums、Schema 和 portable verifier。

返回包不能只报告成功，也不能以一篇总结代替原始轨迹。
