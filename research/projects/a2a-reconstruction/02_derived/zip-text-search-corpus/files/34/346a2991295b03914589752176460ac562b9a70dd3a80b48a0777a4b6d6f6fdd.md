# Static capability card

- `AtReferenceAdded` creates a materialized reference.
- `AtReferenceRemoved` deactivates/removes a materialized reference.
- `AtReferenceAutoUpdated` and `AtReferenceTargetSuperseded` update the
  materialized reference after a target changes.
- Both endpoint-shaped (`source_entity`, `target_entity`, `reference_id`) and
  typed-locator-shaped (`source_concept_id`, `at_reference`) historical records
  exist.
- Reducers must be replay-idempotent.
- `active_references_to` and concept-retire migration consume the same lifecycle
  semantics.

This card intentionally describes installed operations, not the answer or the
private event streams.
