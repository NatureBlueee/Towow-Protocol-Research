# PRSE-OS 完整开发包 v0.3-dev

这是一个**可交接给本地团队继续发展的工作包**，不是最终标准，也不是某个 Harness 的替代品。

PRSE-OS 的目标，是把“专业化、详细化、完备化地讲清楚一个产品”从少数人的隐性能力，变成可由人类、单 Agent、多 Agent、工作流引擎或本地 Harness 共同运行、检查和改进的制度。

## 这个包包含什么

- PRSE-OS v0.1：产品研究与规格工程方法系统；
- v0.2：AI 原生规格协议、Harness-neutral 运行契约与召集台参考实现；
- v0.3-dev：本次为团队交接新增的统一架构、设计过程、决策沿革、完整模板、测试、路线图与工具；
- 召集台 v0.6/v0.7/v0.8、Agent 协调基础设施研究、可读性工程 Skill 与旧原型截图；
- 本地 Harness 接入协议、Skill/Context/Validator/Artifact 模板；
- 质量门、规格成熟度、方法可观测性、盲消费者测试与变更传播测试。

## 最核心的边界

PRSE-OS 规定：

- 产品事实与语义如何表达；
- 应产出什么结构化成果；
- 什么质量才有资格作数；
- 失败如何暴露；
- 何时应升级给人类。

它不规定：

- 使用多少个 Agent；
- 哪个模型；
- 如何并行；
- 用什么数据库和 UI 框架；
- 本地 Harness 的内部实现。

执行实现可以多样，质量责任必须统一。
