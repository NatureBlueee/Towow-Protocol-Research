# PRSE-OS 方法架构

PRSE-OS 由七个层次组成：

1. **规范内核**：原则、概念、决策、不变量与术语；
2. **AI 原生规格协议**：稳定 ID、依赖、版本、来源、Scope、Supersession；
3. **能力运行时**：CapabilityProfile、Skill、工具和权限；
4. **上下文渠道**：知识包、最小充分装载、冲突和新鲜度；
5. **生产工作流**：研究、语义建模、闭环、视图、保证、表达；
6. **质量保证**：Validator、质量门、盲交和人类升级；
7. **观测与治理**：方法事件、指标、变更传播和方法版本。

## 关键分工

- 描述体系回答“世界和要求是什么”；
- Skill 体系回答“怎样完成一种标准变换”；
- 流程体系回答“怎样组织多个变换”；
- Harness 回答“怎样实际执行”；
- Reference Project 回答“这些机制是否在真实产品中有用”。

四者不能混为一层。

## 标准运行闭环

```text
Frame
  → Evidence
  → Claims & Decisions
  → Concepts / Objects / Relations / Lifecycles
  → Closed Loops / Policies / Risks
  → Views / UI / Language
  → Independent Validation
  → Release / Handoff
  → Observability / Method Learning
```

每一阶段都可回退；流程不是瀑布，而是带质量门和影响传播的图。
