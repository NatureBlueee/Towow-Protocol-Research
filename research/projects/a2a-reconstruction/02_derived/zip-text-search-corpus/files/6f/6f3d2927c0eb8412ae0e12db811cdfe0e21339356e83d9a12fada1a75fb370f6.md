# 当前研究状态与可信边界 v0.5

## 已经相对稳定的判断

1. 静态 Agent Card、能力标签、Embedding 或知识图谱只能在特定任务中充当发现投影，不能定义主体完整未来行动空间。
2. 模型概率、实体身份、能力、授权、目标所有权、承诺、现实 Effect、目标域 Adoption 和主体 Acceptance 不能互相代答。
3. 能力是任务、环境、工具、权限、资源、恢复、版本和时间条件下的可达性，不是实体永久标签。
4. 现实效力必须由相称目标世界的 readback 或 witness 支持；生产者日志、签名和 VC 只能证明其各自所证明的内容。
5. 主权 A2A 的必要性来自不可折叠的权威、责任、信息边界、战略关系、退出权、第三方 standing 与接受权，而不是部署是否分布式。
6. 关系稳定以后，最小权限确定性运行通常优于持续使用开放式 Agent 协调；新 Defeater 应触发局部 dependency-closure reopen。
7. NoDeal、Conditional、Unknown、Disputed 和 Reopen 是一等结果；成交率不是总体目标。
8. Settlement 是带 RelationVersion、jurisdiction、standing、challenge horizon 和 evidence state 的范围化派生视图，不是布尔值。

## 获得现实结构支持、但不能普遍化的判断

1. 合格联合行动空间的修订至少包括 Expansion、Transformation 和 Protective contraction；Clarification 不应自动升级为形成。
2. 有 standing 的外部 Authority 可以在双边签署、授标或 Effect 后改变、收缩或重开路径。
3. 同一组织/信任根内部存在 proposal、recommendation、ratification、execution、Effect witness、acceptance 等不可互相代行的 authority functions。
4. 数据使用可产生聚合趋势、战略信号与新的派生权利问题；仅记录读取权限不足。
5. `Γ=<R,V,T,A,E,D,O>` 对当前 12 个不重复现实事项中的编码任务具有初步表达力；这仍是单研究者校准，不是完备性或一致性证明。

## 局部机制支持

1. 现实 probe + 权威拒绝 + countercondition reduction 能在跨技术权威域中形成新路径。
2. 动态边界在合成私有约束任务中可用更少披露达到可行解。
3. 版本化共同对象、最小权威门和目标域 readback 能减少自由聊天历史中的状态漂移。
4. 当前 Fieldkit 能表达外部 jurisdiction、challenge、scoped Settlement 和 Effect 后 reopen；三项 Shadow reconstruction 结构验证通过。

## 当前核心未知

1. `C18`：真实人和组织是否会因 Agent/Towow 的介入形成冻结前态中不存在的新行动。
2. `C19`：相比优秀经纪人、项目经理、人类+AI 或同权限中心 Agent，是否产生正净协调剩余。
3. `C20`：真实 Principal 是否能理解并自由作出范围化认领，系统是否会投射或塑造偏好。
4. 长期策略行为、权力不对称、串谋、第三方外部性和监管怎样改变机制。
5. Relation Schema materiality 在真实组织中有多少可自动判断，多少必须由相称 Authority 裁决。
6. 模型升级后，Mandate、目标所有权、长期记忆和数据派生边界能否持续保持有效。

## 当前证据层次

- **形式与构造层：** 定义、反例、状态机、构造实验、代码不变量；
- **真实技术域层：** 本地工作区、目标域 readback、adoption/revocation/recovery；
- **公开制度档案层：** 真实组织、权威、Effect、监管/争议和后续处置，但缺少 Agent 介入与完整私有前态；
- **真实 Principal 前瞻层：** live Mandate、explain-back、Agent 因果、长期 Acceptance 和净价值——仍然缺失。

单一 E1–E7 轴只描述主张成熟度；来源还必须用主体真实度、权威可见度、私有上下文、时间过程、Effect、反事实、可追溯性和选择机制单独评价。

## 当前研究纪律

- 不用文件数、事件数、样本数或测试通过数替代证据等级；
- 不把生成器内零错误外推为现实零风险；
- 不把正式批准写成 explain-back 或自由认领；
- 不把制度裁决自动写成全社会福利真值；
- 不把来源未观察到的信息写成不存在；
- 不把公开档案冒充 Agent 干预实验；
- 不因概念有现实意义就让它成为顶层协议对象；
- 不因中心能计算就假定它能代行 Authority；
- 不因两个进程分离就假定出现两个真实 Principal。
