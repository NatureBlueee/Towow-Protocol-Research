# R5C Constructive Flagship Return Summary

## Scope of this return

This packet closes one flagship Formation Episode, `R5C-EP-001`, under its
frozen synthetic local contract. It does **not** close the whole fifth-stage
research program. Matched central formation, real human Recognition, external
source transfer and cross-version/environment/time holdouts remain open.

## Most surprising result

The hardest part was not a receipt schema or EventLog correctness. A usable
cross-principal capability did not exist until authority delivery, recovery and
negative decisions were treated as one semantic operation. Four apparently
working Allbuddy source implementations were defeated by concurrency,
response-loss, browser impersonation, abort and replay counterexamples. A
fifth open World review then defeated a 50/50-green implementation on missing
deltas, false ack confirmation, private-invalid evidence and Viewer leakage.

## Most important Design Delta

Adopt **authority-first countercondition reduction** for tasks where principals
cannot safely collapse:

```text
freeze who owns each claim
→ execute a local falsification probe
→ exchange the minimum observable countercondition
→ remove unsupported schema/crypto
→ form recovery + canonical readback + handoff
→ let the independent target materialize only its scoped report
→ open re-review and ablate the formed condition
```

Routine execution after this boundary freezes should be deterministic or
least-privilege central. Sovereign A2A is not the preferred runtime for a path
already formed.

## What became newly reachable

One real local model-driven formation episode created a path that did not
exist in either baseline repository:

- Allbuddy's synthetic consumer canonically reports a coarse monotonic
  adoption state without disclosing the Artifact;
- an independent Agent World process claims, reads, journals, validates,
  projects and acknowledges that report;
- adopted→revoked→offline/unknown→adopted preserves one projection identity;
- source ack plus fresh-process replay preserves the same semantic state;
- producer-only and wrong-authority controls create no projection;
- a pre-frozen held-out `not_adopted@rev1` task succeeds with no private bytes.

This is a real new local technical capability. It is **not** evidence of human
preference, customer adoption, Artifact correctness, business value,
production readiness or a general A2A Capability Claim.

## Comparative result

- static: found much of the conceptual architecture, but did not execute it
  and overprescribed signing/validity mechanisms without a real issuer;
- least-privilege central: ties or wins for executing the already formed
  interface; cannot originate consumer acceptance without impersonation;
- Harness+human: not run as a matched intervention; current evidence suggests
  humans would have to arbitrate multiple authority/recovery decisions, but no
  human-time superiority claim is made;
- sovereign A2A: added value during formation through reciprocal refusal,
  reality probes and countercondition reduction, not through more dialogue.

## Theory update

Supported but narrowed:

- interaction can form a new path when agents can change local reality and
  refuse false authority;
- boundary payload should be selected by authority and falsification, not by a
  generic receipt template.

Not supported:

- A2A is uniquely able to invent the architecture;
- more negotiation is itself useful;
- the formed episode establishes positive business value.

## Next highest-value unknown

Run the frozen method on a true external holdout where two organizations or
real historical owners independently control acceptance, and compare it with a
matched central designer from the same pre-state. The current local synthetic
policy cannot resolve human Recognition or economic value.
