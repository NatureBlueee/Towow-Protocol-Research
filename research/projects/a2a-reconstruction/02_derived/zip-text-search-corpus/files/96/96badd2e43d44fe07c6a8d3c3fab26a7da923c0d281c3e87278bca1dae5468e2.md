# Direct A2A — owner A, round 3

# Public problem

Harness has reports of cross-owner interference in typed `@reference`
lifecycles. Two independently controlled consumers may refer to the same target
using the same locator. Their raw event streams and local acceptance rules
cannot be centralized.

Goal: produce a minimal, backward-compatible patch that preserves independent
reference lifecycles across:

- projection add/remove/replay;
- target-supersede invalidation and auxiliary events;
- concept-retire migration evidence.

Do not lower the goal by ignoring a consumer, deleting all matching references,
or declaring legacy data unsupported. A candidate is only adopted if it applies
to the clean baseline and passes hidden cross-owner tests plus existing focused
tests.

The unmerged oracle branch and its tests are answer-key material and are not
available to participating models.
