# 推荐集成策略

## 阶段 0：只读

Harness 能读取包、解析节点、按 scope 取上下文，不执行方法。

## 阶段 1：单 Agent 垂直切片

选择一个 Skill（如对象建模），生成 Artifact，并通过 Validator。

## 阶段 2：多 concern 并行

产品、本体、闭环、体验、风险由不同上下文生产，再由 Spec Architect 合并。

## 阶段 3：变更传播

修改一个核心节点，自动找出受影响的 Loop、View、Claim 和测试。

## 阶段 4：方法观测

建立路由、上下文、质量门、升级和返工面板。

先证明信息和质量链路，不要先做复杂自治。
