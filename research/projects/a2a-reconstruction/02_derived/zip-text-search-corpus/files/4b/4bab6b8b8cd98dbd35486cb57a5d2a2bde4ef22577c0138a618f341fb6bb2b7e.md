# 证据拓扑与公开材料边界 v0.5

## 为什么 E1–E7 不够

E1–E7 描述的是一个主张从形式、合成、工程到真实 Principal 的成熟程度。它适合标记 claim，不适合把来源压成单一分数。

来源是偏科的。一份真实 SEC 文件可以精确显示董事会授权和法律 Effect，却几乎不显示参与者未说出口的偏好；控制型谈判数据恰好相反。若把两者排成一个高低等级，就会丢失研究设计所需的互补关系。

Q(s)=<SR,AV,PC,TP,EO,CF,TR,ST>, 每维 0–3

## Claim–source compatibility

| claim | 最低可观察要求 | 当前相容来源 |
|---|---|---|
| `P1_RELATION_SCHEMA_MATERIALITY` | SR≥2, AV≥2, TP≥2, TR≥2 | `aea_private_merger_negotiations_2019`, `sec_linkedin_proxy_2016`, `sec_irobot_amended_proxy_2023`, `sec_irobot_10k_2024`, `gao_hls_decision_2021` |
| `P2_HIDDEN_PREFERENCE_DISCLOSURE` | PC≥2, TP≥2, CF≥2, TR≥2 | `casino_2021`, `deal_or_no_deal_2017`, `craigslist_bargain_2018` |
| `P3_REAL_AUTHORITY_EFFECT` | SR≥3, AV≥2, EO≥2, TR≥2 | `aea_private_merger_negotiations_2019`, `sec_linkedin_proxy_2016`, `sec_ms_linkedin_closing_2016`, `sec_irobot_amended_proxy_2023`, `amazon_irobot_termination_2024`, `sec_irobot_10k_2024`, `gao_hls_decision_2021`, `nasa_hls_award_2021` |
| `P4_ORGANIZATIONAL_PROCESS_VOCABULARY` | SR≥3, PC≥2, TR≥2 | `ml_process_interviews_2023`, `ml_process_paper_2023` |
| `P5_LIVE_AGENT_DELEGATION_ACCEPTANCE` | SR≥3, AV≥3, PC≥2, TP≥3, EO≥3, CF≥2, TR≥2; live agent intervention and prospective consent | **无** |
| `P6_CAUSAL_NET_VALUE_VS_BROKER` | SR≥3, AV≥3, PC≥2, TP≥3, EO≥3, CF≥3, TR≥2; pre-registered comparative intervention | **无** |

最重要的结果不是“公开材料够不够好”，而是：

- `P1/P2/P3/P4` 可以由互补来源继续推进；
- `P5` 与 `P6` 没有任何公开来源能满足，因为缺少 live Agent intervention、prospective consent 和强比较基线；
- 因此，公开证据可以显著减少未来真人实验的探索负担，但不能消灭真人实验的必要性。

## 设计影响

1. claim ledger 应同时记录 claim maturity 与 source profile；
2. Fieldkit 导入历史材料时必须记录 retrospective/selection risk；
3. 研究导出必须区分 `observed`, `asserted`, `inferred`, `unknown`；
4. 多来源一致只能提高可追溯性，不能凭空恢复不可观察私有状态；
5. 不再使用“公开案例=E7”的说法。
