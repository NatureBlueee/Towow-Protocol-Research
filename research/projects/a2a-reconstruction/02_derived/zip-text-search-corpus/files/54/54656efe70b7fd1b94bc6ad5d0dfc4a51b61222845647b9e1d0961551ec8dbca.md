# Baselines and Ablations

## Baselines

| Route | Actually run | Result |
|---|---:|---|
| opportunity absent / no consumer decision | yes | producer completed; World 0 EventRecords and 0 projections |
| static one-shot | yes, model | plausible architecture and medium predicted reachability; no state change; unsupported crypto/TTL remained |
| full-access central | excluded | unfair because it removes privacy and authority constraints |
| least-privilege central | yes, independent evaluator | can execute frozen interface; cannot originate consumer adoption without impersonation; invention comparison UNKNOWN |
| Harness+human | no matched run | no superiority claim; human Recognition remains open |
| sovereign A2A adaptive | yes, two model principals plus local actions | formed runnable bounded interface through Defeater/countercondition loop |

## Condition ablations

| Removed/changed condition | Actual result |
|---|---|
| canonical consumer decision | producer-only gave 0/0 World state |
| correct World bearer | wrong bearer gave 0 deliveries and 0 projection |
| source availability after accepted fact | same projection downgraded to offline/unknown; source value/revision did not advance |
| positive adoption | pre-adoption cancel holdout projected `not_adopted`, not success |
| complete World delta postcondition | independent review found false ack-ready; repaired and regression-tested |
| explicit ack body | `acknowledged:false` initially misconfirmed; repaired and regression-tested |
| readback public allowlist | private-field input is rejected, not persisted, and downgrades prior current state |
| source→target Viewer mapping | unrelated target Viewer initially accepted; repaired and regression-tested |
| restart/source redelivery | fresh World reconstructs same IDs from journal with `processed=0` |

## Confounds

- stronger model/new code contributed to engineering, so the outcome cannot be
  attributed to interaction alone;
- static baseline received less action authority and therefore tests design
  discovery, not implementation throughput;
- ProductShell adoption is synthetic automatic policy, not human preference;
- root experimenter integrated both implementations and supplied local-service
  approvals; this is bounded technical coordination, not zero-human autonomy;
- matched central formation from the same pre-state was not run, leaving
  uniqueness UNKNOWN.
