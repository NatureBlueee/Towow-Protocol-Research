# Relation Schema 历史过程编码手册 v0.5

## 编码单位

最小单位不是段落，而是一次可能改变共同可行动状态的可定位事件。每个事件必须绑定来源、日期（或时间范围）、行为者和 Authority Locus。

## 七维判定

- `R`：参与者、角色、依赖或第三方位置发生变化；
- `V`：允许被提出、交换、承诺或执行的对象/动作类型变化；
- `T`：合法状态转移、顺序、期限、退出、恢复或争议路径变化；
- `A`：谁有权提出、批准、拒绝、承诺、执行、见证或接受变化；
- `E`：证据类型、效力 witness、证明责任、采纳门变化；
- `D`：披露、用途、可采纳性、派生、保留、再传递或学习规则变化；
- `O`：Commit/Reject/Conditional/Unknown/Adoption/Acceptance/Settlement 的成立规则变化。

## Materiality

一个变化只有在当前任务族、状态、风险和时间窗口内改变合法可达轨迹或其权威、证据、数据和处置语义时，才是 material schema change。

不得用以下替代：

- 金额大；
- 新闻价值高；
- 结果意外；
- 文档 diff 很多；
- 当事人很重视。

### 保留条件规则

若 `Γ` 已明确保留一个 contingency 和其处理路径，contingency 的值从未知变为具体，通常是实例/环境变化，不自动是 schema change。NASA HLS 的 award 数量与 funding 是本轮负控制。

### 跨阈值规则

同一个参数变化在未跨权威阈值时是 instance change；一旦触发新的审批者、合法动作或 Effect witness，它对当前任务就升级为 material schema change。

## 事实标签

- `OBSERVED`：来源直接记录；
- `ASSERTED`：来源中的主体主张；
- `ADJUDICATED`：相称权威作出正式判断；
- `INFERRED`：研究者由多项观察推导；
- `UNKNOWN`：来源未给出，不能用结果补齐。

## 完整性

`operationally_complete=true` 只表示当前事件能在不依赖意义关键自由文本的情况下编码 actor、authority、version、change/effect、outcome 和 source。它不表示私有世界完整。

## 双人编码协议（下一轮）

1. 编码者不得先看对方结果；
2. 先独立标 event boundary，再独立标七维和 materiality；
3. 计算 event-boundary F1、dimension Jaccard、materiality agreement 和 Authority Locus agreement；
4. 所有分歧形成反例记录，不以多数投票掩盖语义问题；
5. 若关键转折的 materiality agreement <0.70，暂停自动分类器扩展，先修定义。
