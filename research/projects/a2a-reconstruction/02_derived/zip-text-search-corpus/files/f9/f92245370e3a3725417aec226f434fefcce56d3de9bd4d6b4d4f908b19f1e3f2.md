# 公开证据桥接后的下一阶段研究计划 v0.5

## 总原则

公开资料不再只是相关工作，而成为正式的档案校准层。下一步按“能否改变理论、仪器或实验设计”分配研究预算；当新增案例不再产生 Design Delta 时停止扩张。

## Track A：档案语料扩展与反例搜索

目标不是立刻做大样本比例，而是把当前十例扩展为 30–50 个最大差异案例，覆盖：

- 法院 specific-performance、合同撤销与实体/授权争议；
- 联盟、合资、技术许可和数据合作终止；
- 监管沙盒、附条件许可和撤回；
- 开放标准组织的 objection/consensus/version migration；
- 政府采购重新评估、取消和责任主体争议。

每新增一例必须声明：反驳哪条命题、补哪一个 schema 维度、为何现有案例不足。

## Track B：第二编码与可重复性

先对当前十例中的五例进行独立第二编码，最少比较：

```text
schema dimensions
primary qualified-space revision
materiality
external standing
Settlement scope
hard unknowns
```

分歧不是只算 κ；要记录“定义不清、来源缺失、规范判断不同、事实读取错误”四类原因，并据此修订 codebook。

## Track C：Shadow Towow reconstruction

选择 Microsoft–Activision、Meta–Giphy、Deloitte 三例，做事后结构重构：

- 冻结公开可见前态；
- 生成 RelationVersion 序列；
- 记录 Authority/Assertion/Challenge/Effect；
- 运行 materiality 与 compile readiness；
- 标注原始过程在哪些字段上不可观察。

这不是证明 Towow 当时会做得更好，而是检验 Fieldkit 是否能无损表达现实历史。

## Track D：强反事实基线

对过程丰富案例构造：

1. 静态表单/标准平台；
2. 优秀人类中介；
3. 同权限中心 Agent；
4. 主权 Entity + 共享 RelationVersion。

比较的不是消息数量，而是：信息暴露、可达结果、拒绝/退出、权威归属、challenge、责任、更新和恢复是否被保留。

## Track E：仪器演进

v0.5 已完成 standing/jurisdiction/challenge/Settlement scope。下一步增加：

- 精确 Stance 引用与撤回；
- Mandate 版本撤销和授权链；
- dependency closure reopen；
- SourceRecord/provenance quality；
- 缺失状态枚举；
- archive-to-fieldkit importer；
- 双编码差异比较器。

## Track F：真人实验仍然保留，但不被动等待

公开档案可以替代 R7-0A 历史校准的一部分。R7-A 仍只在以下问题上不可替代：Agent 因果贡献、真实 Mandate、explain-back、主观负担、操纵风险和净协调剩余。

在外部资源出现前，A–E 可以持续推进；真人实验不再成为研究停摆点。

## 停止规则

- 连续十个新增案例未产生新 schema dimension、命题修订或 Fieldkit delta：停止扩语料；
- 第二编码主要分歧来自来源缺失：转向更丰富材料，不继续优化术语；
- shadow reconstruction 无法表达现实关键差异：优先修订内核；
- 强基线在不可折叠维度上实现等价且成本更低：缩小 Towow 适用域；
- 只有真人变量仍未决时：准备最小 live experiment，不再用更多档案拖延。
