# Next research actions

## 1. Canonical Harness Effect Gateway transfer

- **Uncertainty:** action-aligned effect evidence may fail under real retries,
  partial deploys, adapters, and rollback.
- **Experiment:** replay one real low-risk Harness task with injected partial
  side effects and verify per-action result, postcondition, Acceptance, and
  recovery.
- **Condition needed:** canonical Harness repository and one historical task.
- **Decision changed:** whether the new invariant belongs in shared runtime code
  or remains only a local research rule.

## 2. Dynamic private-world hostile boundary

- **Uncertainty:** literal-file denial is not a sovereign world.
- **Experiment:** use separate OS identities, containers, or services; create
  private files after policy initialization; attack with listing, symlink,
  rename, TOCTOU, inherited descriptors, process environment, and fallback
  reads.
- **Condition needed:** approved local container/user sandbox with recoverable
  cleanup.
- **Decision changed:** whether `partial_sovereign` can be promoted or should be
  abandoned for this platform.

## 3. Independent strong-model holdout

- **Uncertainty:** safe formation, refusal, and repair by strong models under
  real boundaries remain untested.
- **Experiment:** preregister hidden tasks and acceptance; give each Agent only
  its sovereign world; compare static, central, bounded and no-formation paths.
- **Condition needed:** an authorized independent Agent runtime that does not
  share the root scratchpad.
- **Decision changed:** `R5-C15` and the predictive value of Capability Claims.

## 4. Real break-even with a subject

- **Uncertainty:** no privacy, attribution, delay, attention or dispute value was
  priced.
- **Experiment:** one real low-risk task that a subject refuses to centralize;
  measure the same accepted objective under central/manual/sovereign paths.
- **Condition needed:** subject consent, explicit value dimensions and stop
  conditions.
- **Decision changed:** whether the 4.54x runtime and governance burden has net
  positive value anywhere real.
