# Blockers and pending owner gates

There is no external blocker to returning this research packet.

There is one material product-value gate that the experiment cannot decide:
whether a historical source-less removal may affect explicitly sourced
instances in a mixed stream. Resolving it requires:

1. a measured, hashed legacy corpus;
2. an authorized owner acceptance predicate;
3. an explicit migration/cutover policy if semantics change.

This is not marked as an experiment failure that more model turns can repair.
No product patch should be merged until that gate is resolved.
