# 推荐的 AI 原生产品包结构

```text
project-spec/
  project.manifest.yaml          # 入口、版本、优先级、有效范围
  constitution/                  # 产品定义、不变量、非目标
  evidence/                      # 证据和来源
  registries/
    concepts.yaml
    decisions.yaml
    requirements.yaml
    claims.yaml
    risks.yaml
  ontology/                      # 对象、关系、生命周期、政策
  loops/                         # 用户/服务/协作闭环
  views/
    ui/
    operations/
    external-language/
  changes/                       # ChangeSet、影响分析、迁移
  tests/                         # 一致性与盲交测试
  examples/
  negative/                      # 禁止误读、旧锚点、反模式
```

## 为什么不是一份大文档

- AI 可以按依赖装载；
- 改一条定义时能做影响分析；
- 不同消费者只读取相关 View；
- 可以单独校验对象、闭环、语言或页面；
- 旧判断可以明确 supersede，而不是留在文档后半段继续生效；
- 可以对每个节点做 provenance、版本和权限管理。

Word/PDF 仍可作为发布快照，但不应成为唯一真相源。
