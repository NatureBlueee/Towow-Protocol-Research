# QDR 双人盲化编码器材 v0.7

本目录提供双人编码协议、生成器和一致性计算器。完整本地运行会生成：

- `coder_packet_A.jsonl` / `coder_packet_B.jsonl`：两套随机顺序文本包；
- `coder_form_A.csv` / `coder_form_B.csv`：独立编码表；
- `machine_retrieval_key.jsonl`：机器检索标签，仅用于完成编码后的误差分析；
- `packet_manifest.json`：包规模与分层信息。

由于 QDR Standard Download Agreement 不允许未经许可重新发布下载数据或其部分，逐字片段包不进入可分享 release。授权研究者应先合法取得 QDR 数据，再在本地运行：

```bash
python build_packets.py
```

两名编码者在编码完成前不得查看 `machine_retrieval_key.jsonl`。机器 key 不是 gold standard。只有完成双人独立编码、计算一致性并裁决分歧后，才可以把相关标签升级为 adjudicated evidence。
