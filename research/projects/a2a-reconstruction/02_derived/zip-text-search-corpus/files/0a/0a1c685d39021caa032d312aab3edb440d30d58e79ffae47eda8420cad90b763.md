# Economic and Attention Accounting

## Observed costs

- elapsed flagship work from initial state capture to holdout: approximately
  three hours wall clock;
- model principals/evaluators: Allbuddy principal, World principal, candidate
  scout/central evaluator, static baseline, feasibility/semantic/systems
  reviewers, plus root integrator;
- implementation: two isolated product worktrees and one research worktree;
- repeated verification: Allbuddy unit/type/lint/browser checks, World package
  tests, AWIR contracts, package verifier, real local HTTP/process runs;
- rework: four source freezes withdrawn and one World implementation
  COUNTER repaired;
- human attention during execution: no substantive mid-run design answer;
  local-listener approvals were required by the sandbox. Final owner value
  Recognition was not requested or inferred;
- disclosure: coarse six-field source report plus opaque references only;
  Artifact/query/tenant/credentials excluded from World durable bytes.

Exact model token and monetary costs were not exposed by the environment, so
none are fabricated.

## Opportunity-absent baseline

Without the capability, producer completion remains local and World has no
accepted external report. The owner would still need to reconcile producer,
consumer and presentation truth manually, or accept no cross-system state.

## Accepted outcome

A bounded local technical capability and one held-out negative-state result
were achieved. It converts future executions of this exact interface into a
mechanical coordinator task.

## Reusable learning

The main reusable asset is the method and invariant set, not the local file
adapter:

- authority before schema;
- local Defeater before additional dialogue;
- authority delivery as capability;
- invalid evidence must degrade old success;
- adaptive formation followed by simple execution.

## Net-value boundary

Positive local research value is plausible because the episode changed both
source and World design and produced a runnable holdout. Net commercial value
is `UNKNOWN`: no real human/customer Recognition, production comparison or
matched human-time measurement exists.
