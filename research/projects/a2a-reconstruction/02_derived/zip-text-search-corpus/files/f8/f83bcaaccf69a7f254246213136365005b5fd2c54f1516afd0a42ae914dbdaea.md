# 对象与本体建模

## 目的
建立产品世界中“什么存在、如何区分、如何关联、如何变化”的统一解释。

## 步骤
1. 提取候选名词、动作、状态、规则和证据。
2. 将 UI 容器词与领域概念分离。
3. 对每个概念定义：
   - identity criterion；
   - essential properties；
   - relations；
   - lifecycle；
   - invariants；
   - examples / counterexamples；
   - forbidden synonyms。
4. 检查：
   - 同名异义；
   - 异名同义；
   - 对象与事件混淆；
   - 状态与阶段混淆；
   - 证据与决定混淆；
   - UI 投影反向绑架本体。
5. 生成关系图和影响范围。

## 失败信号
- “卡片”成为领域对象；
- 一个总状态机承载所有对象；
- 每个页面重新定义同一个概念；
- 对象没有身份或生命周期。
