# 附录 C　状态机与不变量

## C.1 RelationVersion 状态机

```text
DRAFT
  ├─ propose → PROPOSED
  └─ abandon → WITHDRAWN
PROPOSED
  ├─ material revision → DRAFT(new version)
  ├─ all required stances → RECOGNIZED
  ├─ reject → REJECTED
  └─ defer → DEFERRED
RECOGNIZED
  ├─ capability/evidence/resource gates → COMMIT_READY
  └─ defeater → REOPENED
COMMIT_READY
  ├─ commitments active → ACTIVE
  └─ expiry/material change → REOPENED
ACTIVE
  ├─ obligations complete → COMPLETED
  ├─ dispute → DISPUTED
  ├─ withdrawal/termination → TERMINATED
  └─ defeater → REOPENED
```

## C.2 Mandate 状态机

```text
PROPOSED → ACTIVE → NARROWED → REVOKED
                  └→ EXPIRED
```

规则：narrow 只减少权限；扩展必须生成新版本并由 issuer 重新签发。Revocation 不自动撤销已经发生的 Effect，但会阻止后续 Operation，并触发依赖 Commitment 检查。

## C.3 Commitment 状态机

```text
PROPOSED
→ RECOGNIZED
→ RESERVED
→ ACTIVE
→ FULFILLED / BREACHED / WITHDRAWN / DISPUTED
→ SETTLED / REOPENED
```

`RESERVED` 不代表义务已激活；它表示关键资源已被原子占用。若 reservation 过期，Commitment 回到待资源状态而非继续有效。

## C.4 Operation/Effect 状态机

```text
SPECIFIED → AUTHORIZED → ATTEMPTED
ATTEMPTED → NO_EFFECT | PARTIAL_EFFECT | EFFECT_CONFIRMED | EFFECT_UNKNOWN
EFFECT_CONFIRMED → ADOPTED | NOT_ADOPTED | REVOKED
ADOPTED → ACCEPTED | CONDITIONAL | REJECTED | DISPUTED
```

## C.5 关键不变量

1. **Authority Path Invariant**：每个 material Stance、Commitment 和 Operation 必须存在到 Principal/Authority Root 的有效路径；
2. **Version Exactness Invariant**：Recognition、Mandate、Commitment 和 Operation 引用 exact RelationVersion；
3. **No Silent Material Inheritance**：material change 不继承旧 Stance；
4. **Attempt–Effect Separation**：Attempt 不能自动生成 Effect；
5. **Target Witness Invariant**：Effect 由目标世界或相称外部 witness 证明；
6. **Adoption–Acceptance Separation**：目标域采用不自动生成主体接受；
7. **Reservation Safety**：激活 Commitment 的稀缺资源总预留不超过可用容量；
8. **Model–Authority Separation**：模型置信和文本一致不产生规范权威；
9. **Data Purpose Binding**：数据使用和派生必须落在有效 Mandate 的用途范围；
10. **Scoped Reopen**：Defeater 至少重开所有 material dependents，不覆盖无关历史；
11. **Compiled World Non-Authority**：编译视图不能修改来源域权威事实；
12. **Explicit Unknown**：无法判断不被强制写成 Reject、Accept 或 false；
13. **Standing Preservation**：可折叠机制不得删除必要 challenge/recourse；
14. **Human Override Traceability**：人工覆盖必须记录 Authority、理由、范围和版本；
15. **No Capability by Demonstration**：单次成功只能作为 Evidence，不自动提升为 Qualified Capability。

def scoped_reopen(defeated_node, graph):
    queue = [defeated_node]
    reopened = set()
    while queue:
        n = queue.pop()
        for child, dependency in graph.material_dependents(n):
            if child not in reopened:
                reopened.add(child)
                queue.append(child)
    for node in reopened:
        node.status = downgrade(node)
        emit("SCOPE_REOPENED", node=node, cause=defeated_node)
    return reopened
