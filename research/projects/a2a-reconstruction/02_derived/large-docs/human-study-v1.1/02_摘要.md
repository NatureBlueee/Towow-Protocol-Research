# 摘要

本方案用于检验一套面向超级个体与一人公司（one-person company, OPC）的主权代理系统，能否在真实责任主体、真实事项和真实但低风险的现实效力中稳定运行。研究不把“Agent 之间聊得更好”或“最终成交”作为充分结果，而是观察：一个外部可认证、可授权、可追责，内部却由多个角色、模型、工具、账户、工作流和不可数字化判断共同构成的 Agent Entity，能否在保持本地世界、拒绝权、责任和接受权的条件下，从机会发现推进到关系形成、能力组装、精确委托、资源预留、现实执行、目标世界验证、采用、接受、结清、复用与局部重开。

方案采用分阶段、低风险、逐步升级的研究程序。第一阶段利用历史事项校准数据结构和任务分类；第二阶段以 shadow mode 观察真实 OPC 事项，但不让系统产生现实动作；第三阶段允许可撤回、金额与权限受限的现实 Effect；第四阶段进入两个或多个独立责任根之间的双边形成或临时联盟；第五阶段重复同类任务并注入环境变化，检验 Compiled World、局部重开和长期接受。每个阶段均设置固定平台/表单、扁平强中心 Agent、权威感知中心 Hub、联邦 Relation 系统，以及适当时的优秀人类经纪基线。研究不预设联邦部署或 A2A 必然更优，而是分离语义价值、拓扑价值、形成价值和编译价值。

数据标准覆盖主体与权威图、协调前私有前态、版本化 Mandate、RelationVersion、事件链、Agent/工具调用、资源预留、目标世界 Effect readback、Adoption/Acceptance、人工认知时间、敏感披露、成本、失败、后悔和长期复用。所有 material claim 均须具有来源、时点、版本、权威和证据定位；任何由 Agent 生成的推断均不能冒充 Principal 事实；任何执行日志均不能单独证明现实 Effect；任何技术采用均不能自动写成 Acceptance。

本实验的价值不是一次性证明“通爻优于所有机制”，而是建立可复现的适用边界：何时平台足够，何时中心计算有益，何时必须保留本地权威，何时现实 probe 能创造新路径，何时应该拒绝或重构任务，以及形成后的关系能否被编译为更低成本、更少披露、更可追责的重复运行。方案同时规定安全停机、隐私分层、数据保留、盲化裁决、强基线公平、对抗测试和证据等级，保证真人实验只承担公开资料、形式验证和 sandbox 无法替代的主张。
