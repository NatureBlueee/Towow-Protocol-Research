# 15　分析计划

## 15.1 定量分析

- 参与者内配对比较：语义条件 vs 扁平中心；
- 仅在不可集中事项中比较联邦 vs Hub；
- 标准负控制比较 Router vs 平台；
- 形成事件使用消融和过程前后差异；
- 重复运行比较第一次/第二次/漂移后的成本；
- 使用分层模型或 cluster-robust interval 处理 matter 嵌套于参与者；
- 小样本优先报告个体轨迹、配对差、区间和敏感性，不以单一显著性阈值替代理论判断。

## 15.2 定性与过程追踪

每个关键案例建立：

```text
前态 -> 候选 -> 拒绝/Unknown -> 形成动作 -> 新条件
-> Mandate/Stance -> Commitment -> Operation -> Effect
-> Adoption/Acceptance -> follow-up/Defeater
```

独立裁决者评价形成是否真实、是否由研究系统因果贡献、是否可以由优秀经纪等价解释。保留“不确定”结论，不强制二分类。

## 15.3 互编码一致性

- material event 识别：事件级 precision/recall/F1；
- Authority Locus：类别一致率/Cohen’s kappa；
- Relation Schema 维度：多标签 Jaccard；
- outcome chain：顺序一致率；
- explain-back：material item 得分；
- 分歧先保存，后裁决。

## 15.4 缺失数据

区分：未发生、未观察、参与者拒绝披露、系统故障、丢失、研究者未编码。P3 local-only 不视为缺失，只要本地相称 Gate 返回可审计响应。关键 Effect/Acceptance 缺失的 live case 不进入完整闭环分析，但保留 intention-to-treat。
