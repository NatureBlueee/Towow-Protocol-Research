# 18　用户/Owner 需要准备的资源

## 18.1 现在需要的最小资源

第一阶段只需要两类：

- 3–5 个已经结束的 OPC 历史事项，允许脱敏访谈和关键材料定位；
- 2–3 位愿意进入 4–6 周 shadow mode 的超级个体/OPC，每人提供 3 个自然发生事项。

不需要先签大客户，不需要让参与者把全部聊天或企业资料交给研究系统，也不需要立即执行 Agent-to-Agent 真实交易。

## 18.2 Owner 的具体动作

1. 从身边的独立创业者、顾问、创作者、撮合者中筛选候选；
2. 先发送一页研究说明，不承诺“系统一定促成合作”；
3. 用七行 Case Card 收集候选事项；
4. 由研究团队判断进入历史、shadow 或 live；
5. 安排初始访谈与 follow-up；
6. 不替参与者回答 Authority、风险、接受或后悔；
7. 若有经验撮合者，邀请其作为历史材料提供者或强基线，而不是让其替双方作决定。

## 18.3 参与者邀请话术（简版）

> 我们在研究一种面向独立创业者和一人公司的 Agent 协作系统。它不是帮你强行成交，也不会一开始替你执行高风险动作。研究会选取你正在处理的真实事项，记录你真正的边界、谁有权决定什么、系统遗漏了哪些条件，以及在低风险范围内 Agent 能否帮助你形成、执行或更快拒绝一条路径。你可以把敏感信息留在本地，可以随时拒绝或退出。第一阶段主要是 shadow mode，不改变你的现实流程。
