# 1　为什么需要真人实验

## 1.1 已经不需要真人重复证明的部分

前期理论、代码、公开过程材料、QDR 访谈、模型检查和构造性机制基准已经能够承担以下工作：

- 静态画像在开放任务中不具有普遍充分性；
- Principal、Agent Entity、Authority Locus、Mandate 和 AgentExecution 不能合并；
- Candidate、Capability、Authority 和 Commitment 不能合并；
- ActionAttempt、Effect、Adoption 和 Acceptance 不能合并；
- material change 需要版本化处理；
- 稳定子图可以被编译，变化应触发 scoped reopen；
- 平台、中心 Agent、人类经纪、双边形成、临时联盟和人工裁决可以属于同一机制组合器；
- 在有限抽象模型中，撤销后执行、无 Attempt 的 Effect、无 Effect 的 Acceptance、未预留资源的 Commitment 和旧版本继续运行会形成明确反例；
- 公开 OPC 历史材料可观察到责任根与能力图分离、任务选择、临时能力组装、编译和保护性收缩。

真人参与不应用于再次确认这些概念“听起来合理”。

## 1.2 只有真人实验能够回答的主张

真人实验专门检验五项无法被公开档案或 sandbox 代替的问题：

1. **委托可理解性**：真实 OPC 是否能够理解精确 Mandate、版本差异和 Agent 的代表范围，并在不被术语压垮的情况下作出可靠授权；
2. **真实认领**：系统记录的 Stance 是否真的对应参与者理解、愿意承担和可以撤回的决定，而不是默认勾选或模型代填；
3. **形成因果性**：一条原本不存在或不合格的联合行动路径，是否由可消融的 probe、countercondition、伙伴/工具引入或任务重构产生；
4. **相对净价值**：相对成熟平台、强中心 Agent 和优秀人类经纪，系统是否在其适用域减少错误、披露、注意力和后悔，并形成正净值；
5. **长期运行**：关系编译后是否降低第二次、第三次任务成本，同时保持退出、责任、Effect 与 Acceptance 边界。

## 1.3 实验的基本伦理取向

研究目标不是提高成交率。对不合适的事项，正确结果可以是 `REJECT`、`DEFER_UNKNOWN`、`PROTECTIVE_CONTRACTION` 或 `RESTRUCTURE_TASK`。实验不得诱导参与者突破真实风险边界，也不得把参与者拒绝视为研究失败。相反，系统是否能更快、更准确地不成交，是核心价值指标之一。
