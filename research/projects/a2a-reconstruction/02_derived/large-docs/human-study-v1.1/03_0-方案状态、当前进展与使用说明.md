# 0　方案状态、当前进展与使用说明

本轮已经完成 H0 的第一批公共校准：20 个 OPC/solo-origin 案例、59 个过程事件、统一编码手册与 Schema；完成六根对象的可执行内核、17 项核心测试、九类 mutation 有界检查；完成 24 案例、五机制、2,400 次扰动评估的构造基准；完成 Fieldkit v0.8 的责任根、能力图和任务主权派生视图。上述工作用于减少真人阶段的调试成本，不替代真实 Mandate、Effect、Acceptance 或净价值证据。

本文件是可直接用于招募、伦理审查、技术实施和现场执行的正式研究方案，不是概念性路线图。它回答五个必须提前冻结的问题：

1. **数据标准**：什么数据可以进入研究，最小完整度、来源、时点、版本、质量、隐私和证据要求是什么；
2. **实验内容**：参与者和系统分别要做什么，必须产生哪些研究对象，观测哪些指标；
3. **实验设计**：在什么事项、环境、条件和基线下运行，主要假设和停止条件是什么；
4. **实验价值**：每个结果能支持或推翻什么主张，会怎样改变系统设计；
5. **协同与基础设施**：多 Agent 以何种角色和权限交互，中心化与联邦组件怎样组合，需要哪些连接器、事件、身份、策略和 Effect witness。

方案使用“必须”表示实验完整性或安全 Gate，使用“建议”表示可根据样本条件调整的实施方式。样本量是阶段性建设规模，不是假定效应量后的最终统计功效结论。任何超出低风险、可逆、有限金额和有限数据范围的现实动作，都必须另行评审。
