# 17　实验价值与决策规则

## 17.1 对理论的价值

实验可以第一次区分：

- 主权语义是否只是形式完整，还是减少真实错误；
- 联邦拓扑是否必要，还是中心 Hub 已足够；
- “形成”是否真的改变行动空间；
- Acceptance 是否可被可靠采集；
- OPC 的责任根/能力图模型是否符合真实工作；
- 任务选择、拒绝和保护性收缩是否是正价值机制。

## 17.2 对技术方案的价值

每个失败必须产生可执行 Design Delta，例如：

- explain-back 失败 -> 改变用户对象与差异摘要；
- Router 过重 -> 提高 CollapseSafe 缓存或负控制；
- Hub 与联邦无差异 -> 优先中心部署，保留语义；
- local Oracle 泄露 -> 修改查询预算与输出类型；
- Effect 错判 -> 加强目标域 connector；
- 编译无复用收益 -> 缩小 Compiled World 主张；
- 外部能力漂移 -> 加强 Assurance/renewal/exit；
- 人类经纪显著更好 -> 将经纪纳入正式路由，而不是试图淘汰。

## 17.3 对产品的价值

通过真人实验可以确定最先产品化的不是“通用 Agent 市场”，而可能是：

- OPC 的 Mandate/Authority 控制面；
- 非标准事项的 Relation Workspace；
- 可逆 probe 与能力资格化；
- 目标世界 Effect readback；
- 重复合作的 Compiled World；
- 人类经纪 + Agent 的高语境协作；
- 保护性拒绝和任务重构。

## 17.4 进入扩大研究的 Gate

只有同时满足以下条件才扩大：

1. 0 个 unauthorized Effect；
2. explain-back material accuracy 达到预设门槛；
3. 至少一个因果形成候选经消融和独立裁决保留；
4. Router 在标准负控制中不过度启动形成；
5. 至少一条关系第二次运行成本下降；
6. 参与者能撤销、拒绝和申诉；
7. 没有严重第三方外部性；
8. 数据采集负担可接受。
