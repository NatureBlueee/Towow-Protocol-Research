# 20　跨实验综合：稳定结论、被限定主张与系统 Design Delta

## 20.1 当前最稳定的形式与设计结论

综合理论、实验和公开历史，以下结论目前具有最高稳定性：

### 静态表示不普遍完备

开放任务中的行动空间会因工具、伙伴、授权、学习和任务重构而变化，任何固定 profile 都只能承担受限任务族中的投影。设计上，profile 用于提名，任务相关边界用于资格化。

### 当前不可行不等于全局不可行

一个候选被本地 Oracle 拒绝，可能暴露缺少的条件、工具、伙伴或执行位置。PFE 必须把 Unknown 和 Countercondition 转化为形成动作，而不是把所有拒绝当成永久失败。

### 可达性不推出能力、可靠性或接受

能够运行一次不等于可承诺；工具成功不等于 Effect；Effect 不等于 Adoption；Adoption 不等于 Acceptance。系统必须保持成熟度和效力链。

### 概率与权威正交

模型可以高置信地错，也可以正确但无权作数。选择性执行、Mandate、Evidence 和 Authority 必须同时存在。

### 单体能力不推出联合能力，联合能力也不等于各方责任闭合

高阶互补可能创造新路径，但必须同时闭合资源、权威、Effect 和对外责任。

### 稳定部分应编译，异常部分应重开

持续智能协商不是默认最优。零漂移与标准任务中，确定性机制更低成本；关系变化时只重开受影响子图。

## 20.2 获得限域机制支持的主张

以下主张已经获得明确但受限的机制证据：

- 交互式边界在合成凸/线性世界中可减少披露并保持可行性；
- 本地贡献列在隐藏模式团队构成中优于公开 profile；
- 风险门能够降低被建模错误，但可能牺牲覆盖率；
- 原子预留可以消除生成器内的共享预算超卖；
- 目标域 readback 能修正真实仓库的终态误判；
- Authority-first probe 与 countercondition 能在技术域内形成新可运行路径；
- 收敛本体能保留给定查询而减少顶层对象；
- materiality + dependency closure 能在有界模型中避免全局重开；
- 版本化权威图能保留公告和覆盖式单状态丢失的结构。

这些结论不能直接外推为真实用户价值。

## 20.3 被后续证据限定或推翻的主张

### “多轮 A2A 自然创造新能力”

R5.4 只证明更丰富的规范表达。能力形成必须有可达路径变化、现实 probe、资源/授权变化或 Effect 证据。

### “主权 A2A 优于中心化”

R5 的 4.54 倍开销、标准任务旁路和公开制度负控制表明，中心化常是系统必要组件。正确命题是：权威和信息不可无损折叠的局部需要主权机制。

### “一次形成成功证明能力”

R5.2 能力 holdout 未通过预注册门槛，说明资格化、恢复和 freshness 必须长期维护。

### “NAC 是通用语义基础”

NAC 保留为发现入口和多视角索引，不再承担开放世界本体。

### “软件仓库或进程可作为完整 Principal”

技术域可以拥有状态与局部 Authority，却不具备人的价值认领、法律责任和长期接受。R5C 因此被限定为技术权威域证据。

### “Relation Schema 七维已经完备”

58/58 映射只说明当前编码无残差，不排除编码者吸收偏差。七维是当前最简操作化候选，不是已证完备本体。

## 20.5 当前统一理论的最简表达

可以把本文的核心压缩为一条依赖链，但不能再把链条写成简单流程：

\[
\{W_i\}
\xrightarrow{boundary}
\Gamma_v
\xrightarrow{formation}
Q_t
\xrightarrow{qualification}
Cap
\xrightarrow{recognition/commitment}
C
\xrightarrow{operation}
Eff
\xrightarrow{adoption/acceptance}
S
\xrightarrow{compile/reopen}
CW.
\]

每个箭头都不是自动映射，而是一个需要相称证据、权威和失败处理的门。三个形成循环和五种贯穿语义使该链条可以递归返回。

## 20.6 原创性应如何表述

本文的潜在原创贡献不应写成“首次提出权限、承诺、共同对象或多中心治理”。更准确的表述是：

> 本研究把任务相关主权边界、未预定义行动空间构成、条件性能力资格化、范围化授权与认领、目标世界效力、机制组合、局部确定性编译和 scoped reopen，组织为一套面向 Agent Entity、尤其是超级个体与 OPC 的统一可运行体系，并用正负实验持续改变其设计。

其原创性是否足以构成学术贡献，最终还取决于真实 OPC 结果和与强基线的比较。
