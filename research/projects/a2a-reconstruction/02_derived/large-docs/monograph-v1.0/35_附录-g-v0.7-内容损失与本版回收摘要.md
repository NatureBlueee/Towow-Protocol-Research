# 附录 G　v0.7 内容损失与本版回收摘要

v0.7 被判定为扩展研究计划而非正式统一论文，主要因为其正文把历史形成过程和证据压成最新判断。v1.0 回收了以下六层：

1. **理论谱系层**：HDC/FHRR/NAC/BIC、搜索到构成、三维统一模型；
2. **机制层**：SJAC、JAA、PFE、CRA、Recognition、Commitment、Effect、Compiled World；
3. **形式层**：定义、假设、十一项命题、证明草图与反例；
4. **证据层**：全部实验的研究问题、方法、基线、数字、失败、限制和 Design Delta；
5. **系统层**：六 root、事件包络、状态机、Harness、Context Compiler、Effect Gateway、Router 和外部适配；
6. **现实层**：OPC 多角色、经济价值、策略行为、第三方 Standing、可证伪强基线和真实实验。

本版不要求所有历史术语进入顶层本体，但要求每个术语有明确去向。完整逐项 42 条损失审计随论文单独发布。
