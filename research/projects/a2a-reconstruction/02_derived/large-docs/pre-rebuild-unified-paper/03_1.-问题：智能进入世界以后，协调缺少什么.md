# 1. 问题：智能进入世界以后，协调缺少什么

现有大模型正在快速吸收理解、翻译、搜索、计划、工具调用和代码生成能力。随着模型能够读取长上下文、调用工具并产生长程行为，过去因理解成本过高而必须依赖固定部门、标准表单、人工汇报和中心经理的协作结构，会出现新的可替代空间。Kimi K2.5、DeepSeek-V3 等系统展示了模型在复杂推理、并行 Agent 与工具执行上的增长方向，但模型能力增长本身不会自动提供权威、责任、承诺、证据和结算结构 [@kimi2026; @deepseek2024]。

官方 A2A 协议已经为独立 Agent 的发现、消息、任务、制品和异步通知提供互操作框架；MCP 则为 Agent 与工具、资源、Prompt、Sampling、Roots 和 Elicitation 等环境能力建立接口 [@a2a2026; @mcp2025]。这些基础非常重要，但它们主要回答：

> 已经决定要交互的 Agent，怎样连接、传输和执行任务？

本文研究的是更上游也更下游的问题：

> 当主体尚未完整知道自己的需求、能力和合作对象时，怎样形成新的联合行动；当候选行动形成以后，怎样让它在多个主权世界中分别作数，并最终产生受控现实效果？

这不是普通消息协议可以独立解决的问题。它同时包含：

1. **认识问题**：各主体拥有巨大、动态、异构而私有的世界；任何公共表示都只是投影。
2. **生成问题**：需求、角色、能力组合和解决方案常常不是预先给定的，而是在看到候选方案、运行局部试验和改变条件以后才出现。
3. **权威问题**：模型可以理解和建议，却不能凭置信度获得代表主体承诺、披露、花费资源或接受结果的权力。
4. **现实问题**：消息送达、工具返回成功、日志写入和文件存在，都不自动等于目标世界已经改变，更不等于业务主体接受。
5. **制度问题**：跨主体协作包含责任、拒绝、退出、争议、托管、补偿和结算；这些不能隐藏在对话文本中。
6. **经济问题**：主权协调本身有成本。若一个最小权限中心能够安全保留任务、隐私、权威和责任，复杂 A2A 可能没有必要。

因此，本文把研究对象定义为：

> **生成式 Agent-to-Agent 协调**：多个独立 Principal 通过各自 Agent，在有限而受控的边界上共同发现、构造、验证和认领联合行动，并把被认领的行动编译为可执行、可验证、可接受和可结算的现实关系。

这里的中心不是 Agent 的人格，也不是消息，而是**共同现实的形成过程**。
