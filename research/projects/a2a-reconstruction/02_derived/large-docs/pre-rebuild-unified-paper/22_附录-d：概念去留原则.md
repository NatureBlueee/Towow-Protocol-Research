# 附录 D：概念去留原则

完整概念决策账本见随附 `concept_decision_ledger.csv`。合并或降级一个概念时，需要回答：

1. 原来区分的现实情况是否仍可表达？
2. 原来阻止的错误是否仍能阻止？
3. 权威、证据和责任被移动到哪里？
4. 什么反例会证明合并丢失必要能力？

通过这一标准，PFE、CRA、NAC、CapabilityEnvelope 和 Compiled World 被保留为策略、Pipeline、Provider 或视图，而不再作为平行权威世界。
