# Problem v1 候选：权威不可代行条件下可验证共同可行动性的形成与持续

Contract：`PRB-JOINT-ACTION-FORMATION / v1`

状态：`CANDIDATE`。未经用户决定，不是 `ACTIVE`，也不取代 `Problem v0 / SEED`。

历史继承审计当前建议：`READY`（审计仍为 `DRAFT`）。V1 本身保持不变；审计约束的是
后续讨论、研究线和系统设计不能过度拟合最近输入。中心成本、Agent 原生运行环境和人的

## 形式化研究问题

设必要主体集合为 \(P=\{p_1,\ldots,p_n\}\)。每个 \(p_i\) 保有不能被其他主体代行的局部
世界 \(W_i\)、权威范围 \(A_i\) 与披露策略 \(\delta_i\)。研究开始前冻结：

- 世界前态 \(S_0\)；
- 原始价值与不可接受底线 \(V_0\)；
- 合格联合行动路径的资格谓词 \(Q\)；
- 必要 Principal、Authority Locus 与目标域 witness；
- 可比较的强基线和统一成本口径。

候选关系不是一份全局世界模型，而是一组带来源、范围、版本和依赖的跨世界主张与状态转换。
它必须允许不同主体分别理解、修正、拒绝、保持 Unknown、授权、承诺和挑战。

对于 operator 序列 \(O\) 和路径 \(\pi\)，只有同时满足以下条件，才提出“形成了新的共同
可行动性”：

1. 在冻结的 \(S_0\) 中不存在满足同一 \(Q\) 的语义等价路径；
2. \(O\) 的每项现实改变都具有相应权威来源，且不静默扩大任何主体的 Authority Envelope；
3. 执行 \(O\) 后首次出现满足 \(Q\) 的 \(\pi\)；
4. 移除、反转或阻断关键 operator 后，\(\pi\) 不再成立；
5. \(Q\)、\(V_0\) 或必要主体若发生 material change，该变化被单独记录并由有权主体认领；
6. Capability、Mandate、Commitment、Execution、Effect、Adoption、Acceptance 与
   Settlement 分别由相应证据建立，不能互相自动推出；
7. 后续撤销、争议、漂移和失败能够沿真实依赖传播，并允许继续、阻断、退出或局部重开；
8. 相较权威感知强中心、成熟制度、平台流程、人类经纪与单一强研究者直接整合，新增价值
   高于披露、协调、等待、验证、治理、恢复与认知成本。

若路径在 \(S_0\) 已经存在，只是此前未知，则结果属于**发现**。若路径来自改变工具、权限、
伙伴、资源或现实条件，则可能属于**条件创造**。若路径来自降低原始价值底线、改写 \(Q\)
或遗漏必要主体，则属于**问题转变**，不能回填为原问题的 formation。

因此，v1 候选真正追问的不是“联邦 Agent 怎样协作”，而是：

> 在权威不可代行、信息不可完全汇聚的条件下，哪些可验证的状态转换能够把原本不存在的
> 合格联合行动路径构造成可执行、可归因、可接受并可持续的共同可行动性；面对低频、异构、
> 跨领域且事前难以枚举的关系，怎样把首次形成所需的高成本智能判断和平台规则建立沉淀为
> 可复用、可编译的关系路径，并将不同子问题路由到中心、联邦、平台、人类或混合机制，使
> 全生命周期真实处置成本低于可信基线？

## 成本不是 token，而是规则形成与智能判断

本研究记录模型、RAG、算法和机器执行支出，但不以一两美元的调用差异解释系统价值。主要
成本是：

- 多团队形成问题、角色、合同、规则、审批、接口和验收标准；
- 高语境人员的理解、解释、例外与责任判断；
- 开会、追问、等待、返工、晚拒绝和机会损失；
- 权威、能力、现实 Effect 和接受的验证；
- 关系形成后的治理、漂移、恢复和重开。

RAG 可以降低检索成本，摘要和专用算法可以降低已知关系语法中的计算成本；它们不能自动
形成未知角色、局部权威、新条件、现实 witness 和接受规则。中心机制的关键负担不是原始
数据量，而是低频异构关系中不可安全复用的 material judgment 数量。

同时，v1 不把这一点当作通爻已经获胜的理由。必须检验通爻是否真的降低了每类新关系的
边际规则形成成本，还是仅把平台建设成本转移成边界表达、本地接入、证据、授权解释和治理
成本。

详细账本、公式、Router 变量与五项成本假说见：
`research/projects/joint-action-formation/economics/lifecycle-cost-model.md`。

## 与 v0 的主要差异

- v0 描述完整生命周期；v1 候选增加了冻结前态、资格谓词、operator 和反事实必要性。
- v0 容易把发现与形成并列叙述；v1 候选把发现、条件创造和目标改写设为互斥分类。
- v0 强调不可折叠主权；v1 候选不预设联邦拓扑，改为检验来源范围与权威是否被保真保存。
- v0 列出 Effect、Adoption 和 Acceptance；v1 候选明确它们与能力、授权、承诺、执行、
  Settlement 之间均不存在自动蕴含。
- v0 以强中心、平台和人类经纪为基线；v1 候选新增成熟制度与单一强研究者直接整合，并要求
  报告七线共享来源和模型相关性。
- v1 候选进一步把中心、联邦、平台和人类机制变成 Router 可组合的结果，比较首次规则形成、
  稳定编译、多次复用、漂移和重开的生命周期成本，而不是单次模型调用成本。
- PFE、NAC、RelationVersion、Mandate、ledger 与依赖闭包都只是待消融的候选机制，不是
  问题定义预设的答案。

## 当前不能宣称

此候选来自档案七线分析和一次匿名模型盲审。它没有证明通爻机制有效，没有证明联邦优于
中心，没有证明七线优于直接整合，也没有证明真人授权、现实 Effect、Adoption、Acceptance
或净正价值。39 项历史能力没有全部逐字出现在问题陈述中，不构成 V1 缺陷；它们由七条
研究线、场景、机制实验和工程设计继续继承。下一步仍由用户决定激活、重写、拒绝，或继续
保留为候选；最近讨论不能被当作对 V1 的静默修订。
