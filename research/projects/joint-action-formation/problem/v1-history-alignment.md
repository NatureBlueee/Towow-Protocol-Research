## 一、结论

用户的校正是：当前 v1 候选本身是好的；发生过拟合的是 v1 形成以后，我们围绕中心 Agent、
成本和 Agent 原生运行环境进行的继续讨论。那次讨论逐渐把三个重要的解释维度说成了新的
研究中心，因而遮住了 v1 已经建立的完整问题。

所以，本审计不再把“历史能力没有逐字出现在问题契约中”解释为 v1 缺陷，也不要求重写
v1。它承担的是另一项职责：约束后续研究、解释和系统设计不得只追随最近一次谈话，从而
遗失 v1 所指向的完整问题和历史研究能力。

39 项历史设计能力的逐项比对结果是：

| 当前 v1 覆盖 | 数量 | 含义 |
|---|---:|---|
| `EXPLICIT` | 22 | 问题契约中存在可定位的现实差异或失败条件 |
| `PARTIAL` | 10 | 有相关词语，但原行为、owner 或移除失败不足 |
| `ABSENT` | 7 | 当前问题中没有可恢复的正式位置 |

机器可检查的逐项账本见
`research/projects/joint-action-formation/problem/v1-history-alignment.json`。

这里的 `EXPLICIT / PARTIAL / ABSENT` 只表示某项能力在 **V1 文本中的展开程度**，不是
V1 的质量评分。一个形式化问题定义没有义务枚举所有发现算法、运行组件、验证方法和系统
机制；这些内容可以由 LineContract、场景、实验和工程设计继承。

这次审计要求的是：

> 每个历史概念原来区分的现实情况、能阻止的失败和当前去向都必须明确；“能映射进新文字”
> 不能替代“原正例和移除失败仍然可执行”。

## 二、用户本轮判断在历史中的真实位置

“给 Agent 足够的上下文、智能、工具与运行环境，使原来主要由人承担的高智能判断转移到
Agent，并让人只在真正需要的地方高效参与”并不是今天新添加的方向。历史中已有五个直接
前身：

1. `AgentExecution` 被定义为一次绑定 Mandate、上下文快照、执行器、工具和预算的运行，
   而不是一个社会主体；
2. `Sovereign World` 同时包含历史上下文、目标、能力、工具、资源、权威、政策、制度和
   执行环境；
3. `Context Compiler` 的任务不是给 Agent 最多信息，而是生成有来源、可回溯、任务相关的
   最小充分上下文；
4. 企业 Harness、World、Desk 与 Trace 被称为系统连接现实组织的“身体”，把企业对象、
   权限、动作、证据和状态编译为 Agent 能进入的局部世界；
5. OPC 研究已经把主要瓶颈写为人的高认知判断，并追问哪些判断留给人、哪些交给 Agent、
   哪些关系可以编译。

来源：

- `monograph-v1.1/08_4-主体、世界与权威：agent-entity-不是模型实例.md:98-123`
- `monograph-v1.1/19_15-系统架构、协议内核与外部连接器.md:129-152`
- `original-handoff-manual-v1.0/04_研究谱系与概念演化.md:319-328`
- `monograph-v1.1/18_14-面向超级个体与-opc-的主权代理操作系统.md:14-23`

因此，不应把当前用户解释写成一个替代 V1 的新中心。它补充的是
`AgentExecution—Context Compiler—Harness—Compiled World` 环境线，回答 V1 所需的高智能
判断怎样实际发生，而不是重新定义 V1 研究什么。

## 三、历史中必须并列、不能熔平的结构

### 3.1 七条生成链

| 原生研究核 | 它保留的不可替代问题 |
|---|---|
| 发现与边界 | 静态画像不能穷尽未来任务相关行动空间 |
| 问题与关系构成 | 查询、参与者、角色、动作和评价语言本身可能尚未存在 |
| 可能性形成 | 当前不可达可能需要探问、工具、训练、伙伴、授权、重构或现实 probe |
| 能力兑现 | 一条可能路径或一次成功不能直接成为可承诺能力 |
| 权威与规范 | 身份、能力、授权、认领、承诺和资源预留不互相推出 |
| 现实效力 | Attempt、Effect、Adoption、Acceptance 和 Settlement 不互相推出 |
| 运行与演化 | 开放形成、稳定编译、学习、Defeater 与局部重开需要不同控制制度 |

六个 canonical roots 是实现事实源的收敛候选，不是七条研究核的替代。旧研究已经明确：
PFE、CRA、NAC、JAA、SJAC、BIC、Harness 和 Compiled World 即使不拥有第二套正式事实，
仍可能是理论主层、策略、Provider、Pipeline、共同介质或运行投影。

来源：

- `research/projects/a2a-reconstruction/00_orientation/CURRENT_GLOBAL_VIEW.md:18-31`
- `research/projects/a2a-reconstruction/00_orientation/CONCEPT_AND_SYSTEM_LINEAGE.md:5-78`
- `original-handoff-manual-v1.0/06_新研究员使命、方法与工作纪律.md:39-49`

### 3.2 五种贯穿语义

每一层还需要分别保留：

- 认识语义：知道、未知、证据、推断和 Defeater；
- 生成语义：候选、形成算子、组合和任务重构；
- 规范语义：谁有权、谁认领、谁负责；
- 操作语义：执行、Effect、恢复、采用和接受；
- 经济语义：价值、成本、容量、披露、风险和人的注意力。

把这五种语义压成一个“形成成功”布尔值，会再次发生有损整合。

## 四、V1 以后讨论发生的主要变形

以下六点不是对 V1 文本的否定，而是对我们如何解释和继续研究 V1 的校正。

### 4.1 讨论把 formation 验证协议提升成研究本体

冻结 \(S_0\)、资格谓词 \(Q\)、operator 和消融，是区分“发现既有路径”与“因果形成新路径”
的好方法。但历史研究的上游问题恰恰是：查询、必要主体、角色、动作、证据和合格标准本身
尚未形成。

因此后续研究仍应区分两个阶段：

1. 问题与关系语法怎样被构成；
2. 当某项具体 formation 主张进入检验时，才冻结相应的 \(S_0/Q/operator\)。

V1 中的冻结条件应被理解为对一项具体 formation 主张的严格检验要求；它不取消上游
“必要主体、角色、动作、证据和合格标准怎样形成”的研究。

### 4.2 讨论把完整共同现实链压成一个成立门槛

历史要求各层不能互相自动推出，并不表示每个低风险任务都要显式实例化整套 Mandate、
Commitment、Effect、Acceptance 和 Settlement。

更合适的结果不是单一布尔值，而是一组彼此独立的状态：

```text
Boundary / Discovery
Constitution
Possibility Formation
Capability Qualification
Recognition / Authority / Commitment
Effect / Adoption / Acceptance
Compilation / Reopen
Net Value
```

一条新路径可以形成但尚未被资格化；Effect 可以发生但未被接受；关系可以没有扩张，却因
更快识别不兼容而产生保护性价值。每层都需要自己的成功、失败与 Unknown。

### 4.3 讨论把成本变成单一解释中心

历史经济模型比较的是实现价值减去过程成本、错误损失、外部性、风险和后悔。通爻可能：

- 以更低成本完成同一关系；
- 以相近成本提高保真度或减少错误；
- 以更高成本形成基线根本无法形成、但净价值为正的关系；
- 更快得到真实 Reject、Defer 或 Protective Contraction。

V1 的生命周期成本比较仍然保留。后续解释应同时研究联合可达前沿，不能把成本讨论扩张成
“这项研究最终只是在降低协调成本”。

### 4.4 讨论重新围绕中心与去中心形成对立

中心、平台、联邦、人类和确定性服务可以出现在同一关系的不同子问题和阶段。一个中心机制
在某类任务上胜出，只能说明该局部 `CollapseSafe`，不能推翻：

- Agent 运行环境；
- 动态边界与问题构成；
- PFE/CRA；
- Effect 与 Acceptance 的非蕴含；
- 编译、学习和重开。

这恰好是 V1 已经处理正确的地方：Router 的产物是机制图，而不是一次性的架构标签或总胜负。

### 4.5 后续研究若只保留单个 episode，会丢失关系生态

早期原生问题同时研究：

```text
陌生 Agent 发现
→ 生成关系
→ 成功路径沉淀
→ 路由和主体学习
→ 未来发现路径缩短
→ 标准区域结晶为平台或中心
→ 新型需求重新进入开放关系场
```

其中“亿级规模”“分布式原生”“固定全局画像”等旧裁决不能原样恢复；部分已经被证据限定。
但网络级的关系沉淀、路径压缩和学习问题没有被单 episode 模型吸收。

整个研究程序至少需要三个分析尺度，但不要求它们全部成为 V1 的单一分析单位：

1. `AgentExecution`：一次智能判断怎样获得上下文、工具和执行环境；
2. `RelationEpisode`：一项关系怎样发现、构成、形成、兑现并进入现实；
3. `RelationEcology`：多个 episode 怎样沉淀、编译、缩短路径、形成平台并因新差异重开。

### 4.6 讨论把人的参与压成了成本

研究目标不是机械地减少人，而是重新配置人的参与：

- Agent 承担信息搬运、候选生成、探问、工具调用和可自动验证的判断；
- 人在偏好形成、价值冲突、不可逆风险、最终责任和例外处参与；
- 稳定判断被编译；
- 新 Unknown 或 Defeater 才升级。

人的高认知分钟是指标，不是这项配置问题的完整定义。

## 五、PFE、NAC 与用户记忆中的 P 开头机制

档案可以确认的正式机制是 `PFE`，没有找到 `PEC` 或 `PCC` 的历史定义。

### PFE

PFE 不是一个全知规划器，也不只是“形成 operator”的别名。它回答：

> 下一步做什么，最可能使当前问题变得更可判断或更可行动？

它需要同时维护：

- typed Unknown；
- 当前 RelationVersion；
- 候选 formation operators；
- 每项动作的成本、风险、披露与信息增量；
- 对合格行动空间的预期扩张、收缩或澄清；
- 所需 Authority；
- 停止、转人工、升级和退出条件。

`EVPF`，后来写作 `ECVI`，是形成动作的逐步选择准则。V1 不需要在问题定义中内嵌这个
planner；可能性形成研究线必须继续回答下一步应该询问、probe、引入伙伴、申请授权、
重表示还是退出。

PFE 与 CRA 还构成生成—反驳循环：CRA 的能力反例可能返回 PFE 创造新条件，PFE 的新路径
又必须进入 CRA 的 holdout、迁移、容量和恢复资格化。

### NAC

NAC 的普遍语义本体主张已经被降级，但它原来保留的现实差异不能只用“有限披露”概括：

- 异构模型共享外部锚点，不假设内部 embedding 等价；
- SEEK/OFFER 保留关系方向；
- 多尺度前缀支持粗到细的渐进披露；
- 版本和 provenance 防止陈旧坐标成为能力事实。

因此 NAC 应保留为待强自然语言基线检验的 Discovery Provider，而不是重新升为协议本体，
也不能只留下缩写。

## 六、V1 未显式展开、但研究程序必须继承的能力

下面的 `ABSENT` 与 `PARTIAL` 是文本显式度，不表示 V1 问错了，也不要求把这些机制全部
塞进问题陈述。它们约束的是后续 LineContract、场景、实验和系统设计。

### V1 文本未显式展开的七项

- `CAP-DISC-002`：角色绑定与角色交换反例；
- `CAP-DISC-003`：跨模型外部锚点与内部表示的区别；
- `CAP-DISC-005`：SEEK/OFFER 方向性；
- `CAP-DISC-007`：类型化 Boundary Oracle；
- `CAP-REL-004`：本地私有候选生成与最小贡献证明；
- `CAP-CAP-002`：干预前 claim 与 prospective holdout；
- `CAP-RUN-002`：可回源的最小充分 Context Compiler。

其中只有 `CAP-REL-004` 是**历史系统审计**中已经判为 `LOST` 的能力：当前没有 owner
负责让候选在本地私有行动集中生成、只提交改善当前解的最小贡献，并阻止中心因拿不到全集
而宣称无解。这是研究与系统的恢复任务，不是 V1 的文本缺陷。

### 只有部分保留的十项

- 任务相关投影；
- 渐进披露预算；
- 边界充分性；
- typed Unknown 到形成动作的路由；
- 拒绝与 countercondition；
- 组合能力与容量；
- 第三方 Standing 与 recourse；
- 幂等恢复身份；
- Problem/Design/Engineering IR 分离；
- Router 从未经编码材料冷启动。

Authority 与 Reality Effect 是当前 v1 展开最充分的部分。上游能力需要由研究程序继续承担：

> Agent 怎样获得任务相关上下文、怎样从私有世界生成最小候选、怎样用类型化边界响应推进、
> 怎样选择下一项智能判断，以及怎样把形成后的路径资格化为可依赖能力。

## 七、不能反向恢复的旧主张

历史对齐不等于回到最早版本。以下主张已经被否定、限定或没有足够证据：

- NAC 是普遍必要的跨模型语义本体；
- 联邦或分布式部署普遍优于中心；
- 更多 Agent 对话自然形成能力；
- 一次成功建立可承诺能力；
- 六个 roots 能表达旧术语，因此旧机制已经得到保全；
- 合成大样本、形式漂亮或作者自评分证明现实价值；
- OPC 首发参数区可以代表全部组织与市场分布。

这些负结果必须和旧机制的有效局部一起保留。

## 八、以 V1 为锚继续研究的最低继承条件

1. V1 保持原样；中心成本、Agent 原生环境和人的参与配置只能登记为子问题、假说或设计线。
2. \(S_0/Q/operator\) 继续约束 formation 因果主张，不吞并上游问题与关系构成。
3. Authority、Effect 与 Acceptance 继续保持非蕴含，同时允许低风险稳定部分轻量运行。
4. 生命周期成本继续检验，但与可达价值、错误、风险、披露和后悔共同解释。
5. 旧缩写不必全部升为对象；其现实差异、失败检测、owner 与证据边界必须有去向。
6. 研究程序同时保留 episode 内生命周期和跨 episode 的发现、沉淀、编译与学习。
7. 七条研究线继续绑定当前问题；后续改写或替代 V1 时再执行显式迁移。
8. 39 项矩阵用于检查研究程序是否失忆，不用于要求 ProblemContract 逐字包含 39 项能力。

当前 v1 继续保持 `CANDIDATE`，原因只是尚未发生用户的正式激活决定，不是因为本审计要求
重写。刚才的新表述不能覆盖它，只能作为其下的研究输入。
