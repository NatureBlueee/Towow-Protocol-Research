# Problem v2 候选：开放行动世界中的共同可行动性构成与有界机制生态

Contract：`PRB-JOINT-ACTION-FORMATION / v2`

状态：`CANDIDATE`。V2 是一份新的加法式快照，不是对 V1 的覆写、纠错或否定；未经用户
决定，它也不是 `ACTIVE`。

V1 的 Problem 机器文件和人类说明分别按 SHA-256
`9a59de81ac7c5ca0a42ff012bbade98b4be60978742b3c81d26f9024a3e9b408` 与

相应历史继承审计的机器文件和人类说明也分别按

固定。V2 的作用只有一个：把 V1 与历史中已经存在、但独立研究者很容易忘记的共同世界
前提、服务对象、评价框架和研究范式显式冻结下来。“有界机制生态”描述的是后续研究怎样
组织，不是通爻需要服务或维护的最终对象。

## 一、我们研究和服务的是什么

我们仍然研究 V1 所定义的核心问题：

> 当多个 Principal 的世界、权威和责任不能被安全折叠，也不能被其他实体代行时，怎样先
> 判别合格联合行动路径是既存但未被发现、需要改变条件，还是由可归因 operator 真正形成；
> 再使相应关系成为可理解、可修正、可拒绝、可授权、可执行、可验证、可接受并可持续重开
> 的共同可行动性。

V2 没有把这个问题换成 Intent 识别、网络路由、NAC、成本优化或中心—去中心架构选择。
它只是进一步说明：上述问题发生在怎样的世界里，以及不同独立研究线必须共同记住什么。

通爻服务的不是咖啡、失眠、OPC、供应链或某一类交易。它服务的是一个更一般的对象：

> 在开放行动空间中，让既存机会或行动路径能够被发现，让必要的新关系能够被构成、执行、
> 验收、沉淀和重开；同时识别哪些局部问题已经可以交给平台、中心、制度、人类或现成技术，
> 哪些仍需要新的机制。

## 二、共同世界底座

### 1. Agent Entity 是广义实体

Agent Entity 是对外具有连续身份、可认证边界、有限授权和可追责性的实体。它的内部可以
包含人、组织、角色、模型、工具、账户、工作流、审批链和多个局部权威。它不是单一大模型、
单一进程或肉身个人的同义词。

### 2. Intent 是协调接口的统一输入表示，不是新的中心对象

Intent 可以来自两类上游：

- 人或其他主体的显式输入；
- 某个上游系统依据事件、状态或数据产生的隐式输入。

上游究竟怎样感知、推断、编译或生成 Intent，不属于通爻当前的研究对象。对本研究所考察的
协调接口来说，两类输入进入后都表示为 Intent。既有关系事件与现实漂移属于生命周期事件；
只有它们转化为新的协调输入时才表示为 Intent，而不是第三类协调输入。Intent 可以携带可
验证的 Principal、Mandate、provenance 或其他 authority status，也可以保持 Unknown；
接口应保留并验证已有状态，但不能仅凭到达推断某个 Principal 已经提出、认领、授权或接受它。

必须允许下列角色不重合：

1. Intent 的生成者；
2. Intent 声称代表的 Principal；
3. 可能受益的主体；
4. 可能受影响的主体；
5. 有权决定、授权或承担后果的主体。

这个区分不意味着所有 Intent 必须经过同一条归属—授权流水线。它只意味着：当某项后续
行动依赖尚未充分建立的规范地位时，相关研究线必须保持 Unknown 或补足必要判定，不能让
入口相关性静默穿透为行动权威。

### 3. 网络可以是海量、异构和局部私有的

目标环境允许亿级、动态进出的主体，允许模型、工具、角色和本地世界彼此异构，也允许 Intent
关系低频、长尾、跨领域并且事前无法枚举。因此，默认方案不能依赖：

- 把每个主体的完整世界汇聚到一个地方；
- 把每项 Intent 全量广播给所有节点；
- 让每个高级模型逐一理解和判断是否相关。

这不预设 NAC、Gossip、向量签名、联邦学习或任何具体技术。它只要求后续发现机制同时回答：
如何缩小候选、保护局部世界、限制传播与高级智能调用，并测量漏配和错误淘汰。

### 4. 预编译制度与开放形成同时存在

平台、中心系统、合同、制度和人类协调并不是通爻的敌人。它们已经承担了至少一部分对象
识别、角色定义、动作约束、信任、执行、Effect、结算、治理和例外处理。

它们可以被理解为已经编译的行动空间：在稳定、高频、边界明确的分布上，确定性流程或中心
平台很可能是更好的方案。开放关系形成处理的是尚未被这套空间覆盖的部分：角色、动作、伙伴、
条件、能力或接受方式本身仍需形成。

形成成功的路径还可以再次沉淀为合同、平台规则、中心服务、联邦结构或混合机制。出现新差异、
失效或漂移时，再只重开必要部分。中心与去中心因此是关系内部的可选结构和演进结果，不是
研究开始前的阵营选择。

### 5. 三个分析尺度并列

后续研究必须声明自己实际处理的尺度，不能让一个尺度的成功或失败吞并另外两个尺度：

- `AgentExecution`：一次智能判断怎样获得上下文、模型、工具、账户与执行环境；
- `RelationEpisode`：一项关系怎样被发现、构成、兑现并进入现实；
- `RelationEcology`：多个 episode 怎样沉淀、编译、形成平台或中心路径，并因新差异重开。

具体 formation 主张仍以 V1 的可追溯 `RelationEpisode` 为主要单位，但 Agent 的运行环境
是必要的支撑尺度，跨关系的复用和制度演化是必要的生态尺度。前者不是新的总问题，后者也
不能用网络统计替某次执行、授权或主体认领背书。

### 6. 人的参与需要重新配置，而不是被最小化

Agent 可以承担信息搬运、候选生成、探问、工具调用和可自动验证的判断；人或相应 Principal
应在偏好形成、价值冲突、不可逆风险、最终责任和例外中按实际权威参与。减少高认知人力可以
是某些场景的结果指标，但“人类分钟数越少越好”不是全局目标，更不能用自动化穿透人的
拒绝权、责任和不可代行判断。

## 三、V1 核心边界完整继承

V2 不改变 V1 已经建立的承重区别：

- 认证、技术能力、Principal 授权和 AgentExecution 不互相蕴含；
- 发现既存路径、改变现实条件与改写原问题是不同状态转换；
- formation 需要冻结前态、资格谓词、可归因 operator 和反事实消融；
- Capability、Mandate、Commitment、Execution、Effect、Adoption、Acceptance 与
  Settlement 可以分别失败；
- 拒绝、Unknown、中心方案更好、平台更好、无形成、负净价值和退出都是正式结果；
- Clarification、Protective Contraction、Reject 与 Defer 即使没有形成新关系，也可能
  产生保护性价值、信息价值或更早暴露不兼容；
- 稳定路径可以编译，失效与漂移需要沿真实依赖阻断、恢复或局部重开；
- 成本比较覆盖规则建立、高认知人力、等待、验证、错误、治理、恢复和机会损失，而不是
  只比较 token。

因此，V2 是 `V1 + 显式共同世界底座`，不是 `V1 被今天的讨论替代`。

## 四、七条问题家族与有界机制研究

七条原生线继续作为彼此独立的问题家族：

1. 发现与边界；
2. 问题与关系构成；
3. 可能性形成；
4. 能力兑现；
5. 权威与规范；
6. 现实效力；
7. 运行与演化。

问题家族不等于单一机制。NAC 可以在“发现与边界”下拥有自己的机制 profile 和实验；PFE
可以在“可能性形成”下推进；CRA 可以在“能力兑现”下推进。它们只是当前已知例子，不是
V2 的固定模块清单。各机制不需要因为属于一张全局图就失去独立身份，也不需要现在收敛为
同一模型；它们的具体问题、证据与失败门保存在各自 profile 和 LineContract 中。

对于每个机制，后续研究统一采用：

> 在环境与前提 \(E\) 下，针对问题 \(P\)，机制 \(M\) 提供能力 \(C\)，满足要求 \(R\)，
> 明确不负责 \(B\)，当前证据为 \(S\)，并接受替代方案 \(A\) 与失败反例 \(F\) 的检验。

一个机制没有解决作用域外的问题，不构成降级证据。负结果只改变受检验的子主张。已有标准、
平台或 adapter 完整满足要求时直接使用；部分满足时只扩展缺口；确认没有现成方案后才创建
新机制。替代或整合必须在相同前提下重放原正例、能力和移除失败。

## 五、全局评价

后续研究不能再以单一接受率或方案通过率代表价值，也不能用“一美元还是两美元”的模型费用
代表成本。至少需要同时观察：

- 是否增加了保持原始价值底线的真实可达行动；
- 是否保留 Principal 的归属、拒绝、授权、责任和接受；
- 是否影响了未直接参与但受后果影响的主体；
- 是否减少或增加漏配、误唤醒、披露、等待、错误和后悔；
- 是否把人的参与放在相称的偏好、价值、风险、责任和例外判断处，而不是只追求减少人工；
- 是否保存 Clarification、Protective Contraction、Reject 与 Defer 的独立价值；
- 是否相对强平台、强中心、制度、人类和通用技术基线产生独立价值；
- 是否能复用现成能力、编译稳定路径并限制漂移后的重建；
- 系统级增量是否高于全生命周期成本与外部性。

系统级价值不能简单地把所有主体效用相加，更不能以全局增量为由越过某个 Principal 的不可
代行权威或不可接受底线。

## 六、这份 V2 不做什么

V2 不研究上游怎样识别隐式 Intent；不选择 RAG、Context Compiler、联邦学习、Gossip、
多尺度向量签名或 NAC 的具体实现；不把某个案例当作产品范围；不证明中心化或去中心化；
不要求七条线共享一个答案；也不因为新增文件而把 V1 和历史机制变成“旧错误”。

V2 只是后续独立研究者共同冻结的知识底座。具体哪条线需要哪些前提、哪个历史机制仍然适用、
哪个现成方案可以直接采用、哪个缺口需要新机制，由各条线在自己的证据边界内继续回答。

## 七、当前证据和决定边界

V2 主要是对 V1 与历史材料的继承和显化。V2 专属历史继承审计见
`research/projects/joint-action-formation/problem/v2-history-alignment.md`；激活材料的
五件哈希闭包见 `research/projects/joint-action-formation/problem/activation/v2.json`。
真正新增的显式边界很少，最重要的是：

- 显式与隐式来源在接口处统一为 Intent，上游生成保持研究范围外；
- Intent 生成者、所代表 Principal、受益者、受影响者和有权决定者不预设重合；
- AgentExecution、RelationEpisode 与 RelationEcology 必须并列，人的参与按权威和风险
  重新配置，非形成结果的保护性价值必须保留。

这份候选没有证明 NAC、PFE、CRA、通爻或任何组合现实有效，没有激活新问题，没有启动现实
场景，也没有把 V1 标记为错误或 superseded。V2 是否激活，仍需要用户单独决定。
