# Problem v0：不可折叠主权条件下的共同可行动性构成

Contract：`PRB-JOINT-ACTION-FORMATION / v0`

状态：`SEED`，不是当前已经确认的统一答案。

本研究追问：怎样让一个对外具有连续身份、可认证权威、有限授权和可追责性的 Agent
Entity，在不暴露、复制或交出完整内部世界的情况下，与其他不能被替代、也不能彼此代行
权威的实体，共同形成此前不存在的真实关系。

困难在于，研究面对的不是目标、角色、动作和规则已经给定的任务。问题是什么、谁应参与、
各方能贡献什么、条件能否改变、谁有权决定、需要什么证据、怎样才产生现实效果，以及由谁
采用和接受，往往都尚未完整形成。因此，研究对象不是消息或方案，而是一个跨 Principal
关系 episode 如何从不可行动变为可被各方理解、修正、拒绝、授权、承诺、执行和验证。

这里的“共同”不要求统一世界模型。各主体保留本地事实、解释、权利和责任，只在具体行动
所需范围内形成可以相互引用的主张、条件、权威、承诺、效力和接受关系。

v0 的任务不是被七条研究线共同证明，而是接受它们分别提出的最强反例。只有当研究能够
说明哪些差异不能折叠、哪些机制可以降级、什么场景具有判别力，以及什么结果会迫使核心
问题重写时，才形成提交给用户确认的 v1 候选。
