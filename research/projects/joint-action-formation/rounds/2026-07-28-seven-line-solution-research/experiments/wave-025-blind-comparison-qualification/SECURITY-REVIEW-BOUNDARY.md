# Wave025 安全研究交接边界

日期：2026-08-01  
状态：`SECURITY_REVIEW_REQUIRED / DEFERRED_TO_SECURITY_PERSONNEL`

用户决定：网络安全相关内容交由安全人员处理。本研究 Agent 从本标记起不再继续挖掘、实现、
复现或验证下列事项，也不再把被外部模型拒绝的相关请求改写后重试：

- 网络、容器或主机隔离绕过；
- 权限边界、攻击面与可利用路径验证；
- 面向真实系统的渗透、规避或攻击实现；
- 需要安全专业判断才能宣称成立的防护、无泄漏或抗攻击结论。

这些事项保持 `NOT_REVIEWED_BY_SECURITY / NO_SECURITY_CLAIM`，由安全人员另行决定材料、方法、
权限和验收标准。这里的“暂停处理”不表示风险不存在，也不表示当前实现已经安全。

本研究 Agent 可以继续不涉及上述行为的本地工作：确定性数值与字节语义、分类器规则定义、
合成任务比较、证据状态与研究谱系整理。若这些工作遇到依赖安全判断的前提，只记录为
`SECURITY_REVIEW_REQUIRED`，不自行补证。
