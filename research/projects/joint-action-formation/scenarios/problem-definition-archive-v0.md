# 场景：七条原生研究线独立攻击 Problem v0

Contract：`SCN-PROBLEM-DEFINITION-ARCHIVE / v0`

这是一个 `ARCHIVE / PROBLEM_DEFINITION` 场景。它只在本地材料环境中运行，现实效果仅指
产生可校验的候选研究制品，不得被描述为现实关系形成或主体接受。

七条线提交前互不可见。它们必须分别指出：

1. v0 忽略或错误折叠了什么；
2. 去掉本线区分会重新出现什么现实错误；
3. 什么场景能够区分本线解释与最强替代解释；
4. 什么反向结果会迫使本线或其历史术语降级；
5. 它能支持什么，以及明确不能支持什么。

最终是否形成 `Problem v1 / ACTIVE` 只由用户决定。
