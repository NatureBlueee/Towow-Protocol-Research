# Research

这是长期研究的开放工作区，不是某一轮任务的执行目录。

目录只用于帮助定位：

- `NOW.md`：当前研究现场；
- `DECISIONS.md`：真正改变方向的决定；
- `questions/`：问题地图；
- `library/`：来源、阅读笔记和语料索引；
- `projects/`：独立研究线，可自由定义结构；
- `experiments/`：跨项目可复用的实验、数据或工具；
- `syntheses/`：跨研究线综合；
- `artifacts/`：论文、图、代码、演示等输出；
- `archive/`：退出当前现场但仍需保留的材料；
- `templates/`：可选起点。

没有文件要求每轮必填。只保存未来无法轻易重建、且会帮助判断或接续的内容。

创建新研究线可以运行：

```bash
make new-study STUDY=<short-name>
```

也可以直接建立更适合当前问题的结构。
